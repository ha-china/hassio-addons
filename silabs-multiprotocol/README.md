# \[已过时\] Home Assistant 应用：SiliconLabs Zigbee/OpenThread 多协议应用

SiliconLabs 基于无线电设备的 Zigbee/OpenThread 多协议容器，例如
Home Assistant Yellow、Home Assistant SkyConnect 和 Home Assistant Connect ZBT-1。

![支持 aarch64 架构][aarch64-shield]
![支持 amd64 架构][amd64-shield]

## 简介

该应用（以前称为附加功能）允许您在同一个基于 SiliconLabs 的无线电设备上同时使用 Zigbee 和 OpenThread 协议。该无线电需要安装支持多个 IEEE 802.15.4 个人局域网（PAN）的 RCP 多PAN 固件。该附加功能已通过带有 EFR32 系列 2 无线电的设备进行测试。
