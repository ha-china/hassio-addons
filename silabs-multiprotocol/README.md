# **[已弃用] Home Assistant App：SiliconLabs Zigbee/OpenThread 多协议 App**

Silicon Labs 基于的无线电（如 Home Assistant Yellow、Home Assistant SkyConnect 和 Home Assistant Connect ZBT-1）的 Zigbee/OpenThread 多协议容器。

![支持 aarch64 架构][aarch64-shield]
![支持 amd64 架构][amd64-shield]

## 关于

此应用程序（以前称为附加组件）允许您在单个 Silicon Labs 基于的无线电上同时使用 Zigbee 和 OpenThread 协议。需要安装 RCP Multi-PAN 固件以支持多个 IEEE 802.15.4 个人局域网（PAN）。该附加组件已在基于 EFR32 Series 2 的无线电上经过测试。
