## 关于

这是 Home Assistant 的一个示例应用。启动后，它会每隔 5 秒显示一句随机名言。

它展示了几项功能和结构，包括：

- 完整的 GitHub 仓库。
- 通用 Dockerfile 的结构和设置。
- `config.yaml` 和 `build.yaml` 文件的使用。
- 如何与服务一起使用 S6 覆盖层的通用结构。
- Bashio 的基本用法。
- 使用 GitHub Actions 进行持续集成和部署。
- 部署到 GitHub Container Registry。
- 我们在基础镜像中的 Bash 函数库的小部分使用。
- Docker 标签 schema 的使用。
