# Home Assistant App: Let's Encrypt

Let's Encrypt 是一家证书颁发机构，它通过一个旨在消除以往复杂的手动创建、验证、签名、安装和续订证书过程的自动化流程，为传输层安全性加密提供免费的 X.509 证书。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

设置 Let's Encrypt 允许您为您的网页和 Web 接口使用经过验证的证书。
它要求您拥有您请求证书的域名。

生成的证书可以在其他插件中使用。默认情况下，其他插件中证书的路径和文件将引用此插件生成的文件。
