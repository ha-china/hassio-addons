# Home Assistant 应用：Let's Encrypt

Let's Encrypt 是一个证书颁发机构，通过设计用于消除先前手动创建、验证、签名、安装和更新证书 plethora 的繁琐流程的自动化流程，为传输层安全（TLS）加密提供免费的 X.509 证书。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

设置 Let's Encrypt 允许您使用已验证的证书用于您的网页和网络界面。
您需要拥有您正在申请证书的域名所有权。

生成的证书可以在其他插件中使用。默认情况下，其他插件内证书的目录和文件将指代本插件生成的文件。
