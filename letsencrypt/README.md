# Home Assistant App: Letsencrypt

Let's Encrypt 是一个证书颁发机构，它通过设计用于消除安全网站证书的人工创建、验证、签名、安装和续期此前复杂过程，提供免费的 X.509 证书用于通过自动化过程传输层安全加密。

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

设置 Letsencrypt 允许您为您的页面和网络接口使用经过验证的证书。
您需要拥有您正在申请证书的域名。

生成的证书可在其他附加组件中使用。默认情况下，其他附加组件中的证书路径和文件将指向此附加组件中生成的文件。
