# Home Assistant App: 邮件过滤器

[![发布状态][release-shield]][release] ![项目阶段][project-stage-shield] ![维护状态][maintenance-shield]

Rspamd 邮件过滤器，可选 ClamAV 抗病毒...
请小心！ClamAV 会消耗大量内存！
不推荐在内存低于 6GB 的设备上使用。

## 关于

重要：此应用程序需要已安装 Mailserver 应用！

此应用程序为您的邮件服务器提供邮件过滤器。
