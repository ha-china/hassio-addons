# Home Assistant App: 邮件过滤器

[![发布状态][发布盾牌]][发布] ![项目阶段][项目阶段盾牌] ![维护状态][维护盾牌]

Rspamd 邮件过滤器，可选 ClamAV 抗病毒功能...
请注意！ClamAV 会消耗大量内存！
不推荐在内存小于 6GB 的设备上使用。

## 关于

重要：此应用需要安装邮件服务器应用！

此应用为您的邮件服务器提供邮件过滤器。
