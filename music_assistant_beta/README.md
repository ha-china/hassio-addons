# 音乐助手（BETA）应用程序

音乐助手官方BETA版本发布通道。

## ⚠️ 重要通知

这是音乐助手的BETA版本。它包含了一些新功能和改进，将在稳定版发布前进行测试。

**如果您符合以下条件，请使用此应用程序：**

- 希望提前访问新功能
- 愿意帮助测试和报告问题
- 能够容忍偶尔的故障或不稳定
- 想要为使音乐助手变得更好做出贡献

**如果您不符合以下条件，请不要使用此应用程序：**

- 需要始终稳定且可用于生产的系统
- 不愿意处理问题
- 无法承担音乐设置中的任何停机时间

## 什么是BETA？

BETA版本是功能完整但在成为稳定版本之前进行测试的版本。通常包括：

- ✨ 稳定版本中尚未包含的新功能
- 🔧 性能改进
- 🐛 以前版本中的错误修复
- 🧪 需要真实世界测试的变更

## 与稳定版的不同

| 方面    | 稳定版               | BETA                                  |
| ------- | -------------------- | ------------------------------------- |
| 稳定性  | 非常稳定            | 一般稳定，可能存在问题               |
| 功能    | 经过良好测试的功能   | 正在被测试的新功能                   |
| 更新    | 更新频率较低        | 更新频率较高                         |
| 用例    | 生产使用            | 测试和早期采用                      |

## 报告问题

作为BETA测试者，您的反馈非常宝贵！请报告您遇到的问题：

### 报告前的准备

1. 检查应用程序日志（如果需要，全局或按提供商级别启用`debug`日志）
2. 在[现有问题](https://github.com/music-assistant/support)中搜索
3. 如果可能，验证问题在稳定版本中是否存在

### 报告时包含以下内容：

- 📋 重新创建问题的步骤
- 📝 应用程序的全局日志（或从MA的Web界面下载完整日志文件）
- 🔢 音乐助手版本（在Web UI中可见）
- 🎵 您正在使用的音乐提供商
- 🔊 受影响的播放器

**报告位置**：[GitHub支持存储库](https://github.com/music-assistant/support)

## 更新

BETA版本比稳定版本更新更频繁。通常，每周更新一至两次。

## 已知限制和注意事项

- BETA版本可能包含破坏性变更
- 一些功能可能仅部分实现
- 之间可能发生数据库迁移
- 性能优化可能仍在进行中
- 您无法从稳定版本迁移（反之亦然）

提示：如果您想在保留稳定版本的同时测试BETA版本，只需停止稳定应用程序并运行BETA应用程序。然后，通过停止BETA应用程序并启动稳定版本来恢复到稳定版。两个应用程序不能同时激活。

## BETA测试最佳实践

1. **定期备份**：始终保持最新的备份
2. **监控日志**：关注日志中的问题
3. **报告问题**：通过报告错误帮助我们改进
4. **保持耐心**：一些功能可能不完美
5. **保持更新**：安装更新以获取最新的修复

在家庭助理中备份音乐助手应用程序也会包括您的音乐助手数据。请确保在更新到新版本之前始终进行备份，以便您始终可以轻松地回滚到上一个版本！

## 回滚策略

### 如果出现问题

1. **停止应用程序**
2. **从备份中恢复**（您做了备份，对吧？）
3. **报告问题**
