# 音乐助手（Beta）应用

音乐助手官方Beta发布通道。

## ⚠️ 重要通知

这是音乐助手的Beta版本。它包含了一些新功能和改进，这些将在稳定版发布前进行测试。

**如果你符合以下条件，请使用此应用：**

- 想要提前访问新功能
- 愿意帮助测试并报告问题
- 能够忍受偶尔的bug或不稳定性
- 想要为让音乐助手变得更好做出贡献

**请不要使用此应用，如果你：**

- 总是需要一个稳定的生产就绪系统
- 不擅长处理问题
- 不能容忍任何音乐设置的中断

## 什么是Beta版本？

Beta版本是功能完整且在成为稳定发布前进行测试的版本。通常包括以下内容：

- ✨ 尚未在稳定版本中出现的全新功能
- 🔧 性能改进
- 🐛 从先前的版本中修复的bug
- 🧪 需要进行现实世界测试的更改

## 与稳定版的不同

| 方面    | 稳定版             | Beta版                                       |
| ------- | ------------------ | -------------------------------------------- |
| 稳定性 | 非常稳定           | 一般稳定，可能存在问题                        |
| 功能    | 经过良好测试的功能  | 正在测试的新功能                             |
| 更新    | 更新频率较低        | 更新频率较高                                 |
| 用例    | 生产使用           | 测试与早期采用                              |

## 报告问题

作为Beta测试者，你的反馈非常有价值！请报告你遇到的问题：

### 报告前的准备

1. 检查应用日志（如果需要，请全局或按提供商级别启用`debug`日志）
2. 搜索[现有问题](https://github.com/music-assistant/support)
3. 如果可能，验证问题在稳定版本中是否存在

### 报告时包括以下内容：

- 📋 复现问题的步骤
- 📝 应用程序的全日志（或从MA的Web界面下载完整的日志文件）
- 🔢 音乐助手的版本（在Web UI中可见）
- 🎵 你正在使用的音乐提供商
- 🔊 受影响的播放器

**报告位置**：[GitHub支持仓库](https://github.com/music-assistant/support)

## 更新

Beta版本比稳定版本更新得更频繁。通常，每周更新一两次。

## 已知限制和说明

- Beta版本可能包含破坏性更改
- 一些功能可能仅部分实现
- 版本之间的数据库迁移可能会发生
- 性能优化可能仍在进行中
- 您不能从稳定版本迁移（反之亦然）

提示：如果您想在保持稳定版的同时测试Beta版本，只需停止稳定版应用并运行Beta版应用即可。要恢复到稳定版，只需再次停止Beta版应用并启动稳定版即可。两个应用不能同时运行。

## Beta测试最佳实践

1. **定期备份**：始终保持最近的备份
2. **监控日志**：留意日志中可能出现的问题
3. **报告问题**：帮助我们改进，报告bug
4. **耐心等待**：某些功能可能不完全正常
5. **保持更新**：安装更新以获取最新的修复

在家庭助理中备份音乐助手应用也会包含您的音乐助手数据。请确保在更新到新版本之前始终进行备份，这样您可以随时轻松地回滚到之前的版本！

## 回滚策略

1. **停止应用**
2. **从备份恢复**（您做了备份，对吧？）
3. **报告问题**
