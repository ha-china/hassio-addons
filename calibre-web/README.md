## 关于

[Calibre-Web][calibre-web] 是 Calibre 图书库的 Web 接口。只要指向存放您的书籍的文件夹，它就会将其变成一个您可以直接阅读的站点：包含封面艺术、搜索、作者和系列信息、为家庭中每个人分配的分书架，以及浏览器内的阅读器，支持 EPUB、PDF、漫画和有声书。

它不是 Calibre 本身，也不试图成为 Calibre。Calibre 依然是您用来管理书收集的程序；Calibre-Web 则是所有人（无论是从手机、平板还是电子阅读器访问）访问该书收集的方式，无需桌面应用程序的中介。

此应用还将 calibre 的转换工具一并自带，因此书籍可以转换为您手持设备能识别的任何格式，直接邮寄到 Kindle，或作为 kepub 格式交给 Kobo 设备。
