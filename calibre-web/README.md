## 关于

`Calibre-Web` 是 Calibre 图书库的 Web 界面。指向存放书籍的文件夹，即可将其转换为企业可以从阅读的网站：涵盖封面艺术、搜索、作者与系列列表、每位家庭成员的专属书架、以及浏览器中针对 EPUB、PDF、漫画和有声书的阅读器。

它并非 `Calibre` 本身，也没有试图取而代之。`Calibre` 仍然是用于管理图书集合的程序；`Calibre-Web` 则是让所有人都能访问该集合的方式，无论是通过手机、平板电脑还是电子书阅读器，无需额外桌面应用程序的介入。

此应用还带来了 `Calibre` 的转换工具，因此可以将书籍转换为手中设备能读取的任何格式，也可邮寄到 Kindle，或作为 kepub 交予 Kobo。
