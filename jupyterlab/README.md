## 简介

JupyterLab 是一个开源的 Web 应用程序，允许您创建和分享包含可运行代码、方程、可视化图表和叙述性文本的文档。其用途包括数据清洗与转换、数值模拟、统计建模、数据可视化、机器学习等。

该应用运行 JupyterLab，它是 Project Jupyter 下一代用户界面。它是基于 Jupyter Notebook 和架构设计的，用于支持交互式且可重复的计算的扩展环境。
