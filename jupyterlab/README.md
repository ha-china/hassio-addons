## 关于

JupyterLab 是一个开源的 Web 应用程序，允许您创建和分享包含现场代码、公式、可视化和叙事文本的文档。用途包括：数据清洗与转换、数值仿真、统计分析建模、数据可视化、机器学习等。

此应用运行 JupyterLab，这是 Project Jupyter 的下一代用户界面。它是一个可扩展的交互式和可重现计算环境，基于 Jupyter Notebook 和架构。
