## 介绍

JupyterLab 是一个开源网络应用程序，允许您创建和分享包含实时代码、公式、图表和叙事文本的文档。其用途包括：数据清理与转换、数值模拟、统计建模、数据可视化、机器学习等。

此应用运行 JupyterLab，它是 Project Jupyter 的下一代用户界面。它是一个可扩展环境，用于交互式计算和可复现的计算，基于 Jupyter Notebook 架构。
