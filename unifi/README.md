UniFi 网络应用允许您通过网页浏览器管理您的 UniFi 网络。

## 重要通知

**独立的 UniFi 网络应用即将停止维护。**
Ubiquiti 正在过渡到 UniFi OS 服务器，这意味着它不会转换为 Docker/Home Assistant 应用。从该应用到 UniFi OS 服务器的升级路径不存在。只要 Ubiquiti 继续提供独立的应用程序，此应用将继续工作，但计划长期使用的用户应考虑迁移到专用机器或虚拟机。

## 关于

此应用运行 Ubiquiti Networks 的 UniFi 网络应用软件，允许您通过网页浏览器管理您的 UniFi 网络。该应用为 Home Assistant 提供了一键安装和运行解决方案，使用户能够轻松地将网络启动、运行并更新。

此应用支持所有 Home Assistant 支持的架构，包括 Raspberry Pi。
