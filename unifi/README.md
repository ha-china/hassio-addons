UniFi 网络应用程序允许您使用网络浏览器管理 UniFi 网络。

## 重要通知

**独立的 UniFi 网络应用程序已接近生命末期。**
Ubiquiti 正在转向 UniFi OS Server，该服务器并不对应于 Docker/Home Assistant 应用程序。从本应用程序升级到 UniFi OS Server 没有路径。只要 Ubiquiti 继续提供独立应用程序，本应用程序将继续工作，但计划长期使用的用户应考虑迁移到专用机器或虚拟机。

## 关于

本应用程序运行 Ubiquiti Networks 的 UniFi 网络应用程序软件，允许您通过网络浏览器管理 UniFi 网络。该应用程序为 Home Assistant 提供了单点点击安装和运行解决方案，使用户能够轻松地将网络启动、运行并更新。

本应用程序支持所有 Home Assistant 支持的架构，包括 Raspberry Pi。
