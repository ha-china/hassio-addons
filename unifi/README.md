UniFi 网络应用允许您通过浏览器管理您的 UniFi 网络。

## 重要通知

**独立版 UniFi 网络应用即将进入生命周期结束阶段。**
Ubiquiti 正在转向 UniFi OS Server，这并不对应于 Docker/Home Assistant 应用。从本应用升级到 UniFi OS Server 没有路径。只要 Ubiquiti 继续发布独立应用，此应用将继续工作，但计划长期使用的用户应考虑迁移到专用机器或虚拟机。

## 关于

此应用运行 Ubiquiti Networks 的 UniFi 网络应用软件，让您可通过浏览器管理您的 UniFi 网络。该应用为 Home Assistant 提供了单点击安装和运行解决方案，使用户可以轻松地启动、运行并更新其网络。

此应用支持所有 Home Assistant 支持的架构，包括 Raspberry Pi。
