UniFi 网络应用允许您通过 webb 浏览器管理您的 UniFi 网络。

## 重要通知

**独立的 UniFi 网络应用即将停止维护。**
Ubiquiti 正在过渡到 UniFi OS Server，但这并不意味着存在 Docker/Home Assistant 应用程序。从本应用升级到 UniFi OS Server 没有路径。只要 Ubiquiti 继续提供独立应用程序，该应用将持续工作，但计划长期使用的用户应该考虑迁移到专用机器或虚拟机。

## 关于

此应用运行的是 Ubiquiti Networks 的 UniFi 网络应用软件，允许您通过网页浏览器管理您的 UniFi 网络。该应用为 Home Assistant 提供单击安装和运行解决方案，使用户能够轻松地将网络上线、运行和更新。

此应用支持所有 Home Assistant 支持的架构，包括 Raspberry Pi。
