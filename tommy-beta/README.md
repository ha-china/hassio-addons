# TOMMY Zero (beta)

这是 Home Assistant 附加组件 TOMMY Zero 的 beta 版本（早期测试用的预发布构建，仅限受邀用户）。TOMMY Zero 是一项 Wi-Fi 感应系统，可将 ESP32 设备转化为能够检测穿墙和障碍物移动的位置传感器。

该附加组件将 TOMMY Zero 直接集成到您的 Home Assistant 实例中，允许您为现有自动化创建区域。所有处理均在您的网络上本地完成。

**开始使用：** [安装指南](https://www.tommysense.com/docs/installation/homeassistant)  
**了解更多：** [完整文档](https://www.tommysense.com/docs)
