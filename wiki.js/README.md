## 📖 关于

## 🏁 首次启动

在首次启动时，您将看到一个管理设置向导。向导将引导您完成 Wiki 连接的初始配置以及管理员账户的创建。

请在此过程中创建您的 **管理员账户**（邮箱 / 密码）。

---

## ⚙️ 配置

通过 Home Assistant App 页面中的 **配置** 选项卡配置此应用。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
reset_database: false
reset_database_confirm: false
ssl: true
```
