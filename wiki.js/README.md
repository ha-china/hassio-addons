## 📖 简介

## 🏁 首次启动

首次启动时，您将遇到一个管理设置向导。该向导将引导您完成 Wiki 连接的初始配置以及管理员账户的创建。

在此过程中，请创建您的 **管理员账户**（电子邮箱/密码）。

---

## ⚙️ 配置

请在 Home Assistant 应用页面中的 "**配置**" 标签页中配置该应用。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
reset_database: false
reset_database_confirm: false
ssl: true
```
