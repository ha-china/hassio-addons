## 🏁 首次启动

在首次启动时，你会看到一个管理设置向导。向导将引导你完成 Wiki 连接的初始配置以及创建你的管理员账户。

在此过程中，请创建你自己的 **管理员账户**（邮箱 / 密码）。

## ⚙️ 配置

通过 Home Assistant 插件页面中的 **配置** 选项卡配置插件。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
reset_database: false
reset_database_confirm: false
ssl: true
```
