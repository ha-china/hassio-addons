## 🏁 首次启动

首次启动时，系统将提示您执行管理员设置向导。该向导将引导您完成 Wiki 连接的初始配置以及管理员账户的创建。

在此过程中，请务必创建自己的 **管理员账户**（邮箱/密码）。

---

## ⚙️ 配置

通过在 Home Assistant App 页面的 **配置 (Configuration)** 选项卡中配置此应用程序。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
reset_database: false
reset_database_confirm: false
ssl: true
```
