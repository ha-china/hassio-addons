通过简单、强大的界面轻松管理 Nginx 代理主机。

## 简介

此应用让您无需过多了解 Nginx 或 Let's Encrypt，即可轻松将传入的连接转发到任何地方，包括免费 SSL。

通过界面简单的强大功能，直接将您的域名转发到家庭内部或您所在地运行的 Home Assistant、应用程序或网站。

想要为您的网站添加用户名/密码保护吗？这也是可能的！启用认证并创建一组可访问特定应用程序的用户名/密码列表。

对于高级用户，您可以通过提供额外的 Nginx 指令，自定义 Nginx 代理管理器中每个主机的行为。
