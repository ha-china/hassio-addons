使用简单有力的界面管理 Nginx 代理主机。

## 关于

此应用使您能够轻松将传入连接转发到任何位置，包括免费 SSL，而无需深入了解 Nginx 或 Let's Encrypt。

直接将您的域名转发到运行在家庭或任何地方的 Home Assistant、应用程序或网站，仅需一个简单的强大界面。

想用用户名/密码保护网站吗？没问题！它可以做到！启用认证并创建可访问该特定应用程序的用户名/密码列表。

对于高级用户，您可以通过提供额外的 Nginx 指令来自定义 Nginx 代理管理器中每个主机的行为。
