## 📖 关于

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

> 自托管、注重隐私的 PDF 工具包

> [!CAUTION]
> **实验性/测试版状态**
>
> 此插件仍在开发中且主要针对个人使用。
> 它尚未经过广泛测试，但预计基本功能可以正常工作。

BentoPDF 是一个全面的 PDF 工具包，完全在您的浏览器中运行。它允许您合并、分割、压缩和转换 PDF 文件，而无需将您的文件上传到服务器，确保您的数据保持私密。

## ⚙️ 配置

通过 Home Assistant 插件页面中的 **配置** 选项卡配置插件。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
ssl: false
```
