# Home Assistant App: 语音转短语

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

这是一个快速且本地的语音转文本系统，已根据您的家中物品名称进行个性化定制。
[Speech-to-phrase](https://github.com/OHF-voice/speech-to-phrase) 针对的是较低配置的硬件（如 Raspberry Pi 4 和 Home Assistant Green）。

有关可用的语音命令，请参阅 [文档](http://github.com/OHF-voice/speech-to-phrase)。

基于 [Year of Voice](https://www.home-assistant.io/blog/2022/12/20/year-of-voice/) 构建。

需要 Home Assistant 2023.11 或更高版本。
