# HA China 系统状态监控

实时监控 Home Assistant 系统健康状态和 HA China 服务运行状态。

## 功能概览

### 🖥️ 系统健康度
- **健康评分** - 综合评估 CPU、内存、磁盘使用情况，给出 0-100 分的健康评分
- **系统资源** - 实时查看 CPU、内存、磁盘使用率和运行时间
- **连接状态** - 显示 Home Assistant Core 连接状态和响应时间
- **统计数据** - 实体数量、区域数量、场景数量等统计信息

### 📦 组件状态
实时监控以下组件的运行状态和版本信息：
- **Supervisor** - Home Assistant 管理器
- **Core** - Home Assistant 核心
- **CLI** - 命令行界面
- **DNS** - DNS 服务器
- **Multicast** - 多播网络服务
- **Observer** - 系统观察者
- **Audio** - 音频服务

### 💻 主机信息
- 主机名、操作系统、内核版本
- 系统架构、时区、虚拟化类型
- 磁盘容量和使用情况

### 📊 性能详情
- CPU 核心数和频率
- 内存详细信息
- 网络流量统计
- 系统运行时间

### 🔔 远程服务监控
- 自动监控 HA China 相关服务状态
- 服务异常时自动发送通知到 Home Assistant
- 服务恢复时发送恢复通知

## Web 界面

安装启动后，通过 `http://[HA地址]:8099` 访问 Web 界面。

界面包含四个标签页：
1. **系统健康度** - 健康评分和系统资源概览
2. **组件状态** - 各组件运行状态卡片
3. **主机信息** - 主机详细信息和磁盘状态
4. **性能详情** - CPU、内存、网络详细数据

页面每 30 秒自动刷新数据。

## 配置选项

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `notify` | 布尔 | `true` | 是否在服务状态变化时发送通知 |
| `interval` | 整数 | `300` | 远程服务检查间隔（秒） |

## 使用场景

### 日常监控
- 随时查看系统健康状态，了解资源使用情况
- 检查各组件是否正常运行
- 查看系统运行时间和性能数据

### 故障排查
- 当系统运行缓慢时，查看 CPU、内存使用率
- 检查各组件状态，快速定位问题
- 查看磁盘空间，避免存储不足

### 服务状态通知
- 自动接收 HA China 服务异常告警
- 服务恢复时自动通知
- 了解服务影响范围
