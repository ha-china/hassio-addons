## 功能概览

### 🖥️ 系统健康度
- **健康评分** - 基于基础资源、系统服务、维护状态三大维度给出 0-100 分的健康评分
- **系统资源** - 实时查看 CPU、内存、磁盘使用率和运行时间
- **连接状态** - 显示 Home Assistant Core 连接状态和响应时间
- **优化建议** - 根据当前系统状态给出可操作的维护建议
- **统计数据** - 实体数量、区域数量、场景数量等统计信息

### 📦 组件状态
实时监控以下组件的运行状态和版本信息：
- **Supervisor** - Home Assistant 管理器
- **Core** - Home Assistant 核心
- **CLI** - 命令行界面
- **DNS** - DNS 服务器
- **Multicast** - 多播网络服务
- **Observer** - 系统观察者
- **Audio** - 音频服务
- **详情弹窗** - 支持通过页面内弹窗查看组件配置和统计信息

### 💻 主机信息
- 主机名、操作系统、内核版本
- 系统架构、时区、虚拟化类型、部署环境
- 启动时间、时间同步、LLMNR 主机名
- 磁盘容量、使用率和可用空间

### 🌐 网络信息
- Docker 网络地址、网关、DNS 和接口名称
- 主网卡 IPv4 / IPv6 地址、子网和网关
- 自动兼容 CIDR 地址格式下的子网显示

### 📊 性能详情
- CPU 核心数和频率
- 内存详细信息
- 网络流量统计
- 系统运行时间

### 🔔 远程服务监控
- 自动监控 HA China 相关服务状态
- 服务异常时自动发送通知到 Home Assistant
- 服务恢复时发送恢复通知

## Web 界面

安装启动后，通过 `http://[HA地址]:8099` 访问 Web 界面。

界面包含多个系统信息标签页：
1. **系统健康度** - 健康评分、分项得分和优化建议
2. **组件状态** - 各组件运行状态卡片和详情弹窗
3. **主机信息** - 主机详细信息、部署环境、时间同步和磁盘状态
4. **网络信息** - Docker 网络和主网卡详细信息
5. **Supervisor / Core / 性能详情** - 系统版本、运行状态和资源明细

页面每 30 秒自动刷新数据。

## 配置选项

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `notify` | 布尔 | `true` | 是否在服务状态变化时发送通知 |
| `interval` | 整数 | `300` | 远程服务检查间隔（秒） |

## 使用场景

### 日常监控
- 随时查看系统健康状态，了解资源使用情况
- 检查各组件是否正常运行
- 查看系统运行时间、网络状态和性能数据

### 故障排查
- 当系统运行缓慢时，查看 CPU、内存使用率
- 检查各组件状态，快速定位问题
- 查看磁盘空间、时间同步和网络配置，避免隐性运行问题

### 服务状态通知
- 自动接收 HA China 服务异常告警
- 服务恢复时自动通知
- 了解服务影响范围

## 注意事项

- 需要在 Home Assistant OS 环境中运行
- 需要启用 `homeassistant_api` 和 `hassio_api` 权限
- 通知功能需要 Home Assistant 的持久通知服务支持
