# Home Assistant App: Silicon Labs Flasher App

Silicon Labs Flasher 应用程序（之前称为附加组件）用于烧录基于 Silicon Labs 的无线电。

默认情况下，此应用程序会将固件烧录为使用 Zigbee（Silicon Labs EmberZNet Zigbee 堆栈）。

**注意：** 确保没有其他应用程序或集成正在使用该无线电。特别是，请禁用 Zigbee Home Automation 集成和 Silicon Labs Multiprotocol 应用程序。

![支持 aarch64 架构][aarch64-shield]
![支持 amd64 架构][amd64-shield]

## 关于

此应用程序允许您使用 Gecko Bootloader 文件格式（gbl）烧录固件。默认情况下，它附带用于烧录 Zigbee 的 Home Assistant SkyConnect/ZBT-1 和 Home Assistant Yellow 的固件。
