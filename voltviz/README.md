# Home Assistant App: VoltViz

一个动态的实时音乐可视化工具，将声音转化为惊艳的视觉体验。与您系统音频、麦克风以及 [Music Assistant](https://music-assistant.io/) 同步（通过 [Sendspin](https://www.sendspin-audio.com/)），让您的音乐栩栩如生。

![VoltViz](https://raw.githubusercontent.com/sanderdw/voltviz/main/images/home-assistant/music-assistant.png)

## 特性

- 50+ 种惊艳的可视化风格（粒子效果、3D、复古、音乐节等）
- 支持节拍感知的音频引擎，可选设备端 AI 节拍跟踪、自动增益调节及音乐风格设置
- 实时音频输入来源：麦克风、系统音频或 Sendspin 流媒体
- 使用 Three.js 和 WebGL 实现 GPU 加速渲染
- 通过 Sendspin 集成 Music Assistant
- 支持通过 URL 参数的深链功能查看可视化和设置
