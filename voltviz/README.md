# Home Assistant App: VoltViz

这是一个动态的实时音乐可视化器，将声音转化为令人惊叹的视觉体验。与您系统的音频、麦克风以及 [Music Assistant](https://music-assistant.io/) 和 [Sendspin](https://www.sendspin-audio.com/) 进行同步，观察您的音乐焕发生机。

![VoltViz](https://raw.githubusercontent.com/sanderdw/voltviz/main/images/home-assistant/music-assistant.png)

## 功能特点

- 超过 50 种令人惊叹的可视化风格（粒子效果、3D、复古、音乐节风格等）
- 具备节拍感知音频引擎，可选支持设备上的 AI 节拍追踪、自动增益调整，以及音乐风格设置功能
- 支持来自麦克风、系统音频或 Sendspin 流媒体的实时音频输入
- 使用 Three.js 和 WebGL 实现 GPU 加速渲染
- 通过 Sendspin 集成 Music Assistant
- 支持视觉化器及设置参数的 URL 参数深链接
