# 智能家居部署向导

> ⚠️ **开发阶段声明**：本项目目前仍在积极开发中，部分功能尚未完善。欢迎落地商联系我免费激活体验，但请知悉当前版本可能存在功能缺失或变更，不建议直接用于生产环境。

面向落地商的 HA 部署效率工具，向导式界面将全套智能家居系统部署时间从数天缩短到几小时。

## 功能

| 功能 | 解决了什么问题 |
|------|---------------|
| **标准化部署流程** | 新手不知道 HA 怎么落地，按步骤走不会遗漏；熟练人员可跳过或通过菜单直接使用所需功能 |
| **楼层与区域管理** | 手动建楼层区域太慢，内置 6 套经典户型模板一键套用，可视化管理 |
| **加载项与集成** | 每次去 GitHub 翻 release、下载、拷目录、配权限太麻烦，一键安装+云端同步 |
| **设备发现与管理** | 局域网设备手动添加逐个搜索太慢，自动扫描批量管理 |
| **语音助手配置** | 哪些设备能语音控制得逐个去翻设置，批量管理语音暴露状态 |
| **场景与自动化** | 编写 YAML 自动化门槛高，图形化创建无需写代码 |
| **仪表盘配置** | 手工编辑 Lovelace 配置繁琐，可视化定制实时预览 |
| **远程访问** | 端口映射方案不符合中国法律，与持证合规服务商合作，无需公网 IP 或自建服务器 |
| **全量备份与还原** | 主机彻底损坏也不用重新部署，新设备一键还原 |
| **设备授权管理** | 每台设备独立授权，防止未授权使用，远程检测设备状态 |
