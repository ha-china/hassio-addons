## 简介

该应用允许您编写配置，无需编程经验即可将微控制器直接转换为通过 Home Assistant 控制的智能家居设备。您只需编写 YAML 配置文件；其余（空中固件更新、编译）均由 ESPHome 处理。

</p>

<img title="ESPHome DHT 配置示例" src="https://github.com/esphome/home-assistant-addon/raw/main/esphome-beta/images/dht-example.png" width="500px"></img>

然后只需点击上传，该传感器就会神奇地在 Home Assistant 中出现：
