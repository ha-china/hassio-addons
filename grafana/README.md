## 关于介绍

您所有指标的量化分析平台。

无论指标存储在哪里，Grafana 都让您能够查询、可视化、设置警报并理解指标。创建、探索和分享仪表板。利用性感且引人注目的图表和其他数据可视化技术，了解您的智能家居自动化系统。

将此应用与 InfluxDB 应用结合使用，可获得令人难以置信的家居洞察。
