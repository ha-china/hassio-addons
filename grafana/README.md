## 关于

适用于所有指标的可视分析平台。

Grafana 允许您无论数据存储在何处，都可以查询、可视化、告警并理解您的关键指标。创建、探索和分享仪表盘。使用性感而引人入胜的图表和其他数据可视化功能来了解您的家庭自动化系统。

将该应用与 InfluxDB 应用结合使用，可以将对您家居的见解发挥到极致。
