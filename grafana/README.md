## 关于

适用于您所有指标的指标分析平台。

Grafana 允许您无论指标存储在哪里，都能够进行查询、可视化、告警并理解您的指标。创建、探索和共享仪表盘。使用性感且引人入胜的图表及其他数据可视化技术了解您的家庭自动化系统。

将此应用与 InfluxDB 应用结合使用，可为您家的情况获得极其强大的洞察。
