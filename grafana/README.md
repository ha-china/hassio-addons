## 简介

所有指标的分析平台。

Grafana 允许您查询、可视化、监控并理解您的指标，无论它们存储在哪里。您可以创建、探索和共享仪表盘。使用酷炫且引人入胜的图表和其他数据可视化功能，了解您的家庭自动化系统情况。

将此应用与 InfluxDB 应用结合使用，即可获得您家庭无与伦比的洞察力。
