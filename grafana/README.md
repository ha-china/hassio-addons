用于美观分析及监控的开源平台。

## 概况

您所有指标的分析平台。

Grafana 允许您查询、可视化、警报并理解您的指标，无论它们存储在哪里何地。创建、探索和共享仪表盘。利用酷炫且具有吸引力的图表和其他数据可视化功能，了解您的家庭自动化系统的情况。

将此应用与 InfluxDB 应用结合，让您洞悉您家庭中的惊人功能。
