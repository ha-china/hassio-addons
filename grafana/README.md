数据分析与监控的开源平台。

## 关于

适用于所有指标的通用分析平台。

Grafana 允许您查询、可视化、警报并理解存储在任何地方的指标。
创建、探索和共享仪表板。使用吸引人的图表和其他数据可视化来了解您的家庭自动化系统。

将此插件与 InfluxDB 插件结合使用，以获取对您家庭的无与伦比的有力洞察。
