## 简介

[Stirling PDF][stirling-pdf] 是一个用于处理落入你收件箱中并非完全符合你期望的 PDF 的工作坊。它可以合并、拆分、旋转、裁剪和重新排列页面。压缩过大无法发送的扫描件。将 Word 文档、电子表格、网页或一组照片转换为 PDF，也可以将 PDF 转换回原始格式。你可以对它进行电子签名、添加印章、增加水印、填写表单，或者黑掉本不该出现的内容。

它还具备OCR（光学字符识别）功能。一次 OCR 扫描可以将扫描页面上的文字图片转换为可搜索、可选择和可复制的文本，这正是扫描件档案与真正归档之间的区别。

所有内容都不离家门。文件上传到此应用中，在此处进行处理，然后返回给用户，这正是在自己的电脑上运行它而不是将银行账单粘贴到免费网站上的主要原因。
