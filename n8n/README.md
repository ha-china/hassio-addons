## ⚙️ 配置

通过 Home Assistant App 页面中的 **配置** 选项卡配置此应用。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
listen_address: 0.0.0.0
log_level: info
port: 5678
ssl: false
```
