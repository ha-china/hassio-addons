## 关于

[n8n][n8n] 是一个面向技术人员的的工作流自动化平台：它是一个可视编辑器，您可以在其中将数百个服务连接起来，从 HTTP 请求、Webhooks 和定时任务到数据库、聊天平台和 AI 模型，中间穿插一些 JavaScript 代码。

该应用程序在 Home Assistant 内部运行 n8n，并在侧边栏提供一个面板。当您打开它时，此 Home Assistant 安装所需的凭据已就位，无需生成访问令牌；如果您的 MQTT 代理和 MariaDB 数据库也已配置，相关的凭据也已准备好。Home Assistant 自动化任务将通过内部网络启动工作流；发布其端口和 Webhooks，从任何位置均可访问。
