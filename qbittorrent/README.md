## 简介

[qBittorrent][qbittorrent] 是一个 BitTorrent 客户端，它尽职尽责，无需任何回报。没有广告、没有捆绑的软件组件、无需创建账户。它是人们在选择具有大型客户端功能但希望避免其他客户端缺点时转向的开源客户端。

此应用运行的是无头（headless）版本，因此您获得的是 Web 界面。它处理长寿命客户端所需的一切：带有限制的队列、决定文件存放位置的分类和标签、能够自动下载新剧集的 RSS 阅读器，以及为避免与房屋中其他流量竞争而进行的调度，还有一个完整的 API 用于其他所有功能。

下载的文件保存在 `media` 文件夹中，这使它们能够被 Home Assistant 的媒体浏览器以及将其映射的其他应用访问。Home Assistant 还对 qBittorrent 提供了 [集成][integration]，因此速度和托实体数可以像其他所有内容一样显示在您的仪表板上。
