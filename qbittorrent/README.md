## 概览

[qBittorrent][qbittorrent] 是一个 BitTorrent 客户端，它工作出色但不需要任何回报。无广告，无捆绑的额外功能，无需注册：它是人们选择迁移至获得大型软件功能且无多余功能时所用的开源客户端。

该应用程序运行的是无头构建版本，因此您获得的是 Web 界面。它处理长时间运行的客户端所需的一切内容：带限制条件的队列、决定文件存放位置的类别和标签标签、能够自行下载新剧集的 RSS 源、以便上传不会与家中其他设备争夺带宽的调度功能，以及适用于任何其他功能的全功能 API。

下载的文件将存放在 `media` 文件夹中，这使其处于 Home Assistant 媒体浏览器的范围内以及映射该文件夹的其他应用程序的范围内。Home Assistant [还集成了 qBittorrent][integration]，因此速度和数据集数量可以将您的仪表板上的显示与任何其他内容并列显示。
