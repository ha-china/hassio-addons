## 关于

[qBittorrent][qbittorrent] 是一个无需任何条件就能胜任工作的 BitTorrent 客户端。没有广告，没有捆绑的额外功能，也没有账户：它是人们追求大型客户端功能但拒绝其他所有附加条件的开源选择。

本应用运行的是无头（headless）版本，因此你得到的是 Web 界面。它处理了长运行客户端所需的一切：有限的加载队列、决定文件存放位置的分类和标签、自动下载新集数的 RSS 源、防止上传争夺家庭宽带带宽的调度功能，以及任何其他操作的完整 API。

下载的文件会落在 `media` 文件中，使其处于 Home Assistant 媒体浏览器的范围内，也处于其他映射到此文件浏览器的应用的范围内。Home Assistant 也有 [qBittorrent 的集成][integration]，因此速度和 Torrent 数量可以放在你的仪表盘上，与仪表盘上的其他内容相邻。
