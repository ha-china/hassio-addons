## 关于

[qBittorrent][qbittorrent] 是一款开源的 BitTorrent 客户端，它能完成任务却不索取任何回报。没有广告，没有捆绑组件，无需账户：当人们希望获得大客户端的功能却又讨厌其中多余的附加项时，他们会转向这款客户端。

这款应用运行无头构建版本，因此你获得的是 Web 界面。它处理了长运行时客户端所需的一切功能：带有队列限制的功能分类、决定文件存放位置的类别和标签、能够自动下载新剧集的 RSS 源流、分配带宽以防止上传占用家中其他设备流量的调度功能，以及一个完整的 API 用于其他任何操作。

下载的文件将存储在 `media` 文件夹中，这使得它们可被 Home Assistant 的媒体浏览器访问，以及所有映射到此文件夹的其他应用。Home Assistant 还提供了 [qBittorrent 集成][integration]，因此传输速度和种子数量可以像其他数据一样显示在你的仪表板上。
