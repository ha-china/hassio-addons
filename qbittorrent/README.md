## 关于

[qBittorrent][qbittorrent] 是一个默默无闻但不求回报的 BitTorrent 客户端。没有广告，没有捆绑的额外功能，没有账号：它是那些想要主流功能且无需其他负担的用户所选择的开源客户端。

该应用运行的是无头构建版本，因此您得到的是网页界面。它处理长运行客户端所需的事项：带有限制的队列、决定文件落点的分类和标签标签、会自动下载新剧集的 RSS 源、避免上传占用家中其余带宽的调度功能，以及全方位 API 来满足其他一切需求。

下载的文件存储在 `media` 目录中，这样它们就进入了 Home Assistant 媒体浏览器的接触范围，以及其他映射该目录的其他应用的范围。Home Assistant 也有 [qBittorrent 的集成][integration]，因此速度和 torrent 计数可以放在你的仪表盘上，与任何其他信息并列。
