## 关于

[qBittorrent][qbittorrent] 是一个无需付出任何回报就能完成工作的 BitTorrent 客户端。没有广告，没有捆绑的额外功能，也没有账户：它是人们想要的强大功能且不想用其他产品时被转向的开源客户端。

此应用运行无头构建版本，因此您得到的是 Web 界面。它处理长期运行客户端所需的一切：带有权限限制的队列、决定文件存放位置的类别和标签、自动下载新剧集的 RSS 源、以避免与家庭其他设备争夺带宽而进行调度的上传计划，以及用于任何其他功能的完整 API。

下载的文件会落在 `media` 文件夹中，以便 Home Assistant 的媒体浏览器和其他映射它的应用程序能够访问它们。Home Assistant 也有 [qBittorrent 集成][integration]，因此速度和 Torrent 计数都可以放在您的仪表板上，与所有内容并列。
