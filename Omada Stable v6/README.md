# Home Assistant Omada Add-On v6

这个插件将 Omada Controller v6 直接集成到在 ARM、x64 或 x86 处理器上运行的 Home Assistant 中。
由于新的 MongoDB 版本与 Raspberry Pi 4 的指令集不兼容，版本 6 不再适用于 Raspberry Pi 4。

## 贡献

这个插件是 Matt Bentley 的
[docker-omada-controller](https://github.com/mbentley/docker-omada-controller)
的分支，如果没有他们出色的工作，jkunczik 的 [home-assistant-omada](https://github.com/jkunczik/home-assistant-omada)
将不可能实现。
除了原始的 docker Omada Controller 之外，这个插件将所有持久数据存储在 /data 目录中，
以便与 Home Assistant 兼容。
如果没有其他人的努力，这个插件将不可能实现。
欢迎提交版本更新或新功能的拉取请求。
特别感谢 DraTrav 推动了这个插件的发展！
