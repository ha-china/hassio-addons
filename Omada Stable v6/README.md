# Home Assistant Omada 添加组件 v6

此添加组件将 Omada Controller v6 直接引入到运行于 ARM、x64 或 x86 处理器的 Home Assistant 中。
由于新的 Mongo DB 版本与该指令集不兼容，版本 6 不再适用于 Raspberry Pi 4。

## 贡献

此添加组件最初灵感来源于 Matt Bentley 的
[docker-omada-controller](https://github.com/mbentley/docker-omada-controller)，
也得益于 jkunczik 的优秀工作 [home-assistant-omada](https://github.com/jkunczik/home-assistant-omada)，没有他们的努力，这项功能将无法实现。
除了原始 docker omada controller 之外，
此添加组件将所有持久化数据存储于 /data 目录中，
使其与 Home Assistant 兼容。
没有其他人的付出，此添加组件将无从谈起。
欢迎随时提交版本更新或新功能的 Pull requests。
特别感谢 DraTrav 推动此添加组件的进展！
