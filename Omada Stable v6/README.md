# Home Assistant Omada 插件 v6

该插件将 Omada Controller v6 直接集成到运行于 ARM、x64 或 x86 处理器的 Home Assistant 中。
由于新版本的 Mongo DB 与该架构不兼容，第 6 版在 Raspberry Pi 4 上已无法运行。

## 贡献

本插件最初受 Matt Bentley 的 [docker-omada-controller](https://github.com/mbentley/docker-omada-controller) 启发。
如果没有 jkunczik 的 [home-assistant-omada](https://github.com/jkunczik/home-assistant-omada) 出色的贡献，便不会有本插件。
除了原始 docker omada controller 之外，
本插件将所有持久化数据存储于 /data 目录，
因此可与 Home Assistant 兼容。
在他人努力下，本插件得以实现。
随时欢迎提交版本更新或新功能的需求。（Pull requests）
特别感谢 DraTrav 将此插件推向前进！
