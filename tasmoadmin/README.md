## 关于

TasmoAdmin（以前称为 SonWEB）是一个管理您所有已刷写 Sonoff-Tasmota 设备的中央管理网页界面。其部分功能包括：

- 扫描您的网络并自动添加您的设备
- 快速轻松地查看所有设备的状态
- 从单一位置配置所有设备
- 一次性通过无线向一个或多个设备发送固件更新
- 可自动为您下载最新固件
