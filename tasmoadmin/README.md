## 简介

TasmoAdmin（原名 SonWEB）是一个用于集中管理所有刷写 Sonoff-Tasmota 固件设备的管理网页界面。其功能包括：

- 扫描您的网络并自动添加设备
- 快速方便地查看所有设备状态
- 在一个地方配置所有设备
- 一次性向一个或多个设备发送空中固件更新
- 自动为您下载最新固件
