## 关于

Tailscale 是一款零配置 VPN，可以在几分钟内安装到任何设备上，包括您的 Home Assistant 实例。

在您的服务器、计算机和云端实例之间创建一个安全网络。即使被防火墙或子网分隔，Tailscale 也能正常工作。Tailscale 会为您管理防火墙规则，并可在任何地方使用。
