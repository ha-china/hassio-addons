# 官方 Home Assistant 插件：OpenBao

OpenBao (<https://www.openbao.org/>) 作为 Home Assistant 插件捆绑。

## 关于

OpenBao 是一个基于身份的密钥管理和加密系统。秘密是指您想要严格控制访问的任何内容，例如 API 加密密钥、密码和证书。OpenBao 提供加密服务，这些服务由身份验证和授权方法控制。

## 最后说明

有关如何配置此插件的信息，请参阅插件页面中的 [文档](DOCS.md)

此项目与 OpenBao 无关，只是一个社区努力。
OpenBao 本身采用 MPL-2.0 许可证分发。
