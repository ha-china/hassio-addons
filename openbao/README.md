# 官方 Home Assistant 软件包：OpenBao

OpenBao（https://www.openbao.org/）作为 Home Assistant 软件包整合。

## 关于 OpenBao

OpenBao 是一种基于身份的安全密钥和加密管理系统。任何需要严格控制访问权限的内容（例如 API 加密密钥、密码和证书）都可以作为“秘密”进行管理。OpenBao 提供由认证和授权方法控制的加密服务。

## 最后说明

有关如何配置此软件的说明，请参阅该软件内 [文档](DOCS.md) 页面。

本项目与 OpenBao 无关，仅是社区的努力。OpenBao 本身按 MPL-2.0 许可证分发。
