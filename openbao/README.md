# 非官方 Home Assistant 附加组件：OpenBao

OpenBao (https://www.openbao.org/) 已打包为 Home Assistant 附加组件。

## 关于

OpenBao 是一个基于身份的秘密管理和加密系统。秘密是任何您希望严格控制访问权限的东西，例如 API 加密密钥、密码和证书。OpenBao 提供通过身份验证和授权方法控制的加密服务。

## 最后说明

有关如何配置此附加组件的信息，请参考附加组件页面内的 [文档](DOCS.md)。

该项目与 OpenBao 没有任何关联，仅仅是一个社区努力。OpenBao 本身按照 MPL-2.0 许可证分发。
