# Home assistant 附加组件：Tubesync

这只是一个测试，不确定是否可行。

TubeSync 是针对 YouTube 的 PVR（个人视频录像）。或者，就像 Sonarr 但是针对 YouTube（带有内置的下载客户端）。它旨在将频道和播放列表从 YouTube 同步到本地目录，并在下载媒体后更新您的媒体服务器。

https://github.com/meeb/tubesync

## 安装

此附加组件的安装非常直接，与安装任何其他的 Hass.io 附加组件没有区别。

1. [将我的 Hass.io 附加组件库][repository] 添加到您的 Hass.io 实例中。
1. 安装此附加组件。
1. 在目录 `/config/addon_config/tubesync` 中存储您的配置文件。
1. 启动附加组件。
1. 检查附加组件的日志，查看是否一切正常。
1. 打开 Web 界面 homeassistant:4848


[repository]: https://github.com/jdeath/homeassistant-addons
