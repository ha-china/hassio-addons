# Home assistant 插件：Tubesync

这只是一个测试，不确定是否有效。

TubeSync 是针对 YouTube 的 PVR（个人视频录制器）。或者，就像 Sonarr 但针对 YouTube（带有内置下载客户端）。它的设计是为了将 YouTube 的频道和播放列表同步到本地目录，并在下载媒体后更新您的媒体服务器。

https://github.com/meeb/tubesync

## 安装

此插件的安装非常简单，与其他 Hass.io 插件的安装相比没有不同。

1. 将 [我的 Hass.io 插件仓库][repository] 添加到您的 Hass.io 实例中。
1. 安装此插件。
1. 创建目录 `/config/addon_config/tubesync` 以存储您的配置。
1. 启动插件。
1. 查看插件日志以确认一切正常。
1. 在 homeassistant:4848 打开 Web 界面。


[repository]: https://github.com/jdeath/homeassistant-addons
