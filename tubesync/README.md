# Home assistant 附加组件：Tubesync

这只是一个测试，不确定是否有效。

TubeSync 是一个用于 YouTube 的个人视频录像机（PVR）。或者，就像 Sonarr 是为 YouTube 设计的（内置下载客户端）。它旨在将 YouTube 频道和播放列表同步到本地目录，并在下载媒体后更新您的媒体服务器。

https://github.com/meeb/tubesync

## 安装

该附加组件的安装非常简单，与安装任何其他 Hass.io 附加组件没有不同。

1. 将我的 Hass.io 附加组件仓库 `[repository]` 添加到您的 Hass.io 实例中。
1. 安装此附加组件。
1. 创建目录 `/config/addon_config/tubesync` 以存储您的配置。
1. 启动附加组件。
1. 检查附加组件的日志，以确认一切正常。
1. 在 homeassistant:4848 上打开 Web UI。

[repository]: https://github.com/jdeath/homeassistant-addons
