# Home assistant 插件：Tubesync

这只是一个测试。不确定是否有效。

TubeSync 是一个专为 YouTube 设计的 PVR（个人视频录制器）。或者，就像 Sonarr 但对于 YouTube（带内置下载客户端）。它旨在将 YouTube 频道和播放列表同步到本地目录，并在媒体下载后更新您的媒体服务器。

https://github.com/meeb/tubesync

## 安装

这款附加组件的安装非常简单，与安装任何其他 Hass.io 附加组件没有区别。

1. [将我 Hass.io 附加组件仓库][repository] 添加到您的 Hass.io 实例。
1. 安装此附加组件。
1. 创建目录 `/config/addon_config/tubesync` 用于存储您的配置。
1. 启动附加组件。
1. 检查附加组件的日志，看看一切是否顺利。
1. 打开 Web 界面 `homeassistant:4848`

[repository]: https://github.com/jdeath/homeassistant-addons
