# Home assistant 附加组件：Tubesync

此仅为测试，不知是否可用。

TubeSync 是一个针对 YouTube 的 PVR（个人视频录制器）。或者说，它就像是 Sonarr 的 YouTube 版本（内置下载客户端）。其设计目的是将 YouTube 的频道和播放列表同步到本地目录，并在下载媒体后更新您的媒体服务器。

https://github.com/meeb/tubesync

## 安装

该附加组件的安装非常直接，与其他任何 Hass.io 附加组件的安装方式并无不同。

1. [添加我的 Hass.io 附加组件仓库][repository] 到您的 Hass.io 实例中。
1. 安装此附加组件。
1. 创建目录 /config/addon_config/tubesync 以存储您的配置文件。
1. 启动附加组件。
1. 检查附加组件的日志，以确认一切是否顺利。
1. 打开 WebUI：homeassistant:4848

[repository]: https://github.com/jdeath/homeassistant-addons
