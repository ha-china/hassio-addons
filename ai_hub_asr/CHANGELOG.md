## 更新日志

### v1.1.7 (2026-01-22)

> ⚠️ **重大变更（Breaking Change）**  
> 本次更新优化了 Home Assistant 实体的创建逻辑。建议**先删除集成后重新安装**，以自动创建用于 Home Assistant 调用的实体，确保系统正常工作。  
> 若未完全卸载旧版本再安装，新旧配置可能导致部分冗余文件未清理，可能额外占用约300-500MB硬盘空间，请留意。建议卸载时勾选删除数据，然后重新安装以获得最佳体验。

- 🏠 **实体自动创建**：优化 Home Assistant 实体注册，无需手动添加即可调用程序相关实体。

### v1.1.2 (2026-01-21)

- ⚡ **性能优化**: 修复模型重复加载问题，后续识别速度提升 2-3 秒
- 🔧 **共享模型**: 使用类变量共享模型实例，避免每次连接重新加载
- 🎯 **简化架构**: 移除 VAD 依赖，简化为纯离线识别模式
- 📦 **精简镜像**: 不再下载 VAD 模型，减少下载时间和存储占用

### v1.1.0 (2026-01-21)

- 🎯 **重大重构**: 从二进制 sherpa-onnx 迁移到纯 Python 实现
- ⚡ **性能提升**: 去除 WebSocket 通信开销，直接调用识别引擎
- 📦 **镜像优化**: 镜像体积减少约 50%（不再需要二进制文件）
- 🔧 **架构简化**: 单一 Python 进程，更易维护和调试
- 🚀 **跨平台**: 自动适配 x86_64 和 aarch64，无需手动选择二进制
- ✨ **代码质量**: 更清晰的代码结构，更好的错误处理
