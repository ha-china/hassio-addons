# 非官方 Home Assistant 扩展：syslog-ng

syslog-ng（<https://www.syslog-ng.com/products/open-source-log-management/>）
作为 Home Assistant 扩展捆绑。

## 关于

syslog-ng 允许您灵活地收集、解析、分类、重写和关联来自您整个基础设施的日志，并将它们存储或路由到日志分析工具。

## 附加说明

有关如何配置此扩展的信息，请参阅扩展页面内的 [文档](DOCS.md)。

此项目与 syslog-ng 无关，仅是一个社区努力的结果。syslog-ng 本身是在 GPL/LGPL 许可下分发的。
