## 关于

[Actual][actual] 是一款预算管理应用，它将你的资金保存在你可见的地方。它使用信封预算法：每个月，你把持有的每一货币单位都分配一个任务，数字能合上，因为从未真正分配给你手头实际拥有的钱。

预算生活在你的浏览器中，并通过此应用同步，此应用是唯一保留副本的地方。它不会发送到任何其他地方，没有注册账户，也没有人向你透露你的消费习惯。

家里每个人都基于同一个预算工作，即使手机在信号全无的商店中录入交易，预算依然可用，因为数据已保存在设备上，而不在等待请求之后。

Actual 被设计为从主机根目录提供服务，而侧边栏并非如此，因此此应用携带一个补丁，按请求调整基础路径。这使得面板能够工作，代价是 Actual 称之为不受支持的存储模式。如果这对你很重要，应用文档解释了这意味着什么以及你应该怎么做。
