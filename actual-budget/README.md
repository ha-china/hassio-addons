## 关于

[Actual][actual] 是一款预算应用，它将你的钱保留在看得见的位置。它使用信封预算法：每个月你只需为手中每种货币确定一项用途，数字之所以能相加，是因为你只分配实际拥有的资金。

预算保存在你的浏览器中，并通过此应用同步，此应用是唯一的副本存放位置。Nothing 被发送到任何其他地方，没有账户需要注册，也没有人兜售你用钱做了什么。

房子里的每个人都使用相同的预算，即使手机在没信号的商店输入交易，它也能保持可用，因为数据已存在于设备上，而不是在请求之后。

Actual 旨在从主机的根目录服务，而侧边栏不是，因此此应用携带了一个补丁，为每个请求设置基础路径。这使面板能够工作，代价是 Actual 称不支持的存储模式。如果这对你很重要，应用文档解释了这意味着什么以及你该怎么做。
