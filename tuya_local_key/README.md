# Tuya 本地密钥

使用 QR 码登录从 Home Assistant 中获取 Smart Life / Tuya 设备的本地密钥。

在 Home Assistant 侧边栏中打开应用，输入您的 Smart Life 用户码，使用 Smart Life 应用扫描二维码并确认登录。

该应用程序会在 `/data` 中保持其登录信息、设备列表、扫描结果和更改历史记录。它会最多保留 3 天已保存的设备列表。如需更早获取，请使用“刷新”。
