# 涂鸦本地密钥

使用二维码登录方式，从 Home Assistant 获取 Smart Life / 涂鸦设备的本地密钥。

点击 Home Assistant 侧边栏中的应用程序，输入您的 Smart Life 用户代码，使用 Smart Life 应用程序扫描二维码并确认登录。

该应用程序将其缓存的登录会话存储在应用程序数据卷的 `/data/session.json` 中。

Web UI 缓存设备列表 3 天。点击“刷新”从 Tuya 获取最新列表。
