# Tuya 本地密钥

使用二维码登录从 Home Assistant 获取 Smart Life/Tuya 设备的本地密钥。

点击 Home Assistant 侧边栏中的应用，输入您的 Smart Life 用户代码，使用 Smart Life 应用扫描二维码并完成登录确认。

该应用将在应用数据目录的 `/data/session.json` 文件中存储其缓存的登录会话。

网页界面缓存设备列表长达 3 天。点击"Refresh"可从 Tuya 获取最新设备列表。
