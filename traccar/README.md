## 关于

[Traccar][traccar] 是一款现代 GPS 跟踪平台，现已作为 Home Assistant 应用推出，并允许您无需任何云端服务即可运行 GPS 跟踪软件。

Traccar 支持比市场上任何其他 GPS 跟踪系统更多的协议和设备型号，直接从您的 Hass.io 实例中运行。您可以从各种供应商的 GPS 跟踪器中选择，涵盖从低成本中国型号到高端品质品牌的广泛选择。

Traccar 还提供针对 Android 和 iOS 平台的原生移动应用程序，以便您也可以跟踪这些地方。而且！通过 Home Assistant `traccar` 集成（在 0.83 版本中引入），Traccar 中的数据也会被发送到您的 Home Assistant 实例中。
