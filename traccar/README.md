## 关于

[Traccar][traccar] 是一款现代 GPS 跟踪平台，现已作为 Home Assistant 应用发布，让您无需任何云服务器即可运行 GPS 跟踪软件。

Traccar 支持比市场上任何其他 GPS 跟踪系统更多的协议和设备型号，直接从您的 Hass.io 实例中运行。您可以从各种供应商中选择了 GPS 跟踪器，从低成本的中国型号到高端优质品牌均可选择。

Traccar 也提供了针对 Android 和 iOS 平台的原生移动应用，以便您跟踪这些信息。还有！借助 Home Assistant `traccar` 集成（在 0.83 版本中引入），Traccar 中的数据也会发送到您的 Home Assistant 实例中。
