## 介绍

[Traccar][traccar] 是一款现代化的 GPS 跟踪平台，现已作为 Home Assistant 应用可用，让您能在无需任何云端的情况下运行 GPS 跟踪软件。

Traccar 支持的市场中任何其他 GPS 跟踪系统都比不了的更多协议和设备型号，直接来自您的 Hass.io 实例。您可以从低成本的中国型号到高性价比的品牌中选择各类供应商的 GPS 跟踪器。

Traccar 还为其 Android 和 iOS 平台提供了原生移动应用，这样您就可以进行跟踪。并且！有了 Home Assistant 的 `traccar` 集成（在 0.83 版本中引入），来自 Traccar 的数据也会发送回您的 Home Assistant 实例。
