## 关于

[Traccar][traccar] 是一个现代化的 GPS 追踪平台，现在已作为 Home Assistant 应用推出，允许您在没有云端的情况下运行 GPS 追踪软件。

Traccar 支持的市场任何 GPS 追踪系统都更多的协议和设备型号，直接从您的 Hass.io 实例中运行。您可以从廉价的中华模型到高末品质的品牌，选择各种供应商的 GPS 追踪器。

Traccar 也提供了原生的 Mobil 应用，适用于 Android 和 iOS 平台，以便您也可以追踪它们。还有！有了 Home Assistant `traccar` 集成（在 0.83 中引入），Traccar 中的数据也会被发送到您的 Home Assistant 实例中。
