## 简介

[Traccar][traccar] 是一个现代化的 GPS 跟踪平台，现在已作为 Home Assistant 应用可用，并且允许您在不需要任何云服务的情况下运行 GPS 跟踪软件。

Traccar 支持的协议和设备型号数量多于市场上任何其他 GPS 跟踪系统，您可以直接从您的 Hass.io 实例中选择来自各种供应商的 GPS 跟踪器，从低成本的中國型号到高端质量品牌。

Traccar 也提供了原生的移动应用，适用于 Android 和 iOS 平台，以便您跟踪这些设备！并且！通过 Home Assistant 的 `traccar` 集成（在 0.83 版中引入），Traccar 中的数据也会发送到您的 Home Assistant 实例中。
