## 关于
此插件基于 [docker镜像](https://github.com/seansegal/tincisnotcatan)。进行了许多更改，以更好地处理Websocket。

## 配置

```
port : 8000 #你想要运行的端口。
```

Web界面可以在 `<你的IP>:port` 找到。
