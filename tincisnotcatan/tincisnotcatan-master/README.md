# Catan
Catan在线版，可选玩高级经济功能。最初是为CS32：软件工程导论课程的期末项目而构建。

访问http://tinc.herokuapp.com/尝试游戏！

## 贡献
欢迎贡献！要本地运行，使用以下命令构建Docker镜像：
`docker build -t catan .`

然后使用以下命令运行应用程序：
`docker run --rm --name catan -d -p 4567:4567 --cpus=4 catan`

一旦运行，应用程序将在`localhost:4567`可用。

## 部署

## 最终用户文档

### 主屏幕
您首先看到的是一个主屏幕，其中有一个用于输入用户名的文本输入框。一旦输入了用户名，您将进入一个屏幕，您可以选择创建新游戏或加入现有游戏。要加入现有游戏，只需单击您希望进入的游戏旁边的“加入游戏”按钮。要创建新游戏，首先输入要显示给其他玩家的游戏名称，输入游戏中允许的玩家数量，要玩到的胜利点数，以及要启用的哪些高级经济功能。

十进制资源选项允许资源数量精确到小数点后两位。这允许玩家之间以及与银行进行分数资源交易。

动态汇率选项仅在选中十进制资源选项时才可用。当启用动态汇率时，银行交易率将根据玩家手中的当前资源而变化。

### 开始游戏
一旦玩家创建了游戏或加入了现有游戏，他们将被带到游戏板。一旦所有玩家都加入了，将生成一个随机的回合顺序，游戏开始。根据官方规则，第一位玩家必须放置一个定居点和道路，然后是第二位玩家，依此类推，直到最后一位玩家放置他们的第一个定居点和道路。然后，最后一位玩家将放置他们的第二个定居点和道路，然后是倒数第二位玩家，依此类推，直到第一位玩家放置他们的第二个定居点和道路。

### 回合流程
一旦所有玩家都放置了他们的两个初始定居点，第一位玩家的回合开始。在玩家的回合中，玩家可以选择建造道路、定居点、城市或发展卡，与其他玩家提议交易，与银行交易或玩发展卡。玩家可以在单个回合中选择执行这些操作中的任意多个，但限制是每个回合只能玩一张发展卡。当玩家准备好结束他们的回合时，他们应该按下“结束回合”按钮，以便移动到下一位玩家的回合。

### 玩家标签页
右侧的第一个标签是“玩家标签页”。此标签页显示所有玩家信息，包括胜利点数、资源和发展卡总数，以及剩余建筑数量。如果玩家拥有最长道路或最大军队，则在其玩家标签页中会显示横幅。

### 建造标签页
右侧的第二个标签是“建造标签页”。此标签页显示道路、定居点、城市和发展卡的建造费用。如果玩家没有足够的资源购买建筑，则建造按钮将被禁用。当点击建造按钮时，板上的可用位置将被突出显示。单击这些突出显示的位置之一将在该位置建造适当的建筑。

### 交易标签页
右侧的第三个标签是“交易标签页”。此标签页有两个子标签 - 一个用于与其他玩家交易，另一个用于与银行交易。如果您想与其他玩家交易，输入您希望提供的资源和希望获得的资源。输入负数表示提供的资源，输入正数表示获得的资源。当您准备好向所有玩家提出交易时，应点击“提出交易”按钮。

在此阶段，所有其他玩家将看到提议的交易，并可以选择接受或拒绝交易。随着其他玩家接受或拒绝交易，您将看到他们的回应。如果玩家接受交易，您将有机会与他们最终确定交易，此时将适当地添加和移除资源。如果您想在任何时候取消交易，只需按下“取消交易”按钮，所有其他玩家将被告知交易已被取消。

要与银行交易，选择您希望提供的资源和希望获得的资源。这些资源的交易率直接显示在提供的资源下方。输入您希望获得的资源数量，根据此交易率将自动计算您必须提供的资源数量。如果您想交易，点击“交易”按钮，资源将自动添加到并从您的手中移除。

### 发展卡
手中资源和发展卡的数量显示在屏幕底部的栏中。将鼠标悬停在发展卡上会显示如何使用它的说明。要玩发展卡，点击相应的发展卡图标。

如果玩了一个骑士，所有robber可以移动到的地块都将被突出显示。单击突出显示的地块将robber移动到该地块。如果玩家在该地块附近有建筑，将弹出对话框，当前玩家可以选择一个玩家从其手中随机抽取一张卡。

如果玩了一个丰收年，玩家可以选择将恰好两种资源添加到手中。如果启用了十进制资源选项，可以选中资源的小数部分，只要总数恰好是两个即可。

如果玩了一个垄断，玩家可以从所有其他玩家那里偷取一种资源。

如果玩了一个道路建设，玩家可以以与按下“建造道路”按钮相同的方式建造两条道路。

胜利点数将自动添加到玩家标签页中的胜利点数计数中，但对其他玩家不可见。

## 文档：CatanAPI

### CatanAPI概述
CatanAPI提供了一种简单的方式来跟踪一场Settlers of Catan游戏。API将跟踪游戏的各个方面，并提供足够的JSON格式信息，以便可以图形化表示游戏。以下部分概述了如何创建游戏、设置游戏设置以及发送/接收有关游戏的信息。

### 创建游戏
要创建一场Catan游戏，只需实例化一个CatanAPI对象。为了简单起见，CatanAPI只包含一个空构造函数，该构造函数创建一个具有默认设置的_game。如果您想使用各种设置自定义游戏，应立即调用setSettings方法来设置游戏设置。有关设置对象的更多详细信息，请参阅以下内容。

### 游戏设置对象
在创建游戏后，用户可以使用API的setSettings方法设置游戏设置。此设置函数接受一个具有以下格式的JsonObject：
```javascript
{numPlayers: numPlayers, victoryPoints: victoryPoints, isDecimal: isDecimal, isDynamic: isDynamic, isStandard: isStandard}
```
