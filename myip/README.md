# Home assistant 插件: MyIP

MyIP 是一款高级 IP 工具，旨在提供关于您 IP 地址的广泛信息和诊断信息。它非常适合需要查看和分析 IP 详细信息、检查网站可访问性、执行 DNS 泄露测试等功能的用户。

## 关于此插件

此插件使用 [docker 镜像](https://github.com/jason5ng32/MyIP)。

## 安装

此插件的安装非常简单，与安装任何其他 Hass.io 插件没有区别。

1. 将 [我的 Hass.io 插件仓库][repository] 添加到您的 Hass.io 实例中。
1. 安装此插件。
1. 点击`保存`按钮以存储您的配置。
1. 打开 WebUI，现在可以通过`<your-ip>:port`访问。

## 配置

```
port : 18966 #您希望运行的端口。
```

WebUI 的访问地址为`<your-ip>:port`。
