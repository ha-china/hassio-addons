# Home assistant add-on: MyIP

MyIP 是一个高级 IP 实用工具，旨在提供有关您的 IP 地址的广泛信息和诊断数据。它非常适合需要查看和分析 IP 详细信息、检查网站可用性、执行 DNS 泄漏测试等的用户。

## 关于

此附加组件使用 [docker 镜像](https://github.com/jason5ng32/MyIP)。

## 安装

此附加组件的安装非常直接，与安装任何其他 Hass.io 附加组件没有不同。

1. 将 [my Hass.io add-ons repository][repository] 添加到您的 Hass.io 实例。
1. 安装此附加组件。
1. 点击 `Save` 按钮以保存您的配置。
1. 通过 `<your-ip>:port` 打开 WebUI 应能工作。

## 配置

```
port : 18966 #port you want to run on.
```

WebUI 可在 `<your-ip>:port` 找到。
