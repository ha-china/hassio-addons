# Music Assistant (NIGHTLY) 应用

 bleeding edge 开发的 Music Assistant 构建版本。

## ⚠️ 警告 - 仅供高级用户 ⚠️

这是 **NIGHTLY**（开发版）Music Assistant 版本。它包含最新的代码更改，**不建议用于日常使用**。

### 🔴 关键信息

**关于此应用：**

- ❌ **不稳定** - 随时可能崩溃
- ❌ **未经测试** - 更改直接从开发环境推送
- ❌ **不获支持** - 自行承担风险
- ❌ **不适合初学者** - 可能需要技术知识才能排查问题

**除非您：**

- ✅ 是开发人员或高级用户
- ✅ 了解运行未发布软件的风险
- ✅ 能够自行调试问题
- ✅ 拥有备份系统或测试环境
- ✅ 愿意失去数据或功能

## 什么是 NIGHTLY？

NIGHTLY 构建是从 Music Assistant 的 `dev` 分支自动构建的。它们包括：

- 🚧 开发中的功能
- 🔬 实验性代码
- 🐛 未经验证的 Bug 修复
- ⚡ 最新代码更改（24 小时内）
- 💥 可能存在破坏性变更

## 发布频率

- **更新**：每日（当更改推送到 dev 分支时）
- **测试**：极少或无
- **质量**：差异很大
- **稳定性**：⚠️ 本质不稳定

## 问题报告

### 报告之前

1. ⚠️ 确认您是有意使用 NIGHTLY
2. 检查问题是否存在于 BETA 或 稳定版
3. 搜索现有问题
4. 尝试使用最小配置复现问题

### 需要包含的内容

- **版本**：精确的 NIGHTLY 版本号及日期
- **日志**：完整调试日志
- **上下文**：崩溃时您正在做什么
- **环境**：Home Assistant 版本、硬件规格
- **复现步骤**：逐步的复现步骤

### 报告地点

- 💬 [Discord 服务器](https://discord.gg/PZQ6RWbfeS)

## 回滚策略

### 如果出问题了

1. **停止应用**
2. **从备份恢复**（您确实做了一个备份，对吧？）
3. **报告问题**

## 贡献

运行 NIGHTLY 并发现问题是贡献！您也可以：

- 🐛 [带有详细日志报告 Bug](https://github.com/music-assistant/support)
- 🔧 提交包含修复的合并请求
- 📝 记录问题和工作变通方法
- 💬 在 [Discord](https://discord.gg/PZQ6RWbfeS) 上帮助其他 NIGHTLY 用户
- 🧪 测试特定功能

访问 GitHub 上的 [Music Assistant 组织](https://github.com/music-assistant) 进行贡献。
