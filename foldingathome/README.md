## 关于

Folding@home（简称 FAH 或 F@h）是一个分布式计算项目，用于执行蛋白质动力学的分子动力学模拟。其初始重点是蛋白质折叠，但已转向更多生物医学问题，如阿尔茨海默病、癌症、埃博拉病毒和冠状病毒。

该项目利用志愿者在其系统上安装软件后闲置的个人电脑处理资源。

现在，您可以将 Home Assistant 实例的闲置时间捐赠给 Folding@home 项目，协助与这些疾病作斗争。
