## 项目简介

Folding@home (FAH 或 F@h) 是一个分布式计算项目，用于执行蛋白质动力学的分子动力学模拟。其初期焦点集中在蛋白质折叠上，但现在已转向更偏重生物医学的问题，如阿尔茨海默病、癌症、埃波拉病毒和冠状病毒。

该项目利用了志愿用户在其系统上安装软件后闲置的个人电脑计算资源。

现在，您可以捐赠 Home Assistant 实例的闲置时间为 Folding@home 项目，助力对抗这些疾病。
