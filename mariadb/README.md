# Home Assistant App: MariaDB

Home Assistant 的 MariaDB 数据库。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

## 关于

您可以使用此应用（ formerly 称为附加组件）来安装 MariaDB，这是一个开源（根据 GPLv2 许可）的数据库。MariaDB 可以作为 Home Assistant 的后端数据库。更多信息，请参阅 [MariaDB][mariadb]
