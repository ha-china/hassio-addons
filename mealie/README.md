## 简介

[Mealie][mealie] 是一个食谱管理器与餐食计划器，让您的烹饪生活掌握在自己家中。只需提供您在线找到的食谱地址，它就会提取您实际烹饪的部分：食材、步骤、时间和图片。食谱上方的生平背景便不再重要。

以此为基础，它便变为一个计划工具。将食谱安排在周的日历中，它便会生成购物清单，并将每餐中的相同食材汇总。食谱可进行缩放、标记、分类到不同的食谱集，并与家庭成员共享，每位成员拥有独立的登录账号。

Home Assistant 已为 [Mealie][integration] 提供了集成，因此餐食计划和购物清单可以出现在您的仪表盘上，与其他所有内容并置显示。
