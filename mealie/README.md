## 简介

[Mealie][mealie] 是一个食谱管理和餐食规划器，旨在将您的烹饪流程保留在您自己的家中。给它一个您在线找到的食谱地址，它即可提取实际烹饪所需的部分：食材、步骤、时间和图片。而食谱之上的那些背景故事则被剥离。

在此基础上，它转化为一个规划器。将食谱添加到周度日历中，它便会生成购物清单，并汇总清单上每餐所需的所有相同食材。食谱可以按比例缩放，添加标签，整理入食谱集，并为家庭其他成员共享，每位成员都拥有独立的登录账号。

Home Assistant 拥有 [Mealie 的集成模块][integration]，因此餐食计划和购物清单可以显示在主界面上，与其他 Everything 相邻。该程序会自动发现此应用。
