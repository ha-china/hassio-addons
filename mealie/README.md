## 关于 Meale

[Mealie][mealie] 是一款食谱管理器和餐食计划工具，让您的烹饪记录保存在自家屋内。给它提供一个您在线找到的食谱地址，它会提取出您实际烹饪的部分：食材、步骤、时间和图片（即食谱上的生活故事将保留原样）。

从此，它变成了计划工具。将食谱安排在周历中，它会得出购物清单，并汇总清单中每一餐相同的食材。食谱可以调整大小、打标签、整理成食谱书，并与家庭其他成员共享，每位成员都有自己的登录凭证。

Home Assistant 提供 [Mealie 的集成][integration]，因此餐食计划和购物清单可以显示在您的仪表板上，与其他内容并列。它会自动找到该应用。
