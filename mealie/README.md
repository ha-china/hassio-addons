## 关于

[Mealie][mealie] 是一个食谱管理器和膳食计划器，它将您的烹饪记录保存在您自己的家中。只需提供您从网络上找到的食谱地址，它便会提取您实际使用的内容：食材、步骤、时间和图片。食谱背景中的生平故事将被保留。

从此，它变成了一个计划器。将食谱安排在周历中，它会生成购物清单，并将同一食材汇总到每顿饭中。食谱可以进行缩放、标记、分类_into_食谱书，并与其他家庭成员共享，每个人都有自己的登录账户。

Home Assistant 拥有 [Mealie 的集成][integration]，因此膳食计划和购物清单可以显示在您的仪表板上，与 Everything 一起显示。它会自动查找此应用。
