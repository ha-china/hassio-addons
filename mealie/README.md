## 关于

[Mealie][mealie] 是一款食谱管理与 meal 规划工具，将您的烹饪记录保存在自己的家中。只需输入您在网上找到的食谱地址，它就能提取出您需要烹饪的部分：食材、步骤、时间以及图片。食谱上方的背景故事则会被保留。

随后它便转变为规划工具。将食谱安排在周历中，它就能生成购物清单，计算每道菜中相同食材的总量。食谱可以缩放、添加标签、整理成烹饪书，并与家庭其他成员共享，每个成员拥有独立的登录账号。

Home Assistant 已有 [Mealie 的集成][integration]，因此 meal 计划和购物清单可以像其他功能一样显示在您的仪表板上。它会自动为您找到此应用。
