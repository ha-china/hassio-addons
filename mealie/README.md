## 简介

[Mealie][mealie] 是一款食谱管理器和餐食规划器，它让烹饪记录保存在您的家中。只需提供您在网上找到的食谱地址，它就会提取您实际烹饪的部分：食材、步骤、时间以及图片。食谱背后的“生平故事”将被保留。

在此基础上，它可以转为规划器。将食谱安排在即将到来的日历中，它会计算出购物清单，并汇总清单上每顿饭的相同食材。食谱可以调整分量、添加标签、组织进食谱书，并与家庭成员共享，每位成员都有独立的登录权限。

Home Assistant 拥有 [对 Mealie 的集成][integration]，因此餐食计划和购物清单可以显示在您的仪表板上，与所有内容并列展示。它将自动找到此应用。
