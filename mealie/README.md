为厨房准备的食谱管理器与膳食计划工具。

## 简介

[Mealie][mealie] 是一款食谱管理与膳食计划工具，让你的烹饪记录保存在你自己的家中。只需输入你在网上找到的食谱网址，它便会提取你真的需要烹饪的部分：食材、步骤、时间以及图片，而食谱上方的其他信息则无需操劳。

从此，它便变成了计划工具。将食谱排入周日历，它会自动生成购物清单，并汇总清单中每一餐所需的相同原料。食谱可以调整份量、添加标签、整理成食谱书，并与家庭成员共享，每位成员拥有独立的登录权限。

Home Assistant 提供了 [针对 Mealie 的集成][integration]，因此膳食计划和购物清单可以显示在你的仪表盘上，与其他所有内容并列。它会自行搜索并找到这款应用。
