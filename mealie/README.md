## 简介

[Mealie][mealie] 是一个食谱管理和餐计划工具，让您的烹饪活动保留在自己家中。只需将您在网络上找到的食谱地址输入其中，它即可从中提取实际用于烹饪的部分：食材、步骤、用时以及图片，而保留食谱上方的生平故事。

从此，它便成为您的计划工具。将食谱安排在一周的日历上，它会自动生成购物清单，并在同一份清单上汇总每顿饭中的相同食材。食谱可以进行缩放、添加标签、装入食譜书中，并与家庭成员共享，每位成员拥有独立的登录账号。

Home Assistant 提供了[Mealie 的集成][integration]，因此餐计划和购物清单可以在你的仪表板上显示与其他所有信息相邻。它会自行发现此应用。
