## 关于 Homebox

[Homebox][homebox] 是一套家庭物品存货系统。它会记录你拥有物品的清单、存放位置、购买原价以及当前估值，专为家庭生活设计，而非仓库使用。

物品存放在“位置”（Locations）中，位置可以互相嵌套内联，任何物品都可以打上标签。每个物品都会有照片、收据、说明书、序列号、保修日期以及你想要的任何自定义字段信息。从这些信息中即可查看其详情，而这正是其核心功能所在：想要知道“阁楼里的哪个箱子里装着手持式烘烤炉”，只需通过一秒钟搜索即可得知，无需耗费整个下午的时间。

系统还能针对物品生成维护日志，这样无论是暖气炉的检修服务还是割草机拉刀的更换记录都有了存档之处；它还可以打印带有二维码的标签纸，以便粘贴在物品收纳容器上。
