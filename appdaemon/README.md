Python 应用和 HADashboard for Home Assistant

## 关于

[AppDaemon][appdaemon] 是一个松散耦合的、多线程的、沙箱化的 Python 执行环境，用于编写 Home Assistant 家居自动化软件的自动化应用。它还提供了一个可配置的仪表板（HADashboard），适合安装在墙上平板电脑上。
