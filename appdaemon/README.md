## About

AppDaemon 是一个松散耦合、多线程、沙箱化的 Python 执行环境，用于为 Home Assistant 家庭自动化软件编写自动化应用。它还提供了一个适用于壁挂式平板电脑的可配置仪表板（HADashboard）。
