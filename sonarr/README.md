Usenet 和 BT 用户的智能录像机。

## 关于

[Sonarr] 是面向 Usenet 和 BT 用户的录像机。它可以监视多个 RSS 馈送，以查找您喜欢的节目的新集数，并获取、排序和重命名它们。它还可以配置为自动升级已下载文件的品质，当更好的品质格式可用时。
