## 关于

[Sonarr] 是一款针对 Usenet 和 BitTorrent 用户的 PVR。它可以监控多个 RSS 源，寻找您喜欢的电视剧的新剧集，并自动下载、排序和重命名。它还可以配置为在更好的质量格式可用时自动升级已下载文件的画质。
