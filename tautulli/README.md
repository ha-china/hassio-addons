## 关于

Tautulli 是一个可以与您的 Plex 媒体服务器一起运行的应用程序，用于监控活动并跟踪各种统计数据。

最重要的是，这些统计数据包括已观看的内容、谁观看了它、在何时何地观看以及如何观看。

所有统计数据都通过一个界面美观且清晰的界面展示，包含许多表格和图表，这使得您很容易向其他人夸耀您的服务器表现。
