面向合辑（Usenet）和托特（Torrent）用户的电影整理器/管理器。

## 概述

[Radarr] 是为合辑和比特传用户设计的电影集锦管理器。它可以监控多个 RSS 新闻组以查找新电影，并可以与客户端和索引器接口对接，用于获取、排序和命名文件。此外，它还被配置为在库中已有文件的可用性质量格式改善时，自动升级现有文件的质量。
