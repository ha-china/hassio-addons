专为 Usenet 和网络种子用户设计的电影整理/管理平台。

## 简介

[Radarr] 是一款针对 Usenet 和 BitTorrent 用户的电影库管理工具。它可以监控多个 RSS 快讯以获取新电影，并与客户端和索引器交互来抓取、排序和重命名文件。此外，它还可以配置为当库中出现更高质量格式时，自动将现有文件的等级提升（升级）。
