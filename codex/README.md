## 关于

---

[Codex](https://github.com/ajslater/codex) 是一个基于网络的漫画存档浏览器和阅读器。
该附加组件基于官方 Docker 镜像：https://hub.docker.com/r/ajslater/codex

## 安装

---

安装这个附加组件非常简单，与其他任何附加组件的安装方式没有区别。

1. 将我的附加组件仓库添加到 Home Assistant 实例中（在 supervisor 附加组件存储右上角，或如果你在 HA 中配置了我的仓库，请点击下方按钮）
   [![打开您的 Home Assistant 实例并显示附加组件仓库对话框，其中预填充了特定的仓库 URL。](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Falexbelgium%2Fhassio-addons)
1. 安装此附加组件。
1. 点击 `保存` 按钮以存储您的配置。
1. 将附加组件选项设置为您的偏好设置。
1. 启动附加组件。
1. 检查附加组件的日志，查看一切是否顺利。
1. 打开 WebUI 并调整软件选项

## 配置

WebUI 可访问 <http://homeassistant:PORT>。

您可以将用户文件夹从主题/模板放置到 /share/codex/www/user，

## 选项

| 选项 | 描述 | 默认值 | 示例 |
|--------|-------------|---------|---------|
| `PGID` | 文件权限的组 ID | `0` | `1000` |
| `PUID` | 文件权限的用户 ID | `0` | `1000` |
| `TZ` | 长时间格式的时区 | - | `America/Los_Angeles` |
| `CODEX_RESET_ADMIN` | 重置管理员用户和密码为默认值 | - | `1` |
| `CODEX_SKIP_INTEGRITY_CHECK` | 启动时跳过数据库完整性修复 | - | `1` |
| `csrf_allowed` | 允许访问应用程序的地址的逗号分隔列表 | `http://homeassistant.local:8123,https://homeassistant.local:8123` | `http://localhost:8123` |
| `localdisks` | 要挂载的驱动器硬件名称（逗号分隔）。在驱动器后添加要挂载的文件夹，例如 `MYNAS/public` 仅挂载该文件夹，路径为 `/mnt/MYNAS/public`。文件夹挂载需要附加组件版本在 2026-09-19 之后发布。 | - | `sda1,sdb1,MYNAS` |
| `networkdisks` | 要挂载的 SMB 服务器（逗号分隔） | - | `//SERVER/SHARE` |
| `cifsusername` | 所有共享的 SMB 用户名 | - | `username` |
| `cifspassword` | SMB 密码 | - | `password` |
| `cifsdomain` | SMB 域 | - | `WORKGROUP` |

```yaml
PGID: 1000
PUID: 1000
TZ: "America/Los_Angeles"
CODEX_RESET_ADMIN: 1
CODEX_SKIP_INTEGRITY_CHECK: 1
csrf_allowed: "http://homeassistant.local:8123,https://homeassistant.local:8123"
localdisks: "sda1,sdb1"
networkdisks: "//SERVER/SHARE"
cifsusername: "username"
cifspassword: "password"
cifsdomain: "WORKGROUP"
```

### 自定义脚本和环境变量

该附加组件通过 `app_config` 映射支持自定义脚本和环境变量：

- **自定义脚本**：参见 [附加组件中的运行自定义脚本](https://github.com/alexbelgium/hassio-addons/wiki/Running-custom-scripts-in-Addons)
- **env_vars 选项**：使用附加组件 `env_vars` 选项传递额外的环境变量（大小写名称均可）。有关详细信息，请访问 https://github.com/alexbelgium/hassio-addons/wiki/Add-Environment-variables-to-your-Addon-2。

### 挂载驱动器

该附加组件支持挂载本地驱动器和远程 SMB 共享：

- **本地驱动器**：参见 [附加组件中的挂载本地驱动器](https://github.com/alexbelgium/hassio-addons/wiki/Mounting-Local-Drives-in-Addons)
- **远程共享**：参见 [附加组件中的挂载远程共享](https://github.com/alexbelgium/hassio-addons/wiki/Mounting-remote-shares-in-Addons)
