# Home Assistant Omada 插件 Beta 版

此插件将 Omada 控制器 Beta 版直接集成到 Home Assistant 中。

如果您想从 v5 升级到 v6，请阅读主 README 中的说明。

## 贡献

此插件最初源自 Matt Bentley 的
[docker-omada-controller](https://github.com/mbentley/docker-omada-controller)
项目。若无他们出色的工作，
[jkunczik 的 home-assistant-omada](https://github.com/jkunczik/home-assistant-omada) 也不会有今日的模样。
除原始 Docker Omada 控制器外，
本插件将所有持久化数据存储于 `/data` 目录，
使其能够与 Home Assistant 兼容。
没有其他人的努力，本插件也无法实现。
欢迎提交版本更新或新功能的 Pull Requests。
特别感谢 DraTrav 推动此插件持续发展！
