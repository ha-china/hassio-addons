# Home Assistant Omada Add-On Beta

本附加组件将 Omada 控制器 Beta 版本直接引入 Home Assistant。

请阅读主 README 中的说明以了解从 v5 升级到 v6 的相关信息。

## 贡献

本附加组件最初受 Matt Bentley 的
[docker-omada-controller](https://github.com/mbentley/docker-omada-controller)
以及 jkunczik 的 [home-assistant-omada](https://github.com/jkunczik/home-assistant-omada)
启发，离不开他们卓越的工作，否则本附加组件将无法实现。
除了在原始 docker omada controller 中的情况外，
本附加组件将所有持久化数据存储于 `/data` 目录，
以确保其与 Home Assistant 兼容。
本附加组件的实现离不开其他人的共同努力。
欢迎随时提交用于版本更新或新功能的 Pull requests。
特别提醒 DraTrav，感谢您将本附加组件向前推动！
