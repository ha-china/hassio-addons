# Home Assistant Omada Add-On Beta

该附加组件将 Omada 控制器 Beta 版本直接集成到 Home Assistant 中。

如果需要从 v5 升级至 v6，请参阅主 README 中的说明。

如果需要从 v6.3（或更低版本）升级至 v6.4，请参阅主 README 中的说明。

## 贡献

该附加组件最初受到 Matt Bentley 的
[docker-omada-controller](https://github.com/mbentley/docker-omada-controller)
以及 jkunczik 的 [home-assistant-omada](https://github.com/jkunczik/home-assistant-omada) 的启发。
如果没有他们出色的工作，home-assistant-omada 是不可能实现的。
除了原本的 docker omada 控制器外，本附加组件将所有持久化数据存储于 /data 目录，
使其与 Home Assistant 兼容。
本附加组件的实现离不开其他人们的努力。
若有版本更新或新增功能的 Pull Requests，总是热烈欢迎。
特别感谢 DraTrav 推动此附加组件的发展！
