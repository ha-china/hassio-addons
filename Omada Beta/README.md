# Home Assistant Omada 插件 Beta

该插件将 Omada 控制器 Beta 直接集成到 Home Assistant 中。

有关从 v5 升级到 v6 的信息，请阅读主 README 中的注意事项。

## 贡献

该插件最初受到 Matt Bentley 的
[docker-omada-controller](https://github.com/mbentley/docker-omada-controller)
以及 jkunczik [home-assistant-omada](https://github.com/jkunczik/home-assistant-omada)
的启发。要使其成为可能，离不开这两人优秀的贡献。
除了原始的 Docker Omada Controller 之外，
该插件将所有持久化数据存储在/data 目录中，
以便与 Home Assistant 兼容。
没有其他人的努力，这款插件也是无法实现的。
欢迎随时提交用于版本更新或新增功能的 Pull 请求。
特别感谢 DraTrav 推动该插件的进展！
