# Home Assistant Omada 附加组件 Beta

该附加组件将 Omada Controller Beta 直接集成到 Home Assistant 中。

如果您是想从版本 5 升级到版本 6，请参考主 README 中的说明。

## 贡献

该附加组件最初受到 Matt Bentley 的 [docker-omada-controller](https://github.com/mbentley/docker-omada-controller) 和 jkunczik 的 [home-assistant-omada](https://github.com/jkunczik/home-assistant-omada) 的启发，其成功离不开他们出色的工作。
除了原版 docker omada controller 之外，
该附加组件将所有持续性数据存储于 /data 目录，
因此可以与 Home Assistant 兼容。
没有其他人的努力，这个附加组件是不可能实现的。
欢迎提交任何版本更新或新特性的拉取请求。
特别感谢 DraTrav 推动了这个附加组件的发展！
