# 非官方 Home Assistant 附加组件：Promtail

Promtail (<https://grafana.com/oss/loki/>) 已打包为 Home Assistant 附加组件。

## 关于

Promtail 是一个代理，它将本地日志的内容传输到私有 Loki 存储库或 Grafana Cloud。

## 最终说明

有关如何配置此附加组件的信息，请参阅附加组件页面内的
[文档](DOCS.md)

本项目与 Promtail 无关，仅仅是社区的努力。Promtail 本身采用
