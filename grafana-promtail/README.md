# 非官方Home Assistant插件：Promtail

Promtail (<https://grafana.com/oss/loki/>) 作为Home Assistant插件打包。

## 简介

Promtail是一个代理，将本地日志的内容发送到私有Loki实例或Grafana Cloud。
