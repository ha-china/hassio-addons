# Home assistant 附加组件：Koroko Fast API

Docker 化的 FastAPI 包装器，用于 Kokoro-82M 文本转语音模型。几分钟内即可生成数小时的高质量语音

## 简介

该附加组件使用 [docker 镜像](https://github.com/remsky/Kokoro-FastAPI)。

## 安装

该附加组件的安装非常简单，与其他 Hass.io 附加组件的安装方式基本相同。

1. 将 [我的 Hass.io 附加组件仓库][repository] 添加到你的 Hass.io 实例中。
1. 点击 `保存` 按钮以存储你的配置。
1. 启动附加组件。
1. 查看附加组件的日志，确认一切是否正常。
1. 访问你配置的（默认为 8880）本地 IP 地址和端口

```
Webui 可访问于 `<your-ip>:port`。

[repository]: https://github.com/jdeath/homeassistant-addons
```
