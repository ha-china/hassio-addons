# Home assistant 插件：Koroko Fast API

Docker 化的 FastAPI 包装器，用于 Kokoro-82M 文字转语音模型。在几分钟内即可生成数小时的高质量语音。

## 关于

此插件使用 [docker 镜像](https://github.com/remsky/Kokoro-FastAPI)。

## 安装

此插件的安装非常简单，与其他 Hass.io 插件的安装并无不同。

1. 将 [我的 Hass.io 插件库][repository] 添加到您的 Hass.io 实例中。
2. 点击 `保存` 按钮以保存您的配置。
3. 启动插件。
4. 检查插件日志以查看一切是否正常。
5. 访问您配置的 home assistant 本地 IP（默认为 8880）

```
Webui 可在 `<your-ip>:port` 处找到。
```
