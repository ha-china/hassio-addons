# Home Assistant 插件：Kokoro Fast API

用于 Kokoro-82M 文本转语音模型的 Docker 封装 FastAPI 服务。几分钟内即可生成数小时的高质量语音。

## 关于此插件

此插件使用 [Docker 镜像](https://github.com/remsky/Kokoro-FastAPI)。

## 安装

此插件的安装非常简单，与其他任何 Hass.io 插件的安装方式没有显著区别。

1. [添加我的 Hass.io 插件仓库][repository] 到您的 Hass.io 实例中。
2. 点击 `保存` 按钮以保存配置。
3. 启动插件。
4. 检查插件日志，查看是否一切正常。
5. 访问配置的 Home Assistant 本地 IP 地址及端口（默认为 8880）。

```
Web 界面可通过 `<你的 IP>: 端口` 访问。

[repository]: https://github.com/jdeath/homeassistant-addons
```
