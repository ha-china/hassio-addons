# 插件：InfluxDB2

用于指标、事件和实时分析的扩展式数据存储。

## 关于

InfluxDB v2 是一个开源的时间序列数据库，专为高写入量优化。
它适用于记录指标、传感器数据、事件，并执行分析。它提供了一个 HTTP API 用于客户端交互，并且经常与 Grafana 结合使用以可视化数据。

InfluxDB v2 为您提供了一个漂亮的 InfluxDB 管理界面，用于管理您的用户、数据库、数据保留设置，并让您使用数据探查器来查看数据库内部情况。
