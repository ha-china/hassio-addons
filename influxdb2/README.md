# 扩展：InfluxDB2

适用于指标、事件和实时分析的可扩展数据存储库。

## 简介

InfluxDB v2 是一个开源的时间序列数据库，针对高写入量进行了优化。
它适用于记录指标、传感器数据、事件，并进行数据分析。它提供了一个 HTTP API 用于客户端交互，并且经常与 Grafana 结合使用来可视化数据。

InfluxDB v2 为您提供了一个不错的 InfluxDB 管理界面，用于管理您的用户、数据库、数据保留设置，并允许您使用数据探索器查看数据库内部。
