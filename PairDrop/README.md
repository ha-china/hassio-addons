## 关于此插件

此插件基于 [docker 镜像](https://github.com/schlagmichdoch/PairDrop)。

PairDrop 是一款功能全面的 AirDrop 替代品，可运行所有平台。
通过点对点（P2P）连接向同一本地网络/Wi-Fi 中的设备或已配对的设备发送图片、文件或文本。由于其基于网页，因此可在所有设备上运行。

您想快速从手机传输文件到笔记本电脑吗？
您想与使用 Android 和 iOS 混合系统的朋友以原始质量分享照片吗？
您想在 Linux 系统之间点对点共享私密文件吗？
AirDrop 再次不可靠？
用 PairDrop 发送它！

## 安装

本插件的安装很简单，与安装其他任何 Hass.io 插件一样。

1. 将我的 [Hass.io 插件仓库][repository] 添加到您的 Hass.io 实例中。
1. 安装此插件。
1. 点击 `Save` 按钮以保存您的配置。
1. 启动插件。
1. 检查插件日志以查看一切是否正常运行。
1. 通过 ingress 或 `<your-ip>:port` 打开 Web 界面应该可以工作。

## 配置

```
port : 3000 #您想要运行的端口。
```

Web UI 可在 `<your-ip>:port` 处找到。
