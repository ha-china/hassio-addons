## 关于

本应用基于 [Docker 镜像](https://github.com/remvze/moodist)。

## 安装

此应用的安装非常简单，与其他任何 Hass.io 应用的安装过程没有不同。

1. 将 [我的 Hass.io 应用附加包仓库][repository] 添加到您的 Hass.io 实例中。
1. 安装此应用。
1. 点击 `保存` 按钮以存储配置。
1. 启动应用。
1. 查看应用的日志以确认一切正常。
1. 打开 WebUI，可以通过 Ingress 或 `<您的 IP>:端口` 访问。

## 配置

```
port : 8081 #要使用的端口。
```

WebUI 位于 `<您的 IP>:端口`。
