## 关于

这个插件基于 [docker 镜像](https://github.com/remvze/moodist)。

## 安装

这个插件的安装非常简单，与安装任何其他 Hass.io 插件没有区别。

1. [将我的 Hass.io 插件仓库][repository] 添加到你的 Hass.io 实例。
1. 安装这个插件。
1. 点击 `保存` 按钮来保存你的配置。
1. 启动插件。
1. 检查插件的日志，看看是否一切顺利。
1. 应该可以通过 ingress 或 <your-ip>:port 打开 WebUI。

## 配置

```
port : 8081 #你想运行的端口。
```

Webui 可以在 `<your-ip>:port` 找到。
