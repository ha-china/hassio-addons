## 关于

此插件基于 [docker 镜像](https://github.com/remvze/moodist)。

## 安装

安装此插件非常简单，与安装任何其他Hass.io插件没有区别。

1. 将我的Hass.io插件仓库[repository]添加到您的Hass.io实例中。
1. 安装此插件。
1. 点击“保存”按钮以存储您的配置。
1. 启动插件。
1. 检查插件的日志，以查看一切是否顺利。
1. 通过ingress或<your-ip>:port打开WebUI应该可以工作。

## 配置

```
port : 8081 #您想要运行的端口。
```

WebUI可以在 `<your-ip>:port` 找到。
