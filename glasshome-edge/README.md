# GlassHome 仪表盘 (Edge)

[GlassHome](https://glasshome.app) 是专为 Home Assistant 设计的本地优先仪表盘。新功能在此先进行测试，随后才会正式推出至稳定版附加组件中。

![GlassHome 仪表盘，Midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 你应该安装 Edge 吗？

如果你想在功能稳定之前几周就尝试新功能，并且能接受偶尔的性能波动，请安装 **Edge** 版本。如果你用于日常使用，则应该安装此仓库中的稳定版 **GlassHome 仪表盘** 附加组件。

- 运行在端口 **3124** 上，因此可以**并行**安装稳定版附加组件。你可以同时保留两者。
- 需要 **高级模式**：请在 Home Assistant 用户资料中启用它，才能在商店中查看此附加组件。
- 更新频繁。请查看 changelog（更新日志）标签，了解每次构建的具体变更。
- Edge 构建经过测试，但属于预览版。在进行主要版本升级前，请先备份 Home Assistant。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 初次访问？请遵循 [5 分钟快速入门](https://glasshome.app/docs/quickstart)。

## 发现了一些问题？

这正是 Edge 存在的目的。请在 [Discord 错误报告论坛](https://discord.gg/FJYdeDmrzv) 中报告问题，附上你的 Edge 版本号，我们可在其进入稳定版之前修复它。
