# GlassHome 仪表盘 (边缘版)

[GlassHome](https://glasshome.app) 是专为 Home Assistant 设计的本地优先仪表盘，其早期构建版本包含在边缘版中。新功能会在此处进行测试，随后才会随稳定版附加组件发布。

![GlassHome 仪表盘， midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 你需要安装它吗？

如果你希望提前数周体验新功能，并且不介意偶尔出现的粗糙之处，请安装 **Edge** 版本。对于日常使用，请从本仓库安装稳定的 **GlassHome 仪表盘** 附加组件。

- 运行在 **3124** 端口，可在稳定版附加组件**并行运行**。你可以同时保留两者安装。
- 需要 **高级模式**：在 Home Assistant 用户档案中启用它，才能在商店中查看此附加组件。
- 频繁更新。请查阅变更日志标签以了解每次构建更改了什么。
- 边缘版经过测试，但为预发布版本。在版本_major jumps 之前，请备份 Home Assistant。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3.  newcomer？请遵循 [5 分钟快速入门] (https://glasshome.app/docs/quickstart)。

## 发现了什么功能异常？

这正是边缘版所要做的事。请在 [Discord 问题报告论坛](https://discord.gg/FJYdeDmrzv) 报告问题，附上你的边缘版版本，它会在到达稳定版之前得到修复。
