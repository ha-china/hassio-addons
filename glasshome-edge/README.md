# GlassHome Dashboard (Edge)

本地优先的 Home Assistant 仪表板 [GlassHome](https://glasshome.app) 的早期构建版本。新功能在此处进行测试，在稳定版附加组件发布前更新。

![GlassHome 仪表板，午夜玻璃主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 是否应该安装此版本？

如果您想提前几周尝试新功能，并且不介意偶尔出现的粗糙之处，请安装 **Edge** 版。对于日常使用，请从同一仓库安装稳定的 **GlassHome Dashboard** 附加组件。

- 运行在端口 **3124** 上，可以**与稳定版附加组件并排运行**。您可以同时保留两者安装。
- 需要开启 **高级模式**：请在 Home Assistant 用户资料中启用它，以便在该商店中看到此附加组件。
- 更新频率高。查看更新日志标签以查看每次构建更改了什么。
- Edge 构建经过测试，但属于预发布版本。在 Major 版本号变化前，请备份 Home Assistant。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3.  newcomers？请按照 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart) 操作。

## 发现了什么故障？

这正是 Edge 版存在的意义。请在 [Discord 问题报告论坛](https://discord.gg/FJYdeDmrzv) 中提交问题，并提供您的 Edge 版本，它将在进入稳定版之前就被修复。
