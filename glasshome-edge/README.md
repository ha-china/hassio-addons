# GlassHome 仪表板 (边缘版)

[GlassHome](https://glasshome.app) 是专为 Home Assistant 设计的本地优先仪表板。新的功能会先在此处供测试，稳定版附加组件发布前会更新此处。

![GlassHome 仪表板，Midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 您应该安装这个吗？

如果您想提前几周尝鲜新特性，并且不介意不时的小瑕疵，请安装 **Edge** 版。对于日常使用，建议改用此仓库中的稳定版 **GlassHome Dashboard** 附加组件。

- 运行在端口 **3124** 上，因此可以与稳定版附加组件**并行工作**。您可以同时保留两个安装。
- 需要开启 **高级模式**：请在 Home Assistant 用户个人资料中启用它，以便在商店中查看此附加组件。
- 更新频繁。查看更新日志标签，了解每个构建版本的具体改动。
- Edge 构建经过测试，但仍属预发布版本。Major 版本更新前，请对 Home Assistant 进行备份。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 初次使用？跟随 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart)。

## 发现错误了吗？

这正是 Edge 的作用所在。请在 [Discord 错误报告论坛](https://discord.gg/FJYdeDmrzv) 报告问题，注明您的 Edge 版本，它将在这项功能从未进入稳定版前就被修复。
