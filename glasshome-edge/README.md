# GlassHome 仪表盘 (Edge)

GlassHome 是一款本地优先的 Home Assistant 仪表板，地址为 [GlassHome](https://glasshome.app)。新功能在此处先行测试，稳定版插件发布前才会在此上架。

![GlassHome 仪表盘，午夜玻璃主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 您应该安装这个吗？

如果您想提前几周试用新功能，并能够接受偶尔出现的粗糙边缘，请安装 **Edge** 版本。对于日常使用，请从同一仓库安装稳定的 **GlassHome 仪表盘** 插件而不是 Edge 版本。

- 运行在端口 **3124**，因此它可以与稳定版插件**并行工作**。您可以同时保留两个版本。
- 需要 **高级模式**：在您的 Home Assistant 用户档案中启用它，才能在商店中看到这个插件。
- 更新频繁。请检查更新日志标签，了解每个构建版本更改了什么。
- Edge 构建经过测试，但属于预览版。在版本重大跳变前，请备份 Home Assistant。

## 开始使用

1. 安装并启动插件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 如果您是新手，请跟随 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart)。

## 发现什么错误了吗？

这正是 Edge 所在的位置。请在 [Discord 缺陷报告论坛](https://discord.gg/FJYdeDmrzv) 中报告它，附上您的 Edge 版本，问题在到达稳定版之前就会得到修复。
