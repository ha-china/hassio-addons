# GlassHome Dashboard (Edge)

GlassHome (https://glasshome.app) 的早期构建版本，这是一个本地优先的 Home Assistant 仪表板。新功能会在此处进行测试，然后发布于稳定版附加组件中。

![GlassHome 仪表板，Midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 你应该安装它吗？

如果你希望提前几周尝试新功能，并且能忍受偶尔的不完美，请安装 **Edge** 版本。对于日常使用，请在同一仓库中安装稳定的 **GlassHome Dashboard** 附加组件。

- 运行在端口 **3124** 上，因此可以 **并列** 运行稳定版附加组件。你可以同时保留两者安装。
- 需要 **高级模式**：在 Home Assistant 用户资料中启用它，才能在商店中看到这个附加组件。
- 更新频繁。查看变更日志选项卡，了解每次构建更改了什么。
- Edge 构建经过测试，但属于预发布版本。在升级到主要版本前，请备份 Home Assistant。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 新手？请跟随 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart)。

## 发现 bug 了？

这正是 Edge 存在的用途。在 [Discord 错误报告论坛](https://discord.gg/FJYdeDmrzv) 报告它，并提供你的 Edge 版本，它将在到达稳定版之前得到修复。
