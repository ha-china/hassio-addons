# GlassHome 仪表盘 (边缘版)

[GlassHome](https://glasshome.app) 是专为 Home Assistant 设计的本地优先仪表盘的最新早期版本。新功能在此进行测试，随后才会发布到稳定版附加组件中。

![GlassHome 仪表盘，Midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 您应该安装此版本吗？

如果您想提前几周体验新功能并且不介意偶尔出现的一些小瑕疵，请安装 **Edge** 版本。如果您希望用于日常使用，建议从同一存储库中安装稳定的 **GlassHome 仪表盘** 附加组件。

- 运行在端口 **3124** 上，因此它可以与稳定版附加组件**并列运行**。您可以同时保留两个版本。
- 需要启用 **高级模式**：在您的 Home Assistant 用户资料中启用它，才能在商店中看到该附加组件。
- 更新频繁。请查看“更新日志”选项卡，以了解每个构建版本具体做了什么更改。
- Edge 构建经过测试，但仍为预览版。在主要版本跳跃之前，请备份 Home Assistant。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 这是您第一次访问吗？请遵循 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart)。

## 发现什么出问题了？

这正是 Edge 版本存在的意义。请在 [Discord 错误报告论坛](https://discord.gg/FJYdeDmrzv) 中报告问题（注明您的 Edge 版本号），这样问题就在新功能到达稳定版之前得到修复。
