# GlassHome Dashboard (Edge)

本地优先的 Home Assistant 仪表盘 [GlassHome](https://glasshome.app) 的早期构建版本。新功能会在此进行测试，随后再发布到稳定版附加组件中。

![GlassHome 仪表盘，Midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 你是否应该安装这个？

如果你想在几周之前尝试新功能且能接受偶尔的不完美，请安装 **Edge** 版。对于日常使用，请从相同的仓库安装稳定的 **GlassHome Dashboard** 附加组件。

- 运行在端口 **3124**，因此可以**并行运行**稳定版附加组件。你可以同时保留两个版本。
- 需要 **高级模式**：在你的 Home Assistant 用户个人资料中启用它，才能在商店中看到此附加组件。
- 更新频繁。请查看更新日志选项卡，了解每个构建更改了什么。
- Edge 构建经过测试，但属于抢先版。在大版本升级前请备份 Home Assistant。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 新用戶？请遵循 [5 分钟快速入门](https://glasshome.app/docs/quickstart)。

## 发现了一些破损的问题？

这正是 Edge 的用场。请在 [Discord 错误报告论坛](https://discord.gg/FJYdeDmrzv) 中报告，并在其中注明你的 Edge 版本，这样在问题进入稳定版之前就会被修复。
