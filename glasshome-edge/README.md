# GlassHome Dashboard (Edge)

Early builds of [GlassHome](https://glasshome.app), the local-first dashboard for Home Assistant. New features land here for testing before they ship in the stable add-on.

![GlassHome dashboard, Midnight Glass theme](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## Should you install this?

Install **Edge** if you want to try new features weeks early and don't mind the occasional rough edge. For daily use, install the stable **GlassHome Dashboard** add-on from this same repository instead.

- Runs on port **3124**, so it works **side by side** with the stable add-on. You can keep both installed.
- Requires **Advanced Mode**: enable it in your Home Assistant user profile to see this add-on in the store.
- Updates frequently. Check the changelog tab to see what each build changes.
- Edge builds are tested, but pre-release. Back up Home Assistant before major version jumps.

## Getting started

1. Install and start the add-on.
2. Open `http://homeassistant.local:3124` (or `http://YOUR_HA_IP:3124`).
3. New here? Follow the [5-minute quickstart](https://glasshome.app/docs/quickstart).

## Found something broken?

That's exactly what Edge is for. Report it in the [Discord bug-reports forum](https://discord.gg/FJYdeDmrzv) with your Edge version, and it gets fixed before it ever reaches stable.
