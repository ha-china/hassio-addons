# GlassHome 仪表盘 (边缘版)

[GlassHome](https://glasshome.app) 是用于 Home Assistant 的本地优先仪表盘。其早期构建版本在此处进行测试，以确保推出稳定版附加组件前的新特性。

![GlassHome 仪表盘，午夜玻璃主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 您应该安装这个吗？

如果您希望在几周前尝试新功能并能接受偶尔的不稳定，请安装 **Edge** 版本。对于日常使用，请从相同的仓库中安装稳定的 **GlassHome 仪表盘** 附加组件。

- 运行在端口 **3124**，因此可以与稳定版附加组件 **并驾齐驱**。您可以同时保留两个安装。
- 需要 **高级模式**：请在家 Assistant 用户个人资料中启用它，以便在商店中看到此附加组件。
- 更新频繁。请在更改日志选项卡中查看每个构建更改了什么。
- Edge 构建已测试，但属于预发布版本。在主要版本升级前请备份 Home Assistant。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 新人？请遵循 [5 分钟快速上手指南](https://glasshome.app/docs/quickstart)。

## 发现了一些问题？

这正是 Edge 存在的意义。请在 [Discord 错误报告论坛](https://discord.gg/FJYdeDmrzv) 报告中您的 Edge 版本，它会在进入稳定版前得到修复。
