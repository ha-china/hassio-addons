# GlassHome 仪表盘 (Edge 版)

[GlassHome](https://glasshome.app) 是为 Home Assistant 设计的本地化仪表盘。[Edge](https://github.com/mobilitygeek/glasshome-dashboard/releases) 版本用于在功能稳定前进行测试。

![GlassHome 仪表盘，Midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

## 是否需要安装此版本？

如果您想提前几周尝试新功能并且不介意偶尔会出现一些问题，请安装 **Edge** 版。对于日常使用，建议从同一仓库安装稳定的 **GlassHome 仪表盘** 附加组件。

- 运行在 **3124** 端口，因此可以与稳定版附加组件 **并排运行**。你可以同时安装两个版本。
- 需要开启 **高级模式**：在你的 Home Assistant 用户资料中启用它，才能在该商店中看到此附加组件。
- 更新频繁。请查看变化日志（Changelog）选项卡，了解每次构建的具体变更。
- Edge 版本经过测试，但属于预发布版本。请务必在发生重大版本升级前对 Home Assistant 进行数据备份。

## 开始使用

1. 安装并启动附加组件。
2. 打开 `http://homeassistant.local:3124`（或 `http://YOUR_HA_IP:3124`）。
3. 如果是新手，请按照 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart) 操作。

## 发现哪里出错了？

这正是 Edge 存在的意义所在！请在 [Discord 的问题报告论坛](https://discord.gg/FJYdeDmrzv) 提交问题，并提供你的 Edge 版本信息，我们的团队会在工作室版本还尚未稳定之前就进行修复。
