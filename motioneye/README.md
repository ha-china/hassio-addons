为您的摄像头提供简单、优雅且功能丰富的 CCTV/NVR（监控与录像机）。

## 关于

motionEye 是一个流行的前端，用于名为“运动（motion）”的摄像头软件。此应用程序支持两者，允许您将摄像头添加到您的 Home Assistant 设置中。

motionEye 是一个开源的 CCTV 和 NVR，既优雅又真正易于使用。它可用于婴儿监护器、施工现场监控_viewer、商店摄像头 DVR、花园安全监控等，用途更多。

motionEye 的一些酷功能：

- 支持大量摄像头，包括 IP 摄像头。
- 可以通过连接多个 motionEye 实例一起添加多个摄像头。
  例如，通过在您的网络中使用运动操作系统（MotionEyeOS）Pi Zero + Pi摄像头。
- 支持将录像上传到 Google Drive 和 Dropbox。
- 支持运动检测，包括邮件通知和调度。
- 可连续记录、运动检测或延时摄影，并支持保留设置。
