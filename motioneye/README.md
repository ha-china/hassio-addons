## 简介

motionEye 是一款面向名为 motion 的摄像头软件的流行前端应用程序。该应用程序提供双重功能，允许您将摄像头添加到您的 Home Assistant 设置中。

motionEye 是一款开源的 CCTV 和 NVR，设计优雅且使用起来非常简单。它可用于婴儿监视器、建筑工地监控查看器、商店摄像头录像机、家庭安全监控以及更多用途。

motionEye 的一些酷炫功能：

- 支持大量数量的摄像头，包括 IP 摄像头。
- 通过连接多个 motionEye 实例添加多个摄像头。
  例如，在网络中使用 MotionEyeOS 配合 Pi Zero + Pi 摄像头。
- 支持将录像上传到 Google Drive 和 Dropbox。
- 支持运动检测，包括电子邮件通知和计划调度。
- 可支持连续录制、运动检测录制或延时摄影录制，并可设置保留策略。
