## 简介

motionEye 是名为 motion 的摄像头软件的热门前端。此应用提供了该功能，允许您将摄像头添加到您的 Home Assistant 设置中。

motionEye 是开源的 CCTV 和 NVR，设计优雅且非常容易使用。它可以用作婴儿监视器、建筑工地监控查看器、商店摄像头 DVR、家庭安防监控等，用途广泛。

motionEye 的一些酷炫功能：

- 支持惊人的摄像头数量，包括 IP 摄像头。
- 可以通过连接多个 motionEye 实例实例来添加多个摄像头。
  例如，您可以在网络中使用 MotionEyeOS 搭配 Pi Zero 和 Pi 摄像头。
- 支持将录像上传至 Google Drive 和 Dropbox。
- 具备运动检测功能，包括邮件通知和定时计划。
- 可设置保留策略，进行连续录像、运动录像或延时摄影。
