## 关于

[Jellyfin][jellyfin] 是一个媒体服务器。指向存放您的电影、系列和音乐的文件夹，它就会识别所有内容，收集艺术图片和描述，并将所有内容传输到您想观看的任意设备：浏览器、手机、平板电脑、游戏机或电视。

它不会向外发送任何信息。无需注册账户，无订阅，也没有付费版功能限制；您本地机器上的服务器就是全部产品。此应用让该服务器运行在 Home Assistant 旁边，其图书库位于与您的其他应用相同的 `media` 文件夹中。

当设备无法直接播放文件时，转码任务可以交给 Intel 或 AMD 显卡，使用 Jellyfin 项目提供的相同修补版 FFmpeg。Home Assistant 内置的 [Jellyfin 集成][integration] 将图书库引入媒体浏览器，并将从中播放的设备作为媒体播放器。
