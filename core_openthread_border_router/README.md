## 原始 readme。

OpenThread Border Router 附加组件。该插件使用上游 OpenThread
Border Router 实现，并将其封装为 Home Assistant 的附加组件。

**注意：** 这需要支持 OpenThread
RCP 固件的 802.15.4 射频设备。如果您使用的是 [Home Assistant Yellow](https://www.home-assistant.io/yellow/) 或 [Home Assistant Connect ZBT-1](https://www.home-assistant.io/connectzbt1/)（以前称为 SkyConnect），
则会自动安装正确的固件。

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

## 关于

此附加组件允许您组建或加入 Thread 网络，并使 Home Assistant
成为 Thread Border Router。
