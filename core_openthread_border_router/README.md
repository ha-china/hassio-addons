## 原始 README。

OpenThread 边界路由器附加组件。该附加组件使用上游 OpenThread 边界路由器实现，并将其封装为 Home Assistant 的附加组件。

**注意：** 这需要支持带有 OpenThread RCP 固件的 802.15.4 兼容无线电。如果您使用的是 [Home Assistant Yellow](https://www.home-assistant.io/yellow/) 或 [Home Assistant Connect ZBT-1](https://www.home-assistant.io/connectzbt1/)（之前称为 SkyConnect），则会自动安装正确的固件。

![支持 aarch64 架构][aarch64-shield]
![支持 amd64 架构][amd64-shield]

## 关于此内容

此附加组件允许您建立或加入 Thread 网络，并将 Home Assistant 用作 Thread 边界路由器。
