# GlassHome 仪表盘

一个精美、以本地为主的 Home Assistant 仪表盘。无需 YAML，无需云端，没有任何杂乱信息。

![GlassHome 仪表盘，午夜玻璃主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

GlassHome 位于您的 Home Assistant 前端，将其转变为整个家庭都能使用的仪表盘。它径直通过 WebSocket 连接 Home Assistant，并完全运行在您的硬件上：无需云端中继，无需遥测数据。

## 为什么你一定会喜欢它

- **堪称精品应用。** 具有圆润、分层、以触控为优先的设计，适用于墙壁平板电脑、手机和桌面 alike。
- **直接在界面中构建。** 拖拽、放置和缩放仪表盘组件。无需 YAML，无需重启即可应用更改。
- **按房间组织。** 按区域组织，提供用于灯光、气候、带图表的传感器、摄像头、天气、场景、电池等的仪表盘组件。
- **随心定制。** 内置九个主题，每个主题都包含完整的光模式和暗模式。
- **随你成长。** 从 GlassHome Hub 安装社区仪表盘组件，或使用 [Widget SDK](https://glasshome.app/docs/widget-development) 构建自己的。

每个房间都有专属仪表盘，只需轻触即达：

## 开始使用

1. 安装并启动附加组件。开箱即用，无需配置。
2. 打开 `http://homeassistant.local:3123`（或 `http://YOUR_HA_IP:3123`）。
3. 按照 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart) 进行连接并添加您的第一个仪表盘组件。

GlassHome 正在积极开发中。如果某些内容无法与您的设置正常工作，请告诉我们。
