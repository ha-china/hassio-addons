# GlassHome 仪表盘

一款美观、本地优先的 Home Assistant 仪表盘。无需 YAML，无需云端，整洁无冗余。

![GlassHome 仪表盘，午夜玻璃主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

GlassHome 置于您的 Home Assistant 前方，将其转化为全家人都能使用的仪表盘。它直接通过 WebSocket 连接 Home Assistant，并完全运行在您自己的硬件上：无需云端中继，无需遥测数据。

## 您会喜欢它的理由

- **感觉像一款高端应用。** 采用圆润、分层、触控优先的设计，适用于墙上平板电脑、手机和台式机 alike。
- **在 UI 中构建。** 拖拽、放置和调整大小组件。无需 YAML，无需重启即可应用更改。
- **按房间组织。** 按区域整理，包含灯光、气候、带图表的传感器、摄像头、天气、场景、电池和更多功能的组件。
- **打造属于您的风格。** 内置七种主题，每种都具备完整的亮区和暗区模式。
- **随您需要成长。** 从 GlassHome Hub 安装社区组件，或使用 [组件 SDK](https://glasshome.app/docs/widget-development) 构建您自己的组件。

## 开始使用

1. 安装并启动附加组件。开箱即用，无需配置。
2. 打开 `http://homeassistant.local:3123`（或 `http://YOUR_HA_IP:3123`）。
3. 按照 [5 分钟快速入门指南](https://glasshome.app/docs/quickstart) 进行连接并添加您的第一个组件。

GlassHome 正处于积极开发中。如果您发现某些内容在您当前的设置中不起作用，请告诉我们。
