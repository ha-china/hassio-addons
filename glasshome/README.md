# GlassHome 控制面板

一个美丽、本地优先的 Home Assistant 控制面板。无需 YAML，无需云端，无杂乱。

![GlassHome 控制面板，Midnight Glass 主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

GlassHome 位于您的 Home Assistant 前端，将其变成全家都可以使用的控制面板。它通过 WebSocket 直接连接到 HA，并在您自己的硬件上运行：无云端中继，无遥测数据。

## 为什么你会喜欢它

- **感觉像是一款高端应用。** 圆润、分层、以触摸优先的设计，适用于壁挂平板、手机和桌面。
- **内置 UI。** 拖放和调整小部件大小。无需 YAML，无需重启以应用更改。
- **按房间组织。** 使用灯光、气候、带有图表的传感器、摄像头、天气、场景、电池等小部件按区域组织。
- **个性化定制。** 七种内置主题，每个主题都包含完整的浅色和深色模式。
- **随你成长。** 从 GlassHome Hub 安装社区小部件，或使用 [小部件 SDK](https://glasshome.app/docs/widget-development) 创建您自己的小部件。

## 开始使用

1. 安装并启动此附加组件。它即装即用，无需配置。
2. 打开 `http://homeassistant.local:3123`（或 `http://YOUR_HA_IP:3123`）。
3. 按照文档中的 [5分钟快速入门](https://glasshome.app/docs/quickstart) 指引连接并添加您的第一个小部件。

GlassHome 正在积极开发中。如果您发现某些功能与您的设置不兼容，我们希望听到您的反馈。
