# GlassHome Dashboard

现代、可定制的 Home Assistant 仪表盘，拥有美观的玻璃形态设计。

## 免责声明：
这是一个测试版本。如果你的设置非常个性化，它可能无法正常工作。我不期望它会崩溃烧毁，因为我已经在我的设置上进行了彻底测试，但请谨慎操作并备份你的 Home Assistant！

## 安装

1. 将此存储库添加到你的 Home Assistant：
   - 设置 → 添加组件 → 组件商店
   - 点击 ⋮（菜单）→ 存储库
   - 添加：`https://github.com/glasshome/glasshome-addon`

2. 从组件商店安装 "GlassHome Dashboard"

3. 启动组件

## 功能

- 🎨 美观的玻璃形态设计，支持深色模式
- 🖱️ 拖放式小部件定制
- 🏠 基于区域的组织
- 📊 多种小部件类型：
  - 带颜色控制的灯光
  - 气候控制
  - 带图表的传感器
  - 带实时流的摄像头
  - 天气
  - 场景
  - 电池监控
- 💾 持久性仪表盘配置
- 🔐 安全认证

## 访问仪表盘

启动组件后，打开浏览器并访问：
- `http://homeassistant.local:3123`（如果你使用 .local 域名）
- `http://YOUR_HA_IP:3123`（将 YOUR_HA_IP 替换为你的 HA IP 地址）

## 配置

目前无需配置选项 - 即插即用！
