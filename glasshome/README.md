# GlassHome 仪表盘

一个美观、以本地优先的 Home Assistant 仪表盘。无需 YAML，无需云端，无需杂乱。

![GlassHome 仪表盘，午夜玻璃主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

GlassHome 覆盖在您的 Home Assistant 之上，将其变成一个整个家庭都可以使用的仪表盘。它通过 WebSocket 直接连接到 HA，并完全运行在您自己的硬件上：没有云端中继，没有遥测数据。

## 您将喜爱的理由

- **具有高级应用的感觉。** 圆润的层级设计，优先触控，适用于墙载平板、手机和台式机。
- **在 UI 内置。** 拖拽、放置和调整小部件大小。无需 YAML，无需重启即可应用。
- **按房间组织。** 按区域组织，配备用于灯光、气候、带图表的传感器、摄像头、天气、场景、电池等的小部件。
- **按您的喜好定制。** 九个内置主题，每个主题都包含完整的光亮和黑暗模式。
- **随您成长。** 从 GlassHome Hub 安装社区小部件，或使用 [小部件 SDK](https://glasshome.app/docs/widget-development) 构建您自己的。

每个房间都有自己的仪表盘，只需一次点击即可访问：

## 开始使用

1. 安装并启动附加组件。开箱即用，无需配置。
2. 打开 `http://homeassistant.local:3123`（或 `http://YOUR_HA_IP:3123`）。
3. 按照 [5 分钟快速入门](https://glasshome.app/docs/quickstart) 连接并添加第一个小部件。

GlassHome 正处于积极开发中。如果某些内容与您的设置不兼容，请告诉我们。
