# GlassHome 仪表盘

一款美观、本地优先的 Home Assistant 仪表盘。无需 YAML，无需云端，无需杂乱。

![GlassHome 仪表盘，午夜玻璃主题](https://glasshome.app/assets/screenshots/home-midnight-glass-dark-desktop.webp)

GlassHome 位于您的 Home Assistant 前方，将其转变为整个家庭均可使用的仪表盘。它直接通过 WebSocket 连接到 HA，并完全运行在您自己的硬件上：无需云端中继，无需遥测数据。

## 您将喜欢它的理由

- **宛如高端应用。** 针对墙壁平板、手机和桌面 alike 设计的圆润、分层、以触控为主的设计。
- **在界面中构建。** 拖拽、放置和缩放小部件。无需 YAML，无需重启才能应用。
- **按房间组织。** 按区域组织，为灯光、气候、带图表的传感器、摄像头、天气、场景、电池等提供小部件。
- **按您的喜好定制。** 内置七个主题，每个主题都包含完整的光暗模式。
- **随您成长。** 从 GlassHome Hub 安装社区小部件，或通过使用 [Widget SDK](https://glasshome.app/docs/widget-developement) 自行构建。

## 开始使用

1. 安装并启动附加组件。开箱即用，无需配置。
2. 打开 `http://homeassistant.local:3123`（或 `http://YOUR_HA_IP:3123`）。
3. 遵循 [5 分钟快速开始指南](https://glasshome.app/docs/quickstart) 进行连接并添加您的第一个小部件。

GlassHome 正处于积极开发中。如果某内容在您设置的设备上不起作用，请告诉我们。
