# Home Assistant 社区应用：Prowlarr

这是一个基于流行的 arr 堆栈（torrenttracker）构建的索引器管理器/代理，旨在与您的各种 PVR 应用进行集成。

## 简介

[Prowlarr] 是一个基于流行的 *arr .net/reactjs* 基础堆栈构建的索引器管理器/代理，旨在与您的各种 PVR 应用进行集成。Prowlarr 支持对托特追踪器（Torrent Trackers）和用户网索引器（Usenet Indexers）的管理。它与 Lidarr、Mylar3、Radarr、Readarr 和 Sonarr 无缝集成，为索引器提供完整的管理，无需为每款应用单独设置索引器（它包罗万象）。
