# Home Assistant 社区应用：Prowlarr

[![发布][release-shield]][release] ![项目阶段][project-stage-shield] ![维护状态][maintenance-shield]

基于流行的 arr 栈构建的索引器管理器/代理，可集成到您的各种 PVR 应用中。

## 关于

[Prowlarr] 是一个基于流行的 *arr .net/reactjs* 基础栈构建的索引器管理器/代理，旨在集成到您的各种 PVR 应用中。Prowlarr 支持 Torrent Trackers（种子站）和 Usenet Indexers（新闻源索引器）的管理。它与 Lidarr、Mylar3、Radarr、Readarr 和 Sonarr 无缝集成，为您所有应用的管理器提供完整的管理功能，无需为每个应用单独设置索引器（它包罗万象）。
