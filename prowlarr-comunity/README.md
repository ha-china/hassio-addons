## 关于

[Prowlarr] 是一个基于流行的 *arr .net/reactjs 基础堆栈构建的索引器管理器/代理，用于与您的各种 PVR 应用集成。Prowlarr 支持管理和使用 Torrent 跟踪器和 Usenet 索引器。它可以与 Lidarr、Mylar3、Radarr、Readarr 和 Sonarr 无缝集成，为您提供全面的索引器管理，无需每个应用单独设置索引器（它可以全部处理）。
