# Home Assistant 附加组件：Tesla HTTP 代理

此附加组件会运行官方的 [Tesla HTTP 代理](https://github.com/teslamotors/vehicle-command)，以允许对现代车辆执行车队 API 请求。请勿为此事联系 Tesla 寻求支持。

## 简介

运行车队 API 授权程序，然后运行 Tesla 的 HTTP 代理代码（使用 Go 语言）。同时也运行一个简单的 Web 服务器，允许您将公开密钥注册到您的车辆。

设置此附加组件相当复杂。详情请阅读 [DOCS.md](https://github.com/llamafilm/tesla-http-proxy-addon/blob/main/tesla_http_proxy/DOCS.md)。如果您需要帮助，可以尝试在 GitHub 上发起讨论。除非您发现了 bug，否则请勿创建问题报告。
