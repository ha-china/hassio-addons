# Home Assistant 扩展：Tesla HTTP 代理

此扩展运行官方的 [Tesla HTTP Proxy](https://github.com/teslamotors/vehicle-command)，允许在现代车辆上进行车队 API 请求。请勿为此向 Tesla 寻求支持。

## 关于
通过车队 API 授权程序运行，然后在 Go 中运行 Tesla 的 HTTP 代理代码。同时运行一个简单的 Web 服务器，允许您将公钥注册到您的车辆中。

设置此扩展相当复杂。请阅读 [DOCS.md](https://github.com/llamafilm/tesla-http-proxy-addon/blob/main/tesla_http_proxy/DOCS.md) 获取详细信息。如果您需要帮助，您可以在 GitHub 上尝试发起一次讨论。除非您已发现一个错误，否则请勿打开一个问题。
