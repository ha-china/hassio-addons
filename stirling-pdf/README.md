## 关于

[斯滕利 PDF][斯滕利 PDF] 是为那些落入收件箱却不完全符合你需求的那些 PDF 文件打造的工作坊。合并、拆分、旋转、裁剪和重新排序页面。压缩过大的扫描文件。将 Word 文档、电子表格、网页或一组照片转换为 PDF，并将 PDF 转换回原始格式。签名、盖章、添加水印、填写表格或排除不应出现的部分。

它也具备阅读功能。一场 OCR 扫描将文本图片中的扫描页面转换为可搜索、可选择和复制的文本，这正是扫描堆与档案之间的区别。

一切都在本地完成。文件上传到此应用，在此进行处理后交回，这就是推荐理由：与其将银行陈述粘贴到免费网站，不如自己运行它。
