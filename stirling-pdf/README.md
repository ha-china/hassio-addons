## 关于

[Stirling PDF][stirling-pdf] 是为您处理落入收件箱中、但并非正符合您需求的 PDF 文档的工作站。它可以合并、拆分、旋转、裁剪和重新排序页面。压缩那些大到无法发送的扫描件。将 Word 文档、电子表格、网页或一系列照片转换为 PDF，并可将 PDF 转回原格式。它可以签名、盖章、添加水印、填写表单或黑出那些本不该出现的部分。

它还能识别文字。OCR 功能将扫描文件的图片文字转换为您可以搜索、选择和复制的真实文本，这正是一堆扫描件与真正档案之间的区别。

所有操作都无需离开您的设备。文件上传到本应用中进行处理，然后传回给您，这正是您需要自行运行它而非粘贴银行账单到免费网站的原因。
