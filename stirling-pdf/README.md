## 关于

[Stirling PDF][stirling-pdf] 是处理你邮箱收到的那份“不太符合你需求”的 PDF 的解决方案。它可以合并、拆分、旋转、裁剪和重组页面。将过大的扫描文件压缩以便发送。将 Word 文档、电子表格、网页或一组照片转换为 PDF，并可以将 PDF 转换回原格式。你可以对其签名、加盖印章、添加水印、填写表单，或者遮盖不应当出现在其中的部分内容。

它也能读取文档。OCR 处理可以将扫描后的图片文本转换为可搜索、可选择和可复制的文本，这与仅仅堆叠一堆扫描件有着天壤之别。

所有这些操作都无需离开你的设备。文件上传至本应用，在此处进行处理然后送回，这才是你自行运行它而非将银行账单粘贴到免费网站上的全部理由。
