## 关于我们

[Stirling PDF][stirling-pdf] 是一个针对落入您的收件箱但并非完全符合您需要的那种 PDF 的工作坊。执行合并、拆分、旋转、裁剪和重排页面。压缩一个过大无法发送的扫描文件。将 Word 文档、电子表格、网页或一系列照片转换为 PDF，并将 PDF 转换回原格式。对其进行签名、盖章、添加水印、填写表格，或涂抹掉本不应包含的部分。

它还可以读取内容。OCR 处理将文本的扫描件从图片文本转换为您可以搜索、选择和复制的文本，这正是扫描件堆砌与档案库之间的区别。

无需任何数据离开您的住所。文件上传至此应用，在此处处理后返回，这就是您自己运行它而不是将银行账单粘贴到免费网站上的全部原因。
