## 关于

[Stirling PDF][stirling-pdf] 是为您收件箱中的 PDF 文件打造的工具，这些文件可能并非完全如您所需。您可以合并、拆分、旋转、裁剪和重新排列页面。压缩扫描件以减轻过大体积，使其易于发送。将 Word 文档、电子表格、网页或相册文件夹转换为 PDF，并可将 PDF 转换回原文档格式。对其进行签署、盖章、添加水印、填写表格或涂抹不需要的部分。

它还能识别文字。OCR 处理可将扫描页上的图像文字转换为您可以搜索、选择和复制的文本，这正是扫描件堆叠与档案之间的区别。

所有操作都在本地完成。文件上传到此应用，在这里进行编辑处理，然后返回给您，这正是您自行运行它而非将银行账单粘贴到免费网站上的原因。
