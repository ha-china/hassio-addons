# Home Assistant 附加组件：Omni Tools

## 简介

Omni Tools 是一个自托管 Web 应用程序，为日常任务提供多种在线实用工具。所有文件处理均在客户端完成，确保隐私和安全。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

## 功能

- **图像工具**：图像尺寸调整和转换器
- **视频工具**：视频剪辑器
- **PDF 工具**：PDF 分割和合并
- **文本文档/列表工具**：各种文本文档处理实用工具
- **日期和时间工具**：日期/时间计算器和转换器
- **数学工具**：数学计算器和转换器
- **数据工具**：JSON、CSV、XML 处理器

## 安装

1. 将我的附加组件存储添加至 Home Assistant 实例（在 supervisor 附加组件存储右上角，或如果您已配置 Home Assistant，可点击下方按钮）
   [![打开您的 Home Assistant 实例，并在显示“添加附加组件存储”对话框时预填充特定存储库 URL。](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Falexbelgium%2Fhassio-addons)
2. 安装"Omni Tools"附加组件
3. 启动附加组件
4. 打开 Web 界面

## 配置

### 选项：`PUID`

运行应用程序的用户 ID。默认为 `0`。

### 选项：`PGID`

运行应用程序的组 ID。默认为 `0`。

### 选项：`TZ`

应用程序的时区设置。

## 使用说明

1. 通过 Home Assistant 侧边栏或导航到附加组件的 Web 界面访问 Web 界面
2. 从以下工具类别中选择：
   - 图像/视频/音频处理
   - PDF 操作
   - 文本文档和列表处理
   - 日期和时间实用工具
   - 数学工具
   - 数据格式转换

所有处理都在您的浏览器本地进行，以实现最大隐私和安全。

### 环境变量

使用附加组件的 `env_vars` 选项传递额外的环境变量（大写或小写名称）。有关详细信息，请参阅 https://github.com/alexbelgium/hassio-addons/wiki/Add-Environment-variables-to-your-Addon-2。
