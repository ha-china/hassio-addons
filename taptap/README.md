# Home Assistant 扩展：taptap - Tigo CCA 到 MQTT

Tigo CCA Tap 到 MQTT 实现将数据从 Tigo 优化器本地获取到 Home Assistant。查看 [文档](https://github.com/litinoveweedle/hassio-addons/blob/main/taptap/DOCS.md) 了解所需的硬件安装和使用方法。
