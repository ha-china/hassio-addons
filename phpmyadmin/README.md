官方 MariaDB 应用的网页界面。

## 关于

这是官方 phpMyAdmin 应用的复刻版，专为测试而制。  
请勿使用，因为随时可能失效。

phpMyAdmin 是用于 MySQL 和 MariaDB 的数据库管理工具。可以通过用户界面执行频繁操作（管理数据库、表、列、关系、索引、用户、权限等），同时您仍可直接执行任何 SQL 语句。

该应用专为管理官方 Home Assistant MariaDB 应用而设计。
