## 关于

phpMyAdmin 是 MySQL 和 MariaDB 的数据库管理工具。许多常见操作（如管理数据库、表、列、关系、索引、用户、权限等）都可以通过用户界面执行，而您也可以直接执行任何 SQL 语句。

这款应用专门设计用于管理官方的 Home Assistant MariaDB 应用。
