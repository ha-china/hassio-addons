这是一个用于官方 MariaDB 应用的 Web 界面。

## 关于

phpMyAdmin 是 MySQL 和 MariaDB 的数据库管理工具。常用操作（管理数据库、表、列、关系、索引、用户、权限等）可以通过用户界面执行，同时您仍具备直接执行任何 SQL 语句的能力。

此应用是专门为管理官方 Home Assistant MariaDB 应用而设计的。
