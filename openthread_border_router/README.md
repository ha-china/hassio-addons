# Home Assistant App：OpenThread 边界路由器应用

OpenThread 边界路由器应用（前身为附加组件）。该应用使用上游的 OpenThread 边界路由器实现，并将其封装为 Home Assistant 的应用。

**注意：** 需要使用支持 802.15.4 功能的无线电设备及 OpenThread RCP 程序。如果您使用的是 [Home Assistant Yellow](https://www.home-assistant.io/yellow/) 或 [Home Assistant Connect ZBT-1](https://www.home-assistant.io/connectzbt1/)（以前称为 SkyConnect），则正确的程序会自动安装。

![支持 aarch64 架构][aarch64-shield]
![支持 amd64 架构][amd64-shield]

## 关于

该应用可让您组网或加入 Thread 网络，并将 Home Assistant 配置为 Thread 边界路由器。
