# Home Assistant 社区应用：MQTT IO

[![发布][发布徽章]][发布] ![项目阶段][项目阶段徽章] ![项目维护][维护徽章]

通过 MQTT 暴露 GPIO 模块和数字传感器，以实现远程控制和监控。

## 关于

通过将通用输入输出（GPIO）、硬件传感器和串行设备暴露到 MQTT 服务器中，实现即时控制与服务。非常适合单板计算机（如 Raspberry Pi）。
