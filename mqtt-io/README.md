# Home Assistant 社区应用：MQTT IO

[![Release][release-shield]][release] ![项目阶段][project-stage-shield] ![项目维护状态][maintenance-shield]

通过 MQTT 暴露 GPIO 模块和数字传感器，用于远程控制和监控。

## 关于

将通用输入输出（GPIO）、硬件传感器和串行设备暴露给 MQTT 服务器。适用于单板计算机，如树莓派。
