## 关于

[Syncthing][syncthing] 是一款连续文件同步程序。它能在两台或多台计算机之间同步文件，并用它来替代专有同步和云服务，提供开放、可信且去中心化的方案。

您的数据只属于您，您有权决定数据存储的地点、是否与第三方共享以及如何通过互联网传输。

此应用将 Syncthing 直接放在您的 Home Assistant 实例旁边，配置、媒体、共享和备份目录均可用于同步。只需几次点击，即可自动将备份从设备中导出。

查看 [Syncthing 的目标][syncthing-goals] 了解更多详情。
