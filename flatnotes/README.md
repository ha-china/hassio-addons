## 安装

该加装机（addon）的安装非常简单，与安装任何其他 Hass.io 加装机没什么不同。

1. [将我的 Hass.io 加装机仓库][repository] 添加到您的 Hass.io 实例中。
2. 安装此加装机。
3. 创建 `/config/addon_config/flatnotes` 目录以存储您的配置。
4. 启动该加装机。
5. 查看该加装机的日志，以确保一切正常。
6. 在浏览器中打开 WebUI，地址为 `homeassistant:8080` 或通过反向代理（ingress）访问。

[repository]: https://github.com/jdeath/homeassistant-addons
