# 3Dash

Home Assistant 的 3D 房屋平面图仪表板。加载您自己的 3D 模型，将其映射到您的智能家居实体，并通过浏览器中的交互式视图控制一切。

## 如何访问

一旦插件运行，请使用浏览器打开 3Dash，地址如下：

```
http://<your-ha-ip>:8099
```

将 `<your-ha-ip>` 替换为您的 Home Assistant 机器的 IP 地址（例如 `http://192.168.1.100:8099`）。

您的浏览器在首次访问时可能会显示证书警告 - 这是正常的（自签名 SSL）。接受它以继续。

## 功能

- 带有自定义 `.glb` 模型的 3D 房屋平面图
- 灯光控制（开关、调光、RGB、RGBW、红外遥控）
- 带有实时传感器数据的墙面显示器
- 动画网络吞吐量管
- 实时太阳定位和天气效果
- 可配置的侧面板，包含脚本、指示器和图表
- 内置配置编辑器和入门向导
- 备份和恢复
- 暗色和亮色主题
