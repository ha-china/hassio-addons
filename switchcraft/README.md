## 📖 关于

## 安装

1. 在 Home Assistant 应用商店中搜索 "SwitchCraft" 应用并安装。
2. 启动 "SwitchCraft" 应用。
3. 检查 "SwitchCraft" 应用的日志，以查看一切是否顺利。
4. 点击 "打开 Web UI" 以访问 SwitchCraft 界面。

---

## ⚙️ 配置

通过 Home Assistant 应用页面中的 **配置** 选项卡配置此应用。

### 选项

```yaml
log_level: info
```
