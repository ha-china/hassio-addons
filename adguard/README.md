## 关于

AdGuard Home 是一个网络级别的广告和跟踪器阻止 DNS 服务器，具备家长控制（成人内容阻止）功能。它的目的是让您控制整个网络和所有设备，并且不需要使用客户端程序。

AdGuard Home 提供了一个美观、易于使用且功能丰富的网页界面，可以轻松管理过滤过程及其设置。
