通过浏览器访问的 Visual Studio Code。

## 关于

此应用运行 Visual Studio Code，允许您直接在 Web 浏览器中编辑 Home Assistant 配置，并可直接嵌入到 Home Assistant 前端用户界面中。

Visual Studio Code 使用 `code-server` 作为远程服务器运行，并提供完整的 VSCode 体验。

该应用开箱即用，已预安装和配置了 Home Assistant、MDI 图标及 YAML 扩展程序。这意味着您可以即时使用自动完成功能，无需进行任何配置。
