通过浏览器访问的 Visual Studio Code。

## 简介

此应用程序运行 Visual Studio Code，让您可以直接从 Web 浏览器编辑 Home Assistant 配置，并可直接嵌入到 Home Assistant 前端界面中。

Visual Studio Code 使用 `code-server` 作为远程服务器运行，并提供完整的 VSCode 体验。

该应用程序已开箱即用地预装了 Home Assistant、MDI 图标和 YAML 扩展并进行了预配置。这意味着无需任何设置即可立即使用自动补全功能。
