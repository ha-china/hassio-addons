这是一个网络不间断电源工具守护进程，允许您轻松管理连接到您的 Home Assistant 机器的电池备份（UPS）设备。

## 关于

网络不间断电源工具（NUT）项目的首要目标是提供对电源设备，如不间断电源（UPS）、电源分配单元、自动转换开关、电源供应单元和太阳能控制器等设备的支持。

NUT 提供了许多控制和监控 [功能][nut-features]，并具有统一的控制和管理工作界面。

超过 140 个不同的制造商和数千个型号 [兼容][nut-compatible]。

网络不间断电源工具（NUT）项目是众多 [个人和公司][nut-acknowledgements] 共同努力的成果。

确保在启动应用后添加 NUT 集成。

有关如何在 Home Assistant 中配置 NUT 传感器的更多信息，请参阅 [NUT 集成文档][nut-ha-docs].
