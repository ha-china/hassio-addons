Network UPS Tools 是一个守护进程，可让您轻松管理连接到您的 Home Assistant 机器的电池备份（UPS）设备。

## 关于 Network UPS Tools (NUT)

Network UPS Tools (NUT) 项目的主要目标是提供对电源设备的支撑，例如不间断电源、配电单元、自动转换开关、电源供应器和太阳能控制器。

NUT 提供了许多控制和监控 [特性][nut-features]，并具有统一的控制和管理接口。

超过 140 家不同制造商以及数千种型号 [兼容][nut-compatible]。

Network UPS Tools (NUT) 项目是许多 [个人和公司][nut-acknowledgements] 共同努力的结果。

请在启动应用后务必添加 NUT 集成。

有关如何在 Home Assistant 中配置 NUT 传感器的更多信息，请参阅 [NUT 集成文档][nut-ha-docs]。
