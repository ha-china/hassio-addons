## 关于

[sabnzbd](http://sabnzbd.net/) 是一个用 C++ 编写的 usenet 下载器，专为性能而设计，通过占用极少的系统资源来实现最快的下载速度。
此 add-on 基于 docker 镜像 https://github.com/linuxserver/docker-sabnzbd。

## 配置

Webui 可以在 <http://homeassistant:PORT> 通过或者直接通过侧边栏使用 Ingress 访问。
默认用户名/密码：login:`sabnzbd`，password:`tegbzn6789`
配置可以通过应用 webui 进行，除了以下选项。

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `PGID` | int | `0` | 文件权限组 ID |
| `PUID` | int | `0` | 文件权限用户 ID |
| `TZ` | str | | 时区（例如，`Europe/London`） |
| `localdisks` | str | | 要挂载的本地驱动器（例如，`sda1,sdb1,MYNAS`） |
| `networkdisks` | str | | 要挂载的 SMB 共享（例如，`//SERVER/SHARE`） |
| `cifsusername` | str | | SMB 网络共享用户名 |
| `cifspassword` | str | | SMB 网络共享密码 |
| `cifsdomain` | str | | SMB 网络共享域 |

### 示例配置

```yaml
PGID: 0
PUID: 0
TZ: "Europe/London"
localdisks: "sda1,sdb1"
networkdisks: "//192.168.1.100/downloads,//nas.local/usenet"
cifsusername: "downloader"
cifspassword: "password123"
cifsdomain: "workgroup"
```

### 挂载驱动器

此 add-on 支持挂载本地驱动器和远程 SMB 共享：

- **本地驱动器**: 查看 [添加组件中挂载本地驱动器](https://github.com/alexbelgium/hassio-addons/wiki/Mounting-Local-Drives-in-Addons)
- **远程共享**: 查看 [添加组件中挂载远程共享](https://github.com/alexbelgium/hassio-addons/wiki/Mounting-remote-shares-in-Addons)

### 自定义脚本和环境变量

此 add-on 通过 `addon_config` 映射支持自定义脚本和环境变量：

- **自定义脚本**: 查看 [在添加组件中运行自定义脚本](https://github.com/alexbelgium/hassio-addons/wiki/Running-custom-scripts-in-Addons)
- **env_vars 选项**: 使用 add-on `env_vars` 选项传递额外的环境变量（大小写名称均可）。详细信息见 https://github.com/alexbelgium/hassio-addons/wiki/Add-Environment-variables-to-your-Addon-2。

## 安装

此 add-on 的安装非常简单，与其他 add-on 并无不同。

1. 将我的 add-on 仓库添加到 home assistant 实例中（在 supervisor 商店右上角添加 add-on 仓库，或者如果你有配置我的 HA，则点击下方的按钮）
   [![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Falexbelgium%2Fhassio-addons)
1. 安装此 add-on。
1. 点击 `Save` 按钮以保存您的配置。
1. 将 add-on 选项设置为您的偏好设置。
1. 启动 add-on。
1. 检查 add-on 的日志以确认一切正常。
1. 打开 webui 并调整软件选项。
