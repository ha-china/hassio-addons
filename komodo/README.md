## 📖 关于

## 安装

1. 在 Home Assistant 应用商店中搜索 "Komodo"。
2. 安装应用。
3. 启动应用。
4. 打开 Web 界面。

---

## ⚙️ 配置

通过 Home Assistant 应用页面中的 **配置** 选项卡配置应用。

### 选项

```yaml
log_level: info
```
