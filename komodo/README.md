## 📖 关于

Komodo 是一款直观的软件开发、部署和服务器编排管理工具。

### ✨ 特性

* **多服务器管理**：连接并管理跨多台服务器和节点的部署。
* **自动化构建与同步**：触发构建，管理容器化服务，并监控部署状态。
* **现代化 Web 界面**：内置响应式界面，可通过 Home Assistant Ingress 直接访问。

---

## ⚙️ 配置

通过 Home Assistant App 页面的**配置**标签页配置应用程序。

### 选项

```yaml
log_level: info
```
