## 关于

[Homebox][homebox] 是家庭物品的库存系统。它记录您拥有什么物品、将它们存放的位置、购买成本以及当前价值，并且专为家庭而非仓库构建。

物品存放在位置中，位置可以嵌套在彼此之中，并且任何物品都可以被标记（标签化）。物品拥有照片、收据、说明书、序列号、保修日期以及您想要的任何自定义字段。从那里起，您可以通过搜索找到它们，而这正是其核心所在：答案是“阁楼上的哪个箱子里装着露营炉”只需一搜便知，而非耗上一个下午。

它还为物品维护日志，因此锅炉检修和割草机刀片更换都有记录可查，并且它可以打印带有 QR 码的标签标签以贴在箱子本身。
