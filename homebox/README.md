您的家中物品的库存管理系统。

## 关于

[Homebox][homebox] 是一个用于管理家中物品的库存系统。它记录您拥有的物品、存放位置、购买价格以及当前价值，专为家庭环境设计，而非仓库。

物品位于特定区域中，区域可以嵌套在其他区域内部，任何物品都可以附加标签。每个物品都有照片、收据、说明书、序列号、保修日期以及您希望添加的任何自定义字段。从此出发，您可以进行搜索，这正是其核心功能：查找阁楼哪个箱子里装有露营炉，只需一次搜索即可，无需耗费一个下午。

该系统还能针对物品维护日志进行记录，使锅炉检修和割草机刀片更换等信息有所归属，还可以打印带有二维码的标签单据，直接粘贴在箱体上。
