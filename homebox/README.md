## 关于

[Homebox][homebox] 是一种用于您家中所有物品的库存系统。它记录下您拥有哪些物品、存放位置、购买成本以及当前价值，并且是专为家庭使用的，而不是为仓库设计的。

物品存在于位置中，位置嵌套在其他位置内，任何物品都可以贴上标签。每个物品拥有照片、收据、说明书、序列号、保修日期以及您想要的任何自定义字段。从这里开始，可以进行搜索，而搜索便是其全部重点："阁楼上的哪个箱子装着露营炉"的答案只需一次搜索即可获得，而不需要耗费一个下午的时间。

它还会为物品维护维护日志，因此锅炉检查和割草机刀片更换都有记录可查，并且它可以打印带有二维码的标签单，以便粘贴在箱子上。
