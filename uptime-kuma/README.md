Uptime Kuma 是一个自托管监控工具，类似于"Uptime Robot"。

## 概述

Uptime Kuma 是一个开源监控工具，与"Uptime Robot"的自托管版本最为相似。

它允许您通过 HTTP/S、TCP、DNS 及其他协议监控服务，并可向您发送停机通知，或触发 Home Assistant 自动化的 webhook 事件。
