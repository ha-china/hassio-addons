## 关于

Uptime Kuma 是一个开源的监控工具，最好与像 "Uptime Robot" 这样的商业服务的自托管版本进行比较。

它允许您通过 HTTP/S、TCP、DNS 以及其他协议监控服务，并且可以发送您关于服务中断的通知，或者触发 Home Assistant 的自动化 webhook。
