## 关于

Uptime Kuma 是一款开源的监控工具，最佳比较对象是类似于 "Uptime Robot" 的自托管商业服务的变体。

它允许您通过 HTTP/S、TCP、DNS 等其他协议监控服务，并且可以在服务中断时向您发送通知，或者触发 Home Assistant 的自动化 webhook。
