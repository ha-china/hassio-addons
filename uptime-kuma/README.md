Uptime Kuma 是一个自托管监控工具，类似于"Uptime Robot"。

## 关于

Uptime Kuma 是一个开源监控工具，最好与其自托管版商业服务（如"Uptime Robot"）进行比较。

它支持您通过 HTTP/S、TCP、DNS 及其他协议监控服务，并能在服务宕机时向您发送通知，或触发 Home Assistant 的自动化 Webhook。
