Uptime Kuma 是一站式托管监控工具，可与"Uptime Robot"相比。

## 关于

Uptime Kuma 是一个开源监控工具，最适合作为"Uptime Robot"等商业服务的自托管版本。

它使您能够监控 HTTP/S、TCP、DNS 及其他协议的各类服务，并可为服务中断发出通知，或触发 Home Assistant 自动化的 Webhook。
