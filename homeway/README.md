## [Homeway.io](https://homeway.io/?source=addon_readme)

**🎉 [引入 Sage AI](https://homeway.io/sage-ai?source=addon_readme_sage_intro) 🎉** - **免费 AI 助手，适用于 Home Assistant 及 Home Assistant 语音设备。** 由 OpenAI 的 ChatGPT、Anthropic 的 Claude 或 Google 的 Gemini 提供支持——Sage 为 Home Assistant Assist 注入生动逼真的语音与沟通能力，可执行家庭操作、查找信息、查看天气等。Sage 提供个性定制功能及超过 56 种声音。

Homeway 是一个 Home Assistant 社区项目，旨在为整个 Home Assistant 社区提供免费、私密且安全的云工具。

## 功能特性

- 🚀 **免费**。可随时随地远程访问您的 Home Assistant。
- 🌿 **智能**。[Sage AI](https://homeway.io/sage-ai?source=addon_readme) 为与 Home Assistant 及 Home Assistant 语音设备进行的生动互动提供动力。
- 🤖 **得力助手**。使用 [Alexa](https://homeway.io/alexa?source=addon_readme) 和 [Google 助手](https://homeway.io/googleassistant?source=addon_readme) 语音控制您的家居。
- 📱 **移动端支持**。官方 [Home Assistant Android 和 iOS 应用](https://homeway.io/app?source=addon_readme) 提供免费远程访问功能。
- ⭐ **ready 适配 AI**。免费的远程 [MCP 服务器](https://blog.homeway.io/remote-mcp-server-for-home-assistant/?source=addon_readme) 使 AI 机器人可从任何地方访问并控制您的 Home Assistant。
- 📺 **支持流媒体**。免费提供 [WebRTC 摄像头流媒体服务] (https://blog.homeway.io/free-webrtc-video-streaming-for-home-assistant/?source=addon_readme)，支持 STUN 和 TURN 访问。
- 🔒 **安全**。高级功能确保仅您可访问。
- 🔭 **私密**。我们从不存储、销售或共享您的数据。
- ⚡ **快速**。全球服务器网络提供低延迟和高速度。
- 🛠️ **易用**。无需维护或专业知识。您的 Home Assistant 始终在线且安全。
- 🌍 **社区驱动**。由社区建设，为社区服务。加入我们的 [Discord 服务器](https://homeway.io/r/discord?source=addon_readme) 参与讨论和提出反馈。

## 立即体验！

- 点击上方的 "INSTALL" 文本。
- 安装完成后，点击上方的 "START" 文本。
- 点击上方的 "OPEN WEB UI" 文本。
- 点击按钮链接您的 Homeway 账户。
- 完成！

如需帮助，请阅读我们的 [完整设置指南](https://homeway.io/getstarted?source=addon_readme_full_guide)！
