## [Homeway.io](https://homeway.io/?source=addon_readme)

**🎉 [介绍 Sage AI](https://homeway.io/sage-ai?source=addon_readme_sage_intro) 🎉** - **为 Home Assistant 和 Home Assistant 语音设备提供的免费 AI 助手。** 由 OpenAI 的 ChatGPT、Anthropic 的 Claud 或 Google 的 Gemini 驱动 – Sage 能够实现逼真的语音和与 Home Assistant 助手的交互，以执行家庭动作、查找信息、查看天气等。Sage 提供个性化定制和超过 56 种语音。

Homeway 是一个 Home Assistant 社区项目，旨在为整个 Home Assistant 社区提供免费、私有和安全云工具。

## 功能

- 🚀 **免费。** 从任何地方远程访问您的 Home Assistant。
- 🌿 **智能。** [Sage AI](https://homeway.io/sage-ai?source=addon_readme) 为 Home Assistant 和 Home Assistant 语音设备提供逼真的交互。
- 🤖 **实用。** 使用 [Alexa](https://homeway.io/alexa?source=addon_readme) 和 [Google Assistant](https://homeway.io/googleassistant?source=addon_readme) 语音控制您的家庭。
- 📱 **移动。** 为官方 [Home Assistant Android 和 iOS 应用](https://homeway.io/app?source=addon_readme) 提供免费远程访问。
- ⭐ **AI 就绪。** 免费的远程 [MCP 服务器](https://blog.homeway.io/remote-mcp-server-for-home-assistant/?source=addon_readme) 允许 AI 机器人从任何地方访问和控制您的 Home Assistant。
- 📺 **可流式传输。** 提供 [WebRTC 摄像头流媒体传输](https://blog.homeway.io/free-webrtc-video-streaming-for-home-assistant/?source=addon_readme)，带有 STUN 和 TURN 访问。
- 🔒 **安全。** 先进功能确保只有您可以访问。
- 🔭 **隐私。** 我们绝不会存储、出售或分享您的数据。
- ⚡ **快速。** 全球服务器网络提供低延迟和速度。
- 🛠️ **简单。** 无需维护或技术知识。您的 Home Assistant 保持在线和安全。
- 🌍 **社区。** 由社区构建和为社区构建。加入我们的 [Discord 服务器](https://homeway.io/r/discord?source=addon_readme) 进行讨论和反馈。
