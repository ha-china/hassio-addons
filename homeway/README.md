## [Homeway.io](https://homeway.io/?source=addon_readme)

**🎉 [推出 Sage AI](https://homeway.io/sage-ai?source=addon_readme_sage_intro) 🎉** - **为 Home Assistant 及 Home Assistant 语音设备提供免费的 AI 助手**。结合 OpenAI 的 ChatGPT、Anthropic 的 Claude 或 Google 的 Gemini，Sage 让您能够以拟人化的声音和对话使用 Home Assistant Assist 执行家庭操作、查询信息、查看天气等。Sage 还提供个性化设定及超过 56 种声音。

Homeway 是一个 Home Assistant 社区项目，旨在为整个 Home Assistant 社区提供免费的、私密的且安全的云端工具。

## 功能特性

- 🚀 **免费**。随时随地远程访问您的 Home Assistant。
- 🌿 **智能**。[Sage AI](https://homeway.io/sage-ai?source=addon_readme) 为 Home Assistant 及 Home Assistant 语音设备提供拟人化的交互体验。
- 🤖 **有用**。使用 [Alexa](https://homeway.io/alexa?source=addon_readme) 和 [Google Assistant](https://homeway.io/googleassistant?source=addon_readme) 语音控制您的家。
- 📱 **移动**。官方 [Home Assistant Android 和 iOS 应用](https://homeway.io/app?source=addon_readme) 免费提供远程访问。
- ⭐ **AI 就绪**。免费的远程 [MCP 服务器](https://blog.homeway.io/remote-mcp-server-for-home-assistant/?source=addon_readme) 使 AI 机器人能够从任意位置访问并控制您的 Home Assistant。
- 📺 **可流媒体播放**。免费的 [WebRTC 摄像头直播流](https://blog.homeway.io/free-webrtc-video-streaming-for-home-assistant/?source=addon_readme)，支持 STUN 和 TURN 访问。
- 🔒 **安全**。高级功能确保仅有您方可访问。
- 🔭 **私密**。我们从不存储、出售或共享您的数据。
- ⚡ **快速**。全球服务器网络提供低延迟和高速度。
- 🛠️ **简易**。无需维护或技术知识。您的 Home Assistant 始终在线且安全。
- 🌍 **社区**。由社区建设，为社区服务。加入我们的 [Discord 服务器](https://homeway.io/r/discord?source=addon_readme) 参与讨论并提供反馈。
