## [Homeway.io](https://homeway.io/?source=addon_readme)

**🎉 [推出 Sage AI](https://homeway.io/sage-ai?source=addon_readme_sage_intro) 🎉** - **为 Home Assistant 及 Home Assistant 语音设备提供免费 AI 助手。** 由 OpenAI 的 ChatGPT、Anthropic 的 Claude 或 Google 的 Gemini 驱动，Sage 能够赋予 Home Assistant Assist 逼真的语音与交流能力，以执行家庭操作、查询信息、查看天气等更多功能。Sage 提供个性化设定，支持超过 56 种语音。

Homeway 是一个 Home Assistant 社区项目，旨在为整个 Home Assistant 社区提供免费、私密且安全的云端工具。

## 功能特性

- 🚀 **免费。** 可从任意位置远程访问您的 Home Assistant。
- 🌿 **智能。** [Sage AI](https://homeway.io/sage-ai?source=addon_readme) 驱动与 Home Assistant 及 Home Assistant 语音设备之间逼真的交互。
- 🤖 **有用。** 使用 [Alexa](https://homeway.io/alexa?source=addon_readme) 和 [Google Assistant](https://homeway.io/googleassistant?source=addon_readme) 语音控制您的智能家居。
- 📱 **手机端。** 官方 [Home Assistant Android 和 iOS 应用](https://homeway.io/app?source=addon_readme) 提供免费远程访问。
- ⭐ **AI 就绪。** 免费远程 [MCP 服务器](https://blog.homeway.io/remote-mcp-server-for-home-assistant/?source=addon_readme) 让 AI 机器人能够从任意位置访问并控制您的 Home Assistant。
- 📺 **支持流媒体。** [提供免费的 WebRTC 摄像头流媒体，](https://blog.homeway.io/free-webrtc-video-streaming-for-home-assistant/?source=addon_readme) 包含 STUN 和 TURN 接入支持。
- 🔒 **安全。** 高级功能确保只有您拥有访问权限。
- 🔭 **私密。** 我们绝不存储、出售或分享您的数据。
- ⚡ **快速。** 全球服务器网络提供低延迟和高速度。
- 🛠️ **易用。** 无需维护或技术知识。您的 Home Assistant 保持在线且安全。
- 🌍 **社区。** 由社区构建，为了社区。加入我们的 [Discord 服务器](https://homeway.io/r/discord?source=addon_readme) 参与讨论和反馈。

## 立即体验！

- 点击上方的"INSTALL"（安装）文本。
- 安装完成后，点击上方的"START"（启动）文本。
- 点击上方的"OPEN WEB UI"（打开网页界面）文本。
- 点击按钮以链接您的 Homeway 账户。
- 完成！

如果您需要帮助，请阅读我们的 [完整 setup 指南](https://homeway.io/getstarted?source=addon_readme_full_guide)！
