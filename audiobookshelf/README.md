## 关于

[Audiobookshelf][audiobookshelf] 是一个用于您已拥有的有声读物和播客的服务器。它读取您指向它的文件，识别它们，获取封面和描述，并将其传递给一个播放器，该播放器记住每个人的进度。

进度跟随听众而不是设备，因此在汽车中的手机上开始的有声读物会继续在家庭浏览器中从相同的秒数开始。播客由服务器本身按照计划订阅和下载，这才是它们属于您而不是被馈送带走的原因。家里的每个人都有自己的帐户，每本书中的独立进度，以及您授予他们的专属库。

您的收藏保持在原地。Audiobookshelf 读取它在 `media` 和 `share` 下给你的文件夹，并且永远不会移动或重写其中的内容。
