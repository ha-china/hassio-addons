## 关于

[Audiobookshelf][audiobookshelf] 是一个您已拥有的有声书和播客的服务器。它会读取您指向的、对其可见的音频文件，识别内容，获取封面和描述，并将其传递给播放器，后者会记住每位听众的进度。

进度跟随听众而非设备，因此如果在车里用手机启动的有声书，回家后在浏览器中会从同一秒继续播放。播客由服务器本身按计划订阅和下载，这使得它们真正属于您，而不仅仅是可以被源夺走的某种东西。家中每个人都有自己的账户，每本书都有自己的阅读进度，以及仅您授予他们的图书馆。

您的收藏夹保持在原位。Audiobookshelf 读取您在 `media` 和 `share` 目录下提供的文件夹，并永远不会移动或重写其中的内容。
