## 关于

[Audiobookshelf][audiobookshelf] 是一个为自己拥有的有声读物和播客服务的服务器。它读取您指向的文件，识别它们是什么，获取封面和描述，并将它们提交给一个能记住每个人在哪停顿下来的播放器。

进度会跟随听者而不是设备，因此如果在车里用手机开始的有声读物，回家后在浏览器中会从同一秒继续。播客由服务器本身按预定计划订阅和下载，这使它们成为您自己的内容，而不是可能被订阅源拿走的内容。家中的每个人都有自己的账户，自己在每本书中的进度，以及只有您赋予他们的图书馆。

您的收藏会保留在原处。Audiobookshelf 读取您设置在 `media`（媒体）和 `share`（共享）文件夹下的文件夹，并且永远不会移动或重写其中的文件。
