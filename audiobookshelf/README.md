## 简介

[Audiobookshelf][audiobookshelf] 是您已拥有的有声书和播客的服务器。它读取您指向的文件，识别它们的内容，获取封面和描述，并将其交付给一个记住每个人阅读进度的播放工具。

进度跟随听众而非设备，因此如果在车内用手机开始有声书，回家在浏览器中会从同一时间点继续收听。播客会由服务器本身按照计划进行订阅和下载，这也是为什么它们是您的，而不是可以被播客订阅源移除的原因。家中的每个人都可以拥有自己的账户、每本书的独立阅读进度，以及仅访问您授予他们的图书馆。

您的收藏将保持原位。Audiobookshelf 读取您设置在 `media` 和 `share` 文件夹下的目录，永远不会移动或重写其中的内容。
