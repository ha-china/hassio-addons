## 关于

[Audiobookshelf][audiobookshelf] 是一个用于播放您已拥有的有声书和播客的服务器。它读取您指向的文件，识别其内容，获取封面和描述，并将它们传递给能够记住每个用户阅读进度的播放器。

进度随听众而非设备移动，因此在车里用手机开始的有声书，在家浏览器上会从同一位置继续播放。服务器会按计划订阅并自行下载播客，这正是它们归属于您而非由播客源带走的原因。家中每个人都有自己的账户、每本书的独立阅读进度，以及您授予他们的专属图书馆。

您的收藏始终保持原位。Audiobookshelf 读取您指定的 `media` 和 `share` 文件夹，从不移动或重命名其中的文件。
