## 关于

[Mealie][mealie] 是一款食谱管理器与餐单计划工具，将您的烹饪活动保留在您自己的家中。只需提供您从网上找到的食谱地址，它就能提取出您实际使用的部分：食材、步骤、时间以及图片。而关于食谱的“生平故事”则会被忽略。

从那里，它便成为一个计划工具。将食谱添加到周计划日历中，它便会自动计算购物清单，并将同一食材 across 每一道餐食进行汇总。食谱可以按比例缩放、标签分类、整理成食谱书，并与家庭成员共享，每位成员都拥有独立的登录账户。

Home Assistant 提供了 [Mealie 的集成][integration]，因此您的计划和购物清单可以展示在仪表盘的其余内容旁边。该应用会自动出现在 Home Assistant 的搜索列表中。
