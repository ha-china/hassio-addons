# Home Assistant 应用：Frigate 完全访问版 Beta（中国大陆优化版）

这是专为**中国大陆地区**优化的 Frigate 完全访问版 Beta，内置了国内镜像源，支持直接下载来自 HuggingFace、GitHub 等平台的模型，无需依赖特殊网络环境。

请查阅 [发布说明](https://github.com/blakeblackshear/frigate/releases) 了解破坏性更新。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield] ![支持 armv7 架构][armv7-shield]

适用于 IP 摄像头，提供实时本地目标检测的 NVR 功能。

请在应用配置目录下创建 `config.yml` 配置文件。

此版本的应用请求完整的设备访问权限，以便为那些在保护模式下无法正常工作的设备禁用保护模式。

[文档](https://docs.frigate.video)
