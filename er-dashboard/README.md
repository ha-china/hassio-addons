## 📖 简介

## 安装

1. 在 Home Assistant 应用商店中搜索"ER-Startseite"。
2. 点击**安装**。
3. 启动应用程序。
4. 点击**打开网页界面**。

---

## ⚙️ 配置

通过 Home Assistant 应用程序页面上的**配置**选项卡配置此应用程序。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
ssl: false
```
