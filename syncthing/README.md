## 简介

[Syncthing][syncthing] 是一个连续文件同步程序。它会在两台或多台计算机之间同步文件，并用一个开放、可靠且去中心化的服务替代专用的同步和云服务。

您的数据只属于您自己，您有权选择数据存储在何处、是否与第三方共享以及如何在互联网上传输这些数据。

此应用程序将 Syncthing 直接放置在您的 Home Assistant 实例旁边，使您的配置、媒体、共享目录和备份目录都可用于同步。只需点击几次，即可自动将您的备份从设备上移走。

请查看 [Syncthing 的目标][syncthing-goals] 列表以查看更多详细信息。
