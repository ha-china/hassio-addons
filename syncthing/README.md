# Syncthing 附加组件

[**Syncthing**](https://syncthing.net/) 包裹在 [Home Assistant Supervisor 附加组件](https://www.home-assistant.io/addons/) 中。

> Syncthing 是一个持续文件同步程序。它实时在两台或多台计算机之间同步文件，安全地免受窥探。你的数据就是你的数据，你有权选择将其存储在哪里、是否与第三方共享，以及如何通过互联网传输。
