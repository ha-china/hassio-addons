## 概述

[Syncthing][syncthing] 是一种连续文件同步程序。它在两台或多台计算机之间同步文件，并用开源、可信且去中心化的方案替代专有同步和云服务。

您的数据仅属于您自己，您有权选择数据存储在何处、是否与第三方共享以及如何通过互联网传输。

该应用程序将 Syncthing 置于您的 Home Assistant 实例旁，并同步您的配置文件、媒体、共享目录和备份目录。只需几下鼠标点击，即可自动将备份从设备移除。

有关更多详细信息，请查看 [Syncthing 的目标][syncthing-goals] 列表。
