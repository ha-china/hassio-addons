# Syncthing 插件

Home Assistant 守护进程插件 [**Syncthing**](https://syncthing.net/) 的包装版本，位于 [Home Assistant Supervisor add-on](https://www.home-assistant.io/addons/)。

> Syncthing 是一个持续的文件同步程序。它在多台计算机之间实时同步文件，并从窥探者那里保护文件安全。您的数据仅属于您自己，您有权选择在何处存储您的数据，是否与第三方共享，以及如何通过互联网传输。
