## About

[Syncthing][syncthing] 是一个持续的文件同步程序。它在两个或多个计算机之间同步文件，并用一种开放、可信且去中心化的服务取代现有的专有同步和云服务。

你的数据仅属于你 yourself，你有权利选择数据存储的位置、是否与第三方共享以及数据如何通过网络传输。

这款应用程序将 Syncthing 直接放置在你的 Home Assistant 实例旁边，使你的配置文件、媒体文件、共享目录和备份目录可用于同步。只需几下操作，即可让你的数据备份自动从设备上移除。

了解 [Syncthing 的目标][syncthing-goals]，以获取更多信息。
