# Syncthing 插件

[**Syncthing**](https://syncthing.net/) 内置于 [Home Assistant 监督员插件](https://www.home-assistant.io/addons/) 之中。

> Syncthing 是一个持续的文件同步程序。它能够在两个或多个电脑之间实时同步文件，安全地保护不受好奇目光的窥探。您的数据属于您自己，您有权选择数据的存储位置、是否与第三方共享以及如何在互联网上传输。
