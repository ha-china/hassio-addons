## 关于

[Syncthing][syncthing] 是一个持续的同步程序。它
在不同计算机之间同步文件，并取代了专有的同步和云服务，提供开放、可信和去中心化的替代方案。

您的数据归您所有，您有权选择其存储位置、是否与第三方共享以及如何通过网络传输。

此应用程序将 Syncthing 直接放置到您的 Home Assistant 实例旁边，使您的配置文件、媒体、共享目录和备份目录可用于同步。
只需几步点击即可自动从设备上获取备份。

查看 [Syncthing 的目标][syncthing-goals] 以了解更多信息。
