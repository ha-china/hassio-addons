# Syncthing 插件

[**Syncthing**](https://syncthing.net/) 被封装在一个 [Home Assistant Supervisor 插件](https://www.home-assistant.io/addons/) 中。

> Syncthing 是一款持续文件同步程序。它实时同步两台或多台计算机之间的文件，安全地保护不受好奇的目光侵犯。你的数据只属于你，你有权选择它的存储位置，是否与第三方共享，以及如何在互联网上传输。
