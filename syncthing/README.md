## 关于

[Syncthing][syncthing] 是一个连续文件同步程序。它
在两台或更多台计算机之间同步文件，并用开放、可信和去中心化的方案替代专有同步和云服务。

您的数据完全属于您，您有权利决定数据存储在何处，是否以及与某些第三方共享，以及它如何通过网络传输。

此应用程序将 Syncthing 直接放置在您的 Home Assistant 实例旁边，让您的配置、媒体、共享和备份目录可用于同步。
自动将备份从设备上移除只需几次点击。

查看 [Syncthing 的目标][syncthing-goals] 以了解更多详情。
