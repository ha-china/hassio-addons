# Home Assistant App: Authelia

面向 Web 应用程序的单点登录多因素门户

## 关于

Authelia 是一个开源的身份验证和授权服务器，它通过 Web 门户为应用程序提供双因素认证和单点登录（SSO）。它作为反向代理的辅助程序，允许、拒绝或重定向请求。
