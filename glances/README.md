Glances 是一个用 Python 编写的跨平台系统监控工具。

## 关于

Glances 是一个跨平台监控工具，旨在通过基于 Web 的界面以最小空间呈现最大量的信息。

Glances 可以将所有系统统计信息导出到 InfluxDB，让您能够查看所有系统信息和其随时间的行为。
