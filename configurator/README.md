# Home Assistant 应用：文件编辑器

基于浏览器的 Home Assistant 配置文件编辑器。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

![Home Assistant 前端中的配置工具][screenshot]

## 简介

文件编辑器（前身为配置工具）是一个小型 Web 应用程序（您通过 Web 浏览器访问它），它提供文件系统浏览器和文本编辑器，用于修改运行在文件编辑器所在机器上的文件。

它由 Ace 编辑器驱动，支持多种代码/标记语言的语法高亮。在编辑 YAML 文件（Home Assistant 配置文件的首选语言）时，会自动检查语法错误。

## 功能特性

- 提供带有语法高亮和 YAML 纠错的 Web 编辑器用于修改文件。
- 支持上传和下载文件。
- 在 Git 存储库中暂存、存放和提交更改，创建和切换分支，推送到远程仓库，以及查看差异。
- 显示可用实体、触发器、事件、条件和服务的列表。
- 一键直接重启 Home Assistant。亦可重新加载组、自动化等。需要 API 密码。
- 提供直接链接至 Home Assistant 文档和图标。
- 可在应用容器内执行 shell 命令。
- 编辑器设置保存在您的浏览器中。
- 以及更多……
