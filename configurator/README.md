# Home Assistant App：文件编辑器

基于浏览器的 Home Assistant 配置文件编辑器。

## 关于

文件编辑器，之前称为配置器，是一个小巧的网页应用（通过网页浏览器访问），它提供了一个文件系统浏览器和文本编辑器，可以修改运行文件编辑器的机器上的文件。

它由 Ace 编辑器驱动，支持多种代码/标记语言的语法高亮。在编辑时，YAML 文件（Home Assistant 配置文件的默认语言）将自动检查语法错误。

## 功能

- 基于网页的编辑器，具有语法高亮和 YAML 检查，可修改您的文件。
- 上传和下载文件。
- 在 Git 仓库中暂存、存储和提交更改，创建和切换分支，推送到远程，查看差异。
- 列出可用的实体、触发器、事件、条件和服务。
- 直接通过按钮重启 Home Assistant。也可以重新加载组、自动化等。需要 API 密码。
- 直接链接到 Home Assistant 文档和图标。
- 在应用容器中执行shell命令。
- 编辑器设置保存在您的浏览器中。
- 还有更多…
