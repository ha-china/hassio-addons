# Home Assistant App: 文件编辑器

适用于 Home Assistant 的基于浏览器的配置文件编辑器。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

![Home Assistant 前端中的配置器页面][screenshot]

## 介绍

文件编辑器（前身为配置器）是一个小型 Web 应用程序（通过 Web 浏览器访问），提供文件系统浏览器和文本编辑器，用于修改运行文件编辑器所在机器上的文件。

它由 Ace Editor 驱动，支持多种代码和标记语言的语法高亮。YAML 文件（Home Assistant 配置文件默认语言）在编辑时会自动检查语法错误。

## 功能

- 基于 Web 的编辑器，提供语法高亮和 YAML 代码检查功能来修改文件。
- 文件上传和下载。
- 在 Git 仓库中暂存、暂存更改并提交更改，创建和切换分支，推送到远程，查看差异。
- 列表中包含可用实体、触发器、事件、条件和操作的列表。
- 单击按钮即可直接重启 Home Assistant。也可以重载组、自动化等。需要 API 密码。
- 直接链接到 Home Assistant 文档和图标。
- 在应用容器内执行 shell 命令。
- 编辑器设置保存在您的浏览器中。
- 以及更多信息…
