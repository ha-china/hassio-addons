## 关于

该附加功能使用 [docker 镜像](https://github.com/5etools-mirror-2/5etools-mirror-2.github.io)。

## 安装

安装此附加功能非常简单，与安装任何其他 Hass.io 附加功能没有区别。

1. [将我的 Hass.io 附加功能仓库][repository] 添加到您的 Hass.io 实例。
2. 安装此附加功能。4 GB 的镜像下载需要一些时间。
3. 点击 `保存` 按钮以存储您的配置。
4. 启动附加功能。
5. 查看附加功能的日志，确认一切正常。
6. 打开 WebUI，可以通过 ingresses 或 `<your-ip>:port` 访问。

## 配置

```
port : 8080 #您希望运行的端口。
```

WebUI 位于 `<your-ip>:port`。
