这是一套为 D&D 5e 玩家和 DM 提供的基于浏览器的工具集。已发布的下载来自 5etools 的 GitHub 仓库图片。无图片或内容托管/发布在 jdeath 的存储库中。由于 Home Assistant 附加组件创建者不使用此工具，因此不提供支持。自托管镜像可能落后于 5etools 网站。镜像大小为 4 GB，因此安装将花费较长时间，请耐心等候。

## 关于

此附加组件使用 [docker 镜像](https://github.com/5etools-mirror-2/5etools-mirror-2.github.io)。

## 安装

此附加组件的安装非常简单，与其他任何在 Hass.io 上的附加组件安装方式没有区别。

1. [添加我的 Hass.io 附加组件存储库](https://github.com/jdeath/homeassistant-addons) 到您的 Hass.io 实例。
2. 安装此附加组件（4 GB 镜像会花费一些时间下载）。
3. 点击 `保存` 按钮以存储您的配置。
4. 启动附加组件。
5. 检查附加组件的日志，以确认一切正常。
6. 通过回环或 `<您的 IP 地址>:端口` 打开 Web 界面即可。

## 配置

```
port : 8080 #您想要运行的端口。
```

Web 界面可以在 `<您的 IP 地址>:端口` 找到。
