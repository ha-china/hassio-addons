## 关于

该插件使用 [docker 镜像](https://github.com/5etools-mirror-2/5etools-mirror-2.github.io)。

## 安装

本插件的安装非常简单，与安装任何其他 Hass.io 插件相比并无不同。

1. [将我的 Hass.io 插件仓库添加到你的 system](repository)。
1. 安装此插件。4 GB 镜像下载需要一段时间。
1. 点击 `保存` 按钮以存储你的配置。
1. 启动插件。
1. 查看插件日志以确认一切正常。
1. 打开 WebUI 可通过 ingress 或 `<your-ip>:端口` 访问。

## 配置

```
port : 8080 # 你希望运行的端口号。
```

WebUI 可在此处访问：`<your-ip>:端口`。
