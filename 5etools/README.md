# Home Assistant 扩展：5etools

一套基于浏览器的工具，适用于 D&D 5e 的玩家和地下城主。从 5etools GitHub 下载图片。jdeath 的存储库中不托管或发布任何图片或内容。由于 Home Assistant 扩展创建者不使用此工具，因此不提供支持。自托管的图片可能落后于 5etools 网站的一个版本。图片大小为 4 GB，因此安装可能需要很长时间，请耐心等待。

## 关于

此扩展使用 [docker 镜像](https://github.com/5etools-mirror-2/5etools-mirror-2.github.io)。

## 安装

安装此扩展非常简单，与安装任何其他 Hass.io 扩展没有区别。

1. [将我的 Hass.io 扩展存储库添加到您的 Hass.io 实例][repository]。
1. 安装此扩展。4 GB 的镜像将需要一段时间下载
1. 点击 `保存` 按钮以存储您的配置。
1. 启动扩展。
1. 检查扩展的日志，以查看是否一切顺利。
1. 打开 WebUI 应该可以通过入口或 <your-ip>:port 访问。

## 配置

```
port : 8080 #您想要运行在的端口。
```

WebUI 可以在 `<your-ip>:port` 找到。
