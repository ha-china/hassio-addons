# Home Assistant 应用：DSMR 数据记录仪

[![打开您的 Home Assistant 实例并显示带有预填充特定仓库 URL 的添加附加项存储库对话框](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsanderdw%2Fhassio-addons)
[![社区论坛][forum-shield]][forum]

这是 DSMR (https://dsmr-reader.readthedocs.io) 的唯一数据记录仪选项。该选项将安装一个数据记录仪，该记录仪通过其 API 将电报 forwarded 到另一个已完全安装的 DSMR-reader 实例。
