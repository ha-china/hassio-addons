# Home Assistant 应用：DuckDNS

通过集成 HTTPS 支持（使用 Let's Encrypt），自动更新您的 DuckDNS IP 地址。

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

## 关于

[Duck DNS][duckdns] 是一项免费服务，它将 DNS（duckdns.org 的子域名）指向您选择的 IP 地址。此应用（以前称为补充程序）支持 Let's Encrypt，并自动创建和续订您的证书。在使用此应用之前，您需要注册 DuckDNS 账户。
