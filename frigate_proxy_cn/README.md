# Home Assistant 扩展：Frigate 代理

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield] ![支持 armhf 架构][armhf-shield] ![支持 armv7 架构][armv7-shield] ![支持 i386 架构][i386-shield]

此扩展创建了一个到独立于 Home Assistant 运行的 Frigate 服务器的代理，这样您就可以在不将 Frigate 作为扩展运行的情况下，在侧边栏中享受访问的便利。

请注意，此扩展本身不运行 Frigate。
