这是一个基于 Spotnet 协议的去中心化 Usenet 社区。

## 关于

Spotweb 索引其他用户使用 Spotnet 协议发布的"spots（站点/帖子）”，并为您提供一个网页界面以搜索和浏览它们。您可以关注或黑名单发布这些帖子的人，建立关注列表，并将找到的 NZB 文件直接传输至下载客户端。

它还配备了一个与 Newznab 兼容的 API，使 Sonarr、Radarr 和 Prowlarr 能够将其用作索引器。

Spotweb 需要自己拥有一个新的 Usenet 提供者来获取站点。启动应用后，您可以在 Spotweb 内部配置此内容。
