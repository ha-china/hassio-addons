A decentralized usenet community based on the Spotnet protocol.

## About

Spotweb indexes the "spots" that other users post to usenet using the Spotnet
protocol, and gives you a web interface to search and browse them. You can
follow or blacklist the people posting them, keep a watchlist, and hand the
NZB files it finds straight to your download client.

It comes with a Newznab compatible API as well, which lets Sonarr, Radarr and
Prowlarr use it as an indexer.

Spotweb needs a usenet provider of its own to retrieve spots with. You
configure that from within Spotweb, after starting the app for the first time.
