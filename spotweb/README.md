基于 Spotnet 协议的分布式 Usenet 社区。

## 关于

Spotweb 使用 Spotnet 协议索引其他用户发布的"Spots"（条目），并提供网页界面供用户搜索和浏览。您可以跟踪或屏蔽发布者，维护观察列表，并将找到的 NZB 文件直接转发到您的下载客户端。

它还包含与新 znab 兼容的 API，使 Sonarr、Radarr 和 Prowlarr 能够将其用作索引器。

Spotweb 需要一个隶属自身的 Usenet 提供商才能检索 Spots。您可在首次启动应用程序时，在 Spotweb 内部配置该提供商。
