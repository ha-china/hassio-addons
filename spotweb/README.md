一个基于 Spotnet 协议的去中心化 Usenet 社区。

## 关于

Spotweb 使用 Spotnet 协议索引其他用户发布的 Usenet“广告位”(spots)，并提供了一个网页界面供你浏览和搜索这些广告位。你可以关注或屏蔽发布这些广告位的用户，建立监控名单，并将找到的 NZB 文件直接传递给下载客户端。

它还提供一套与 Newznab 兼容的 API，这使得 Sonarr、Radarr 和 Prowlarr 可以将它用作索引器。

Spotweb 需要一个属于自己的 Usenet 服务提供商才能检索广告位。你可以在首次启动应用后，在 Spotweb 内部配置该服务。
