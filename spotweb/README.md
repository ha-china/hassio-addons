这是一个基于 Spotnet 协议的去中心化新邮件用户网络（Usenet）社区。

## 简介

Spotweb 利用 Spotnet 协议索引其他用户发布到新邮件用户网络（Usenet）的“站点”（spots），并提供一个网页界面供您搜索和浏览它们。您可以关注或屏蔽发布这些内容的用户，建立观察清单，并将自动发现的 NZB 文件直接递交给您的下载客户端。

它还包含一个与 Newznab 兼容的 API，这使得 Sonarr、Radarr 和 Prowlarr 可以使用它作为索引程序。

Spotweb 需要自己的新邮件用户网络（Usenet）服务提供者才能检索站点。您需要在首次启动该应用后，在 Spotweb 内部配置该服务。
