# 非官方 Home Assistant Add-on：UnPoller

UnPoller (<https://github.com/unpoller/unpoller>) 打包为 Home Assistant add-on。

## 安装

按以下步骤在系统上安装 add-on：

1. 在 Home Assistant 前端中导航到 **Supervisor -> Add-on Store**
1. 通过 URL 添加此新仓库
   (`https://github.com/bluemaex/home-assistant-addons`)
1. 找到 "Unpoller" add-on 并点击它。
1. 点击 "INSTALL" 按钮
1. 阅读 Addon 内部的文档
1. 根据您的喜好配置
1. 开始长期跟踪 👍

## 简介

收集您的 UniFi 控制器数据并将其报告到 InfluxDB 实例，或导出以供 Prometheus 采集。<https://github.com/unpoller/unpoller>
