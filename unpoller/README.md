# 非官方 Home Assistant 附加工具：UnPoller

UnPoller (<https://github.com/unpoller/unpoller>) 作为一个捆绑的 Home Assistant 附加工具有提供。

## 安装

按照以下步骤将此附加工具安装到你的系统：

1. 在 Home Assistant 前端中导航到 **Supervisor -> Add-on Store**
1. 通过 URL 添加此新仓库
   (`https://github.com/bluemaex/home-assistant-addons`)
1. 找到"Unpoller"附加工具并点击它。
1. 点击"INSTALL"按钮
1. 阅读附加工具内的文档
1. 根据你的喜好调整配置
1. 开始使用长期跟踪功能 👍

## 关于

收集你的 UniFi 控制器数据并将其报告给 InfluxDB 实例，或导出用于 Prometheus 收集。 <https://github.com/unpoller/unpoller>
