# 非官方 Home Assistant 添加组件：UnPoller

UnPoller (<https://github.com/unpoller/unpoller>) 作为一个 Home Assistant 添加组件打包。

## 安装

按照以下步骤将添加组件安装到您的系统上：

1. 在 Home Assistant 前端导航到 **Supervisor -> Add-on Store**
2. 通过 URL 添加此新仓库
   (`https://github.com/bluemaex/home-assistant-addons`)
3. 找到"Unpoller"添加组件并点击它。
4. 点击"INSTALL"按钮
5. 阅读添加组件内的文档
6. 根据您的喜好调整配置
7. 开始进行长期追踪 👍

## 关于

收集您的 UniFi 控制器数据，并将其报告到一个 InfluxDB 实例，或导出供 Prometheus 收集。<https://github.com/unpoller/unpoller>
