# Home Assistant 插件：NutriTrace

## 描述
Open WebUI 是一个 **AI 之家** 的自托管 AI 平台，具有 **[可扩展性](https://docs.openwebui.com/features/extensibility/plugin/)**、**功能齐全** 的特点，用户友好，并支持全流程 **[完全离线运行](https://openwebui.com/sovereign-ai)**。通过支持 **Ollama** 和 **兼容 OpenAI 的 API**，它为本地和云端模型提供了一个强大且供应商无关的接口。

如果您想要包含本地 AI 的图像版本，请使用 `https://github.com/mikastamm/open-webui-homeassistant-addon`

## 安装

该插件的安装非常简单，与其他任何 Hass.io 插件的安装方式类似。

1. 将 [我的 Hass.io 插件仓库][repository] 添加到您的 Hass.io 实例中。
1. 安装此插件。
1. 强烈建议您将默认的 `WEBUI_SECRET_KEY` 更改为 `openssl rand -hex 32` 的输出结果（进入 Home Assistant 后运行该命令）。
1. 点击 `保存` 按钮以存储您的配置。
1. 配置服务器后，Ingress 将工作正常。

[repository]: https://github.com/jdeath/homeassistant-addons
