# 家庭助手插件：NutriTrace

## 描述

Open WebUI 是 **AI 的家园**，是一个可自我托管的 AI 平台，它具有 **[可扩展性](https://docs.openwebui.com/features/extensibility/plugin/)**， **[功能丰富](https://docs.openwebui.com/features/)**，用户友好，并且旨在运行 **[完全离线](https://openwebui.com/sovereign-ai)** 。它支持 **Ollama** 和 **OpenAI 兼容 API**，为您提供一个强大的、与供应商无关的界面，用于本地和云模型。

如果您想要包含本地 AI 的图像版本，请使用 `https://github.com/mikastamm/open-webui-homeassistant-addon`

## 安装

此插件的安装非常简单，与安装任何其他 Hass.io 插件没有不同。

1. [添加我的 Hass.io 插件存储库][repository] 到您的 Hass.io 实例中。
1. 安装此插件。
1. 强烈建议您更改默认的 WEBUI_SECRET_KEY 为 `openssl rand -hex 32` 的输出结果（ssh 进入家庭助手并运行）。
1. 点击“保存”按钮以存储您的配置。
1. 在设置好服务器后，Ingress 将开始工作

[repository]: https://github.com/jdeath/homeassistant-addons
