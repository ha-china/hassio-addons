# Home assistant 附加组件：NutriTrace

## 描述
Open WebUI 是**AI 的家园**，一个自托管的 AI 平台，它具备 **[可扩展性](https://docs.openwebui.com/features/extensibility/plugin/)**、 **[功能丰富](https://docs.openwebui.com/features/)**、用户友好，并且专为在 **[完全离线](https://openwebui.com/sovereign-ai)** 环境下运行而建造。它支持 **Ollama** 和 **兼容 OpenAI 的 API**，为您提供了一个强大的、与提供商无关的界面，用于运行本地和云模型。


如果您想要包含本地 AI 的镜像版本，请使用 `https://github.com/mikastamm/open-webui-homeassistant-addon`

## 安装
此附加组件的安装非常直截了当，与安装任何其他 Hass.io 附加组件的过程没有区别。

1. [将我的 Hass.io 附加组件仓库添加到您的 Hass.io 实例][repository]。
1. 安装此附加组件。
1. 强烈建议将默认的 WEBUI_SECRET_KEY 更改为 `openssl rand -hex 32` 的输出（进入 home assistant 并执行）。
1. 点击 `Save` 按钮以保存您的配置。
1. 设置服务器之后，Ingress 将开始工作。

[repository]: https://github.com/jdeath/homeassistant-addons
