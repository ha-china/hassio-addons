## 关于

[Node-RED][nodered] 是一种编程工具，可以将硬件设备、API 和在线服务以新的和有趣的方式连接起来。

它提供了一个基于浏览器的编辑器，可以轻松地将流程连接起来，使用调色板中的各种节点，只需一键即可部署到其运行时。
