## 安装

该插件的安装非常简单，与安装任何其他的 Hass.io 插件没有区别。

1. [添加我的 Hass.io 插件仓库][repository] 到您的 Hass.io 实例。
1. 安装此插件。
1. 点击 `保存` 按钮以保存您的配置。
1. 启动插件。
1. 检查插件日志以确认一切正常。
1. 访问本地 IP:端口。由于某些原因 Ingress 无法工作
1. 查阅官方文档以获取配置支持：https://github.com/benzino77/tasmocompiler

## 配置

```
port: 3000 # 您想要运行前端使用的端口号
```

Web 界面可在此处找到：`<您的 IP>:端口`。
