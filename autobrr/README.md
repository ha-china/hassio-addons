## 关于

---

[Autobrr](https://autobrr.com/) autobrr 是现代下载自动化工具，专门用于 torrents。我们借鉴和采用像 trackarr, autodl-irssi 和 flexget 这样的工具的想法，构建了一个能够完成所有任务甚至更多的工具。

此添加组件基于 Docker 镜像 https://github.com/autobrr/autobrr。

## 安装

---

此添加组件的安装非常简单，与其他添加组件的安装并无不同。

1. 将我的添加组件仓库添加到您的 Home Assistant 实例中（在 supervisor 添加组件存储中点击右上角，或者如果您已配置了 HA，则点击下方按钮）
   [![打开您的 Home Assistant 实例并显示带有特定仓库 URL 预填充的添加添加组件仓库对话框。](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Falexbelgium%2Fhassio-addons)
1. 安装此添加组件。
1. 点击 `保存` 按钮以保存您的配置。
1. 将添加组件选项设置为您的偏好设置。
1. 启动添加组件。
1. 检查添加组件的日志，以查看是否一切正常。
1. 打开 web 界面并调整软件选项。

## 配置

Web 界面位于 <http://homeassistant:7474> 或通过入口网络。
默认凭证：`admin` / `password`（首次登录后更改）。

### 设置步骤

1. 启动添加组件后访问 Web 界面
2. 更改默认登录凭证
3. 配置 RSS 索引器和下载客户端
4. 设置自动化规则和过滤器
5. 使用样本来测试发布

### 选项

| 选项 | 类型 | 默认值 | 描述 |
|--------|------|---------|-------------|
| `PGID` | int | `0` | 文件权限的组 ID |
| `PUID` | int | `0` | 文件权限的用户 ID |
| `TZ` | str | | 时区（例如，`Europe/London`） |
| `localdisks` | str | | 本地驱动器要挂载的列表（例如，`sda1,sdb1`）。驱动器后添加一个文件夹以仅挂载该文件夹，例如 `MYNAS/public` 仅挂载该文件夹，位于 `/mnt/MYNAS/public`。文件夹挂载需要 2026-09-19 以后发布的添加组件版本。 |
| `networkdisks` | str | | 要挂载的 SMB 共享（例如，`//SERVER/SHARE`） |
| `cifsusername` | str | | 网络共享的 SMB 用户名 |
| `cifspassword` | str | | 网络共享的 SMB 密码 |
| `cifsdomain` | str | | 网络共享的 SMB 域 |

### 示例配置

```yaml
PGID: 1000
PUID: 1000
TZ: "Europe/London"
localdisks: "sda1,sdb1"
networkdisks: "//192.168.1.100/downloads"
cifsusername: "dluser"
cifspassword: "password123"
cifsdomain: "workgroup"
```

### 挂载驱动器

此添加组件支持挂载本地驱动器和远程 SMB 共享：

- **本地驱动器**：参见 [在添加组件中挂载本地驱动器](https://github.com/alexbelgium/hassio-addons/wiki/Mounting-Local-Drives-in-Addons)
- **远程共享**：参见 [在添加组件中挂载远程共享](https://github.com/alexbelgium/hassio-addons/wiki/Mounting-remote-shares-in-Addons)

### 自定义脚本和环境变量

此添加组件支持自定义脚本执行和环境变量注入：

- **自定义脚本**：参见 [在添加组件中运行自定义脚本](https://github.com/alexbelgium/hassio-addons/wiki/Running-custom-scripts-in-Addons)
- **env_vars 选项**：使用添加组件 `env_vars` 选项来传递额外的环境变量（大小写名称均可）。详见 https://github.com/alexbelgium/hassio-addons/wiki/Add-Environment-variables-to-your-Addon-2。
