# 非官方 Home Assistant Add-ons: Traefik

作为 Home Assistant add-on 打包的 Traefik。

## 简介

Traefik 是一款现代的 HTTP 反向代理和负载均衡器，使得微服务部署变得简单。此 add-on 基于文件提供动态的 Traefik 配置。

[此处点击获取完整的 Traefik 文档](https://docs.traefik.io/)

## 已知问题和限制

- 默认 80 端口可能与其他端口冲突

## 最后说明

本项目与 Traefik、Traefik 维护团队或 Containous 无关联，仅仅是社区贡献。Traefik 本身按照 [MIT 许可](https://github.com/containous/traefik/blob/master/LICENSE.md) 分发。
