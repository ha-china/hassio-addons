## 关于

此组件使用 [Docker 镜像](https://github.com/livebook-dev/livebook)。

## 安装

此添加组件的安装非常简单，与安装任何其他 Hass.io 添加组件的方式没有区别。

1. [将我的 Hass.io 添加组件仓库][repository] 添加到您的 Hass.io 实例中。
1. 点击 `保存` 按钮以配置存储。
1. 启动添加组件。
1. 检查添加组件的日志，看看是否一切正常。
1. 可以通过 <your-ip>:port 打开 WebUI。
1. 数据将存储在 /addon_configs/2effc9b9_livebook 中。

## 配置

```
port : 8080 #要运行的端口。
```

WebUI 位于 `<your-ip>:port`。
