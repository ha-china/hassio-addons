# Home Assistant App: Roundcube

[![发布][发布盾牌]][发布] ![项目阶段][项目阶段盾牌] ![维护状态][维护盾牌]

基于网页的Roundcube电子邮件客户端。

## 关于

重要：此应用要求已安装并运行MariaDB应用！

此应用提供了一个基于网页的Roundcube电子邮件客户端，可以连接到本仓库中的Mailserver应用
