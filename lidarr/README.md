# Home Assistant 社区应用：Lidarr

[![Release][release-shield]][release] ![Project Stage][project-stage-shield] ![Project Maintenance][maintenance-shield]

看起来和闻起来都像 Sonarr 但专为音乐制作。

## 关于

[Lidarr] 是针对 Usenet 和 BitTorrent 用户的音乐收藏管理器。它可以监控来自您喜欢艺术家的多个 RSS 以查找新曲目，并自动抓取、排序和重命名它们。它还可以配置为当更好的质量格式可用时，自动升级已下载文件的质量。

[Lidarr]: https://lidarr.audio/
