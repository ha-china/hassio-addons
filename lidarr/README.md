看起来像 Sonarr，但专为音乐设计。

## 关于

[Lidarr] 是一个面向 Usenet 和 BitTorrent 用户的音乐集合管理器。它可以监控多个 RSS 源以获取您喜欢的艺术家的最新曲目，并将其抓取、排序和重命名。它还可以配置为在出现更高质量格式时自动升级已下载文件的质量。
