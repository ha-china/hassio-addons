## 关于

[Jellyfin][jellyfin] 是一个媒体服务器。将方向指向存放您的电影、剧集和音乐的文件夹，它将自动识别所有内容，收集艺术图片、描述，并将其提供给您希望观看的设备：浏览器、手机、平板、游戏主机或电视。

它与任何云端服务无关。不需要创建账户、订阅或付费层级；您机器本地的服务器就是全部产品。此应用让 Jellyfin 服务器运行在 Home Assistant 旁边，其库位于与您的其他应用共用的 `media` 文件夹中。

当设备无法直接播放文件时，转码可以交给 Intel 或 AMD 显卡，使用 Jellyfin 项目提供并修补过的 FFmpeg。Home Assistant 自带的 [Jellyfin 集成][integration] 将库引入媒体浏览器，并将其作为媒体播放器添加到从该库播放的设备中。
