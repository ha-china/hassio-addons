# HACS极速版安装器

最简单的HACS极速版安装方式！

> **此插件可以安装HACS极速版及部分常用集成**

## 说明

1. 点击 **安装** 按钮来构建此插件
   - 如需安装其他集成，请先到 **配置** 页面切换并保存
     ![操作步骤](https://github.com/user-attachments/assets/89fb128c-6cff-49aa-8faa-3a56bca078f7)
2. 启动此插件
3. 切换到到 **日志** 页面并按照提供的指示进行操作
