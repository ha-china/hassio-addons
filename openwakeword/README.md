# Home Assistant App: openWakeWord

![支持 aarch64 架构][aarch64-shield] ![支持 amd64 架构][amd64-shield]

这是一个使用 `pyopen-wakeword`（[PyPI](https://pypi.org/project/pyopen-wakeword)）进行唤醒词检测的 Home Assistant 应用程序（以前称为附加组件）。

这是 `年度语音` 计划的一部分（[相关文章](https://www.home-assistant.io/blog/2022/12/20/year-of-voice/)）。

需要 Home Assistant 2023.9 或更高版本。
