# Home Assistant App: Caddy 2

Caddy 2 是一个现代、强大、企业级的开源 Web 服务器，旨在简化、安全和灵活。  
它独特的自动管理 HTTPS 功能无需复杂配置即可默认生效。

## 关于

Caddy 2 通过自动化运行 Web 服务所需的许多基础架构管理工作，来简化并增强您的 Home Assistant 体验。  
凭借其内置的 HTTPS 管理功能、反向代理能力和模块化扩展性，Caddy 可以处理许多关键任务。
