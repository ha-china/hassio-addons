# Home Assistant App: Mailserver

[![Release][release-shield]][release] ![Project Stage][project-stage-shield] ![Project Maintenance][maintenance-shield]

一个用于 Home Assistant 的邮件服务器。
提供 Postfix、Postfix Admin Web 界面以及 Dovecot IMAP。

## 概览

**重要提示：** 此 App 需要先安装并运行 MariaDB App！

此 App 为您的域提供一个邮件服务器。
您也可以在后缀管理 (Postfixadmin) 的 Web 界面中配置额外的电子邮件域名和账号。
