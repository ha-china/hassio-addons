# Home Assistant 应用：邮件服务器

[![发布][发布盾牌]][发布] ![项目阶段][项目阶段盾牌] ![维护状态][维护盾牌]

Home Assistant 的邮件服务器。
提供 Postfix、Postfix Admin 网页界面和 Dovecot IMAP。

## 关于

重要：此应用要求已安装并运行 MariaDB 应用！

此应用为您的域名提供邮件服务器。
还可在 Postfixadmin 网页界面中配置额外的电子邮件域名和账户。
