浏览、编辑、上传并组织您的 Home Assistant 安装的文件。

## 简介

这是一个为您的 Home Assistant 安装提供文件管理功能的工具，以侧边栏面板的形式呈现。它会显示 Home Assistant 存放文件的目录，允许您浏览它们、上传文件、移动文件、解压归档、就地编辑 YAML 文件、预览图片或 PDF，并在其中进行搜索。

其下方是 [FileBrowser Quantum][filebrowser]，一个现代化的网络文件管理器，内置了编辑器、预览功能、搜索索引和 WebDAV。该应用将 Home Assistant 的目录（配置目录、媒体目录、共享目录、备份目录、证书目录以及应用程序及其配置）作为其数据源。

从侧边栏打开它时，Home Assistant 会引导您登录，并为您创建一个专属账户。一旦发布其端口，它还将成为一个 WebDAV 共享目录，因此您可以在电脑上将某个目录挂载为网络驱动器。
