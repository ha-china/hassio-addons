在你的 MQTT  Broker 上浏览话题和消息。

## 关于

[MQTT Explorer][mqtt-explorer] 可以展示 MQTT Broker 内部的情况。
它发现的所有话题都会以树状结构排列，每个话题显示最后一条消息、更新频率以及之前的内容。
这些值会实时进行绘图，可以发布消息，并且整个树在填充过程中始终可搜索。
它是出现问题时的工具：当设备无法显示、话题名称与文档不符，或者你只是想看看实际流量时。

这是一个桌面应用程序，此应用运行的是其 Web 版本：
相同的界面，从 Home Assistant 提供服务，并通过侧边栏打开。
Home Assistant 使用的 MQTT Broker 在打开时已在其连接列表中，包含地址和凭据，因此只需一次点击即可访问该树。
