探索您的 MQTT 代理上的主题和消息。

## 关于

[MQTT Explorer][mqtt-explorer] 展示了 MQTT 代理内部的活动情况。它看到的所有主题都以树状结构展示，包含最后的消息、其更改频率以及之前的内容。值可以随着数据接收而绘制图表，消息可以发布回代理，整棵树在填充过程中始终保持可搜索状态。当设备未显示、主题名称与文档描述不符，或者您只是想查看该流量实际内容时，这就是您打开的工具。

这是一个桌面上的应用程序，此应用运行其 Web 版：相同的界面运行于 Home Assistant 中，并从侧边栏打开。Home Assistant 使用的 MQTT 代理在其连接列表中已经存在，包含地址和凭据，因此只需点击一次即可进入该树状结构。
