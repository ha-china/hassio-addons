## 关于

[MQTT 探索者][mqtt-explorer] 展示了 MQTT 代理内部正在进行的事情。它所看到的所有主题都被组织成一棵树，显示最后一个消息、频率变化以及之前的内容。值可以随着收到而绘制，消息可以发布回代理，整棵树在填充过程中仍可进行搜索。它是解决设备不显示、主题名称与文档不符，或者您只是想查看实际流量的时候使用的工具。

它首先是一款桌面应用程序，此应用运行的是其网络版：相同的界面，由 Home Assistant 提供并从此侧边栏打开。Home Assistant 使用的 MQTT 代理在打开时已在其连接列表中，包括地址和凭据，因此只需点击一次即可进入树状结构。
