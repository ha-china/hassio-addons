## 关于

[MQTT Explorer][mqtt-explorer] 可以显示 MQTT 经纪人内部的情况。它将看到的每个主题都以树状结构排列，显示该主题上的最后一消息、消息变更频率以及其之前显示的内容。值可以在数据到达时进行绘图，消息可以再次发布，且整棵树在填充过程中仍可进行搜索。当设备无法显示、主题名称与文档描述不符，或者你只是想查看所有流量实际内容时，这就是你需要使用的工具。

它是一个桌面应用程序的首发版本，此应用运行其网页版：相同的界面，由 Home Assistant 托管并从侧边栏打开。Home Assistant 使用的 MQTT 经纪人已经在打开时的连接列表中，包含地址和凭据，因此只需点击一次即可进入树状界面。
