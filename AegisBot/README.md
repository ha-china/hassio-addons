## ⚙️ 配置

通过 Home Assistant 应用页面中的 **配置** 选项卡配置此应用。

### 选项

```yaml
ai_provider: gemini
database:
  type: sqlite
debug: false
default_locale: en
demo_mode: false
demo_mode_type: ephemeral
developer_mode: false
environment: production
github_repo: FaserF/AegisBot
github_token: ''
log_level: info
project_name: AegisBot
release_type: stable
reset_database: false
secret_key: ''
version: latest
```
