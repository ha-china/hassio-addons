# Home Assistant 插件：Otaku

Otaku 是免费且开源的，运行在您自己的计算机上，无需基础设施，只需一条命令即可完成安装，并且配置需求极少。LLM（大语言模型）可以是本地的（通过 llama.cpp、KoboldCpp、Ollama 及其他工具），也可以通过 API 服务访问（如 OpenRouter、NanoGPT）。

Otaku 的三大支柱：

- **随着故事的发展，保持写作质量**；
- **保持上下文较小**，即使在撰写长篇故事时，也不会丢失重要的细节；
- **高质量的界面**，包括浏览器端和终端端。

## 安装

该插件的安装非常简单，与其他任何 Hass.io 插件的安装方式没有区别。

1. [将我的 Hass.io 插件仓库][repository] 添加到您的 Hass.io 实例中。
1. 安装此插件。
1. 点击 `保存` 按钮以存储您的配置文件。
1. 启动插件。
1. 检查插件日志以确认是否一切正常。
1. 通过 <your-ip>:port 打开 WebUI。

## 配置

```
port : 8081 # 您希望运行的端口
```

WebUI 可在此地址访问：<your-ip>:port。
