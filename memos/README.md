# Home assistant 插件：Memos

一个以隐私为首要，轻量级的笔记记录服务。轻松捕捉和分享你的精彩想法。

从以下Docker镜像运行：https://github.com/usememos/memos

## 安装

此插件的安装非常简单，与安装任何其他Hass.io插件没有区别。

1. [将我的Hass.io插件仓库添加到你的Hass.io实例][repository]。
1. 安装此插件。
1. 点击“保存”按钮以存储你的配置。
1. 启动插件。
1. 检查插件的日志以查看是否一切顺利。
1. 通过ingress或<你的IP>:端口打开WebUI应该可以工作。
1. 设置将存储在 /addons-config/2effc9b9_memos

## 配置

```
port : 5230 #你想要运行的端口。
```

WebUI可以在 `<你的IP>:端口` 找到。
