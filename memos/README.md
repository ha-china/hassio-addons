# Home Assistant 插件：备忘录

一个以隐私为首要考虑的轻量级笔记记录服务。轻松捕捉和分享你的精彩想法。

从以下 Docker 镜像运行：https://github.com/usememos/memos

## 安装

此插件的安装相当简单，与安装任何其他 Hass.io 插件没有太大区别。

1. [将我的 Hass.io 插件仓库][repository] 添加到您的 Hass.io 实例中。
1. 安装此插件。
1. 点击 `保存` 按钮以存储您的配置。
1. 启动插件。
1. 检查插件的日志，以查看一切是否顺利。
1. 通过 ingress 或 <your-ip>:port 打开 WebUI 应该可以工作。
1. 设置将存储在 /addons-config/2effc9b9_memos 中。

## 配置

```
port : 5230 # 您希望运行的端口。
```

WebUI 可以在 `<your-ip>:port` 找到。
