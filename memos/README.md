# Home assistant 附加组件：Memos

一款注重隐私、轻量级的笔记服务。轻松记录并分享您的精彩想法。

从 https://github.com/usememos/memos 运行 Docker 镜像。

## 安装

此附加组件的安装非常简单，与安装其他任何 Hass.io 附加组件的方式相同。

1. [将我的 Hass.io 附加组件存储库][repository] 添加到您的 Hass.io 实例。
1. 安装此附加组件。
1. 单击 `Save` 按钮以保存您的配置。
1. 启动附加组件。
1. 检查附加组件的日志，确认一切是否正常。
1. 可以通过 ingress 或 `<your-ip>:port` 打开 WebUI。
1. 设置将存储在 /addons-config/2effc9b9_memos

## 配置

```
port : 5230 #您想运行的端口。
```

WebUI 可以在 `<your-ip>:port` 处找到。
