## 安装

该扩展的安装非常简单，在 Hass.io 扩展中安装其他扩展时不会有太大差异。

1. [将我的 Hass.io 扩展存储库][repository] 添加到您的 Hass.io 实例中。
1. 安装此扩展。
1. 点击 `Save` 按钮保存配置。
1. 启动扩展。
2. 检查扩展日志，确认一切顺利。
1. 通过 ingress 或 <your-ip>:port 打开 Web UI。
2. 设置将存储在 /addons-config/2effc9b9_memos 中。

## 配置

```
port : 5230 #要在上面运行的端口。
```

Web UI 可通过 `<your-ip>:port` 访问。
