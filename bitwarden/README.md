# Home Assistant 插件：Vaultwarden (Bitwarden RS)

使用插件 `env_vars` 选项来传递额外的环境变量（变量名不区分大小写）。详情请参阅：https://github.com/alexbelgium/hassio-addons/wiki/Add-Environment-variables-to-your-Addon-2

# ⚠️ 建议使用官方插件 (https://github.com/hassio-addons/addon-bitwarden) 而不是这个分支版。这个分支版唯一的好处是自动发布，而官方版现在已经实现了该功能。 ⚠️

我在业余时间维护这个和其他 Home Assistant 插件：跟进上游变更、Home Assistant 的变更以及在真实硬件上进行测试需要大量的时间（和一些金钱）。我使用我超过 110 个插件中的大约 5-10 个，所以我定期安装测试机器（并购买一些测试服务，如 VPN）供我自己不使用，以用于排错和改进插件。

如果这个插件为您节省了时间或简化了您的设置，我将非常感谢您的支持！
