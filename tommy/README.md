# TOMMY Zero

这是 TOMMY Zero 的 Home Assistant 添加组件。TOMMY Zero 是一款 Wi-Fi 传感系统，能够将 ESP32 设备转变为能够检测穿过墙壁和障碍物的移动性的存在传感器。

该添加组件将 TOMMY Zero 直接集成到您的 Home Assistant 实例中，使您能够在现有自动化中创建区域。所有处理均在其网络本地进行。

**开始使用：** [安装指南](https://www.tommysense.com/docs/installation/homeassistant)  
**了解更多：** [完整文档](https://www.tommysense.com/docs)
