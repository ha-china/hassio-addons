# 获取 HACS

获取 HomeAssistant 中 HACS 的最简单方法。

> **该应用程序不运行 HACS。该应用程序仅提供下载 HACS 的最简单途径。**

## 说明

1. 点击上方的 **"Install"** 按钮来构建该应用程序。
2. 启动应用程序。
3. 进入应用程序日志，并按照其中给出的指示操作。

> [!NOTE]
> 当您在日志中看到 "Remember to restart Home Assistant before you configure it"（配置前请重启 HomeAssistant）这一行时，
> 下载程序已完成，您需要执行它所指示的操作（重启 HomeAssistant）。
> 此时，您可以在不再需要它的情况下卸载该应用程序。
> 其余的操作都在 HomeAssistant 用户界面中进行。
> 更多信息请参阅 [文档](https://hacs.xyz/docs/use/configuration/basic/)。
