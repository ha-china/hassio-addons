# 获取 HACS

下载安装 Home Assistant HACS 的最简单方法。

> **此应用不会运行 HACS。此应用仅提供下载 HACS 的最简便途径。**

## 说明

1. 使用上方的 **安装** 按钮构建应用。
2. 启动应用。
3. 导航至应用日志，并遵循其中的指示。

> [!NOTE]
> 当您在日志中看到 "请在配置前重启 Home Assistant" 这一行时，
> 下载程序已完成，您需要做的是按照其指示操作（重启 Home Assistant）。
> 此时，您可以像不再需要它一样卸载该应用。
> 其余操作将在 Home Assistant 界面中进行。
> 有关更多信息，请查看 [文档](https://hacs.xyz/docs/use/configuration/basic/)。
