# Home Assistant App: DSMR Reader
[![打开您的 Home Assistant 实例并显示预填充了特定仓库 URL 的添加应用存储库对话框。](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsanderdw%2Fhassio-addons)
[![社区论坛][forum-shield]][forum]

提供一款工具，以便轻松提取、存储和可视化 Smart Meter 通过 DSMR 协议传输的数据。

感谢 Dennis Siemensma 创建了 DSMR Reader 软件（https://dsmr-reader.readthedocs.io）和 Bram van Dartel 创建了底层容器镜像（https://github.com/xirixiz/dsmr-reader-docker）。
