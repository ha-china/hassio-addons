# App: InfluxDB3

用于指标、事件和实时分析的扩展型数据存储。
本版本使用 InfluxDB3 Enterprise 并附带 At-Home 许可证。

## 关于

InfluxDB3 是专为高写入量优化的时序数据库。
它适用于记录指标、传感器数据、事件以及执行分析。它提供 HTTP API 供客户端交互，并且通常与 Grafana 配合使用以可视化数据。

# InfluxData At- Home 许可证
