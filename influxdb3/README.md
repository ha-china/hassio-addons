# 应用：InfluxDB3

用于指标、事件和实时分析的可扩展数据存储。
此版本使用带有“在家版”许可证的 InfluxDB3 企业版。

## 关于

InfluxDB3 是一款针对高写入吞吐量优化的时序数据库。
它适用于记录指标、传感器数据、事件以及执行分析。
它提供了一个供客户端交互的 HTTP API，并且通常与 Grafana 结合使用以进行数据可视化。
