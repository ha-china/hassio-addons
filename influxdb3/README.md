# App: InfluxDB3

用于指标、事件和实时分析的可扩展数据存储。
此版本使用 InfluxDB3 Enterprise 及 At-Home 许可证。

## 关于

InfluxDB3 是一款专为高写入量优化的时序数据库。
它适用于记录指标、传感器数据、事件及执行分析。它通过 HTTP API 暴露给客户端交互，通常与 Grafana 组合使用以可视化数据。

# InfluxData At-Home 许可证

要使用此软件，您需要在应用程序配置中提供您的电子邮件地址。
将发送一个 At-Home 许可证请求给 Influxdata。At-Home 使用是免费的。
在接受许可证之前，请阅读激活邮件中的《软件许可证条款》！
