# App: InfluxDB3

面向指标、事件和实时分析的可扩展数据存储库。
此版本使用 InfluxDB3 Enterprise 及 At-Home 许可证。

## 关于 InfluxDB3

InfluxDB3 是为高写入量负载优化的时序数据库。
它适用于记录指标、传感器数据、事件以及执行分析。它提供 HTTP API 供客户端交互，并且常与 Grafana 结合使用以进行数据可视化。

# InfluxData At-Home 许可证
