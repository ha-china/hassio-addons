在你的 Home Assistant 设备上播放 Spotify 音乐。

## 简介

Home Assistant Spotify Connect 应用允许你使用运行 Home Assistant 的设备播放你的 Spotify 音乐。该应用使用 Spotify Connect 协议，使其成为可以被所有官方客户端控制的一种设备。

例如，如果在这个应用已安装的 Raspberry Pi 上运行 Home Assistant，你就可以在 Pi 上播放你的 Spotify 音乐。所以你只需要将你的音响设备连接到 Pi 即可！
