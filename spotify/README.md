在您的 Home Assistant 设备上播放 Spotify 音乐。

## 关于

Home Assistant Spotify Connect 应用允许您使用运行 Home Assistant 的设备来播放您的 Spotify 音乐。此应用使用 Spotify Connect 协议，使其成为一个可以被所有官方客户端控制的设备。

例如，在安装此应用的 Raspberry Pi 上运行 Home Assistant 将允许您在 Pi 上播放 Spotify 音乐。所以您只需要将您的音响系统连接到 Pi 上！
