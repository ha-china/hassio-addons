# 非官方的 Home Assistant 插件：Terrastate

作为 Home Assistant 插件打包的 [Terrastate](https://github.com/webhippie/terrastate)

## 关于

Terrastate 是一个小型的 HTTP 状态后端，用于 Terraform 和 OpenTofu。它实现了原生的 `http` 后端协议——包括状态锁定——并将每个工作区存储为磁盘上的扁平文件。将其作为 Home Assistant 插件运行，可以在独立的基础设施上保持您的 Terraform 状态，拥有自己独立的备份生命周期，与您为其 Provision 的机器解耦。

## 最终说明

有关如何配置该插件的信息，请参阅插件页面上的 [文档](DOCS.md)。

本项目与 Terrastate 无关联，仅仅是社区努力之作。Terrastate 本身采用 Apache-2.0 协议分发。
