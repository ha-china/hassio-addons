# 非官方 Home Assistant 扩展包：Terrastate

[Terrastate](https://github.com/webhippie/terrastate) 已集成为一个 Home Assistant 扩展包。

## 关于

Terrastate 是 Terraform 和 OpenTofu 的一个小型 HTTP 状态后端。它实现了原生 `http` 后端协议——包括状态锁定功能——并将每个工作空间存储为磁盘上的扁平文件。将其运行作为 Home Assistant 扩展包，可使您的 Terraform 状态存储在与其提供资源隔离的基础设施上，拥有独立的备份生命周期，从而与其提供的机器解耦。

## 最后说明

关于如何配置此扩展包的信息，请参阅扩展包目录下的 [文档](DOCS.md)。

该项目与 Terrastate 无隶属关系，仅是社区努力的一部分。Terrastate 本身采用 Apache-2.0 许可证分发。
