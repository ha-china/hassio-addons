# Home Assistant App: LLDAP

基于 [LLDAP](https://github.com/lldap/lldap) 的 Home Assistant LDAP 应用。

## 关于

LLDAP 是一个轻量级的身份验证服务器，它提供了一个具有意见和简化 LDAP 接口的身份验证。

更多信息：https://github.com/lldap/lldap
