在端口 8124 上运行第二个 Home Assistant 核心

无论 Home Assistant 版本如何（2026.8 版在 Supervisor 下将默认端口改为 80），第二个核心始终监听在容器内的端口 8124。
若要访问其他端口，请添加组件的 *网络* 设置中修改主机端口。

原 GitHub 地址：https://github.com/Smeagolworms4/ha_second_core
