在 8124 端口上运行一套额外的 Home Assistant 核心。

无论 Home Assistant 版本如何（2026.8 版将默认端口更改为 80，这是在 Supervisor 下），第二套核心始终在容器内的 8124 端口上监听。若要在其他端口访问它，需在附加组件 *网络* 设置中更改主机端口。

原 GitHub 仓库：https://github.com/Smeagolworms4/ha_second_core
