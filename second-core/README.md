在 8124 端口上运行第二台 Home Assistant 核心。

第二台核心始终在容器的 8124 端口上监听，无论 Home Assistant 的版本如何（2026.8 版在 Supervisor 下已将默认端口更改为 80）。

若要将其映射到其他端口，请在附加功能的 *网络* 设置中更改主机端口。

原始 GitHub 地址：https://github.com/Smeagolworms4/ha_second_core
