## ⚙️ 配置

通过 Home Assistant 插件页面中的 **配置** 选项卡配置插件。

### 选项

```yaml
app_base_url: ''
dev_use_main_branch: false
factory_reset: false
github_token: ''
log_level: info
marketing_page_enabled: false
test_mode: false
```
