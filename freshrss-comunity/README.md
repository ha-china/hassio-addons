## 关于 FreshRSS

FreshRSS 是一个自己托管的 RSS 和 Atom 聚合器。它收集你订阅的源，追踪你已读的内容，并允许你通过搜索、标签和过滤来浏览这些数据。

它按照计划读取你的源，所以打开时内容已准备好等待你，并且它支持 Google Reader 和 Fever 协议，这使得 Reeder、FeedMe、Fluent Reader 和 NetNewsWire 等移动阅读器可以与其同步。

当你从侧边栏打开 FreshRSS 时，Home Assistant 会让你登录，因此无需再次登录。
