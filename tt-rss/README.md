## 安装

1. 在 Home Assistant 应用商店中搜索 "Tiny Tiny RSS"。
2. 安装应用。
3. 配置数据库连接设置（见配置部分）。
4. 启动应用。

---

## ⚙️ 配置

通过 Home Assistant 应用页面中的 **配置** 选项卡来配置应用。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
self_url: ''
ssl: false
```
