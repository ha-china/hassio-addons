## 📖 简介

## 安装

1. 在 Home Assistant App Store 中搜索 "Tiny Tiny RSS"。
2. 安装该应用。
3. 配置数据库连接设置（详见下文配置部分）。
4. 启动应用。

---

## ⚙️ 配置

通过 Home Assistant 应用页面上的 **配置** 选项卡配置该应用。

### 选项

```yaml
certfile: fullchain.pem
keyfile: privkey.pem
log_level: info
self_url: ''
ssl: false
```
