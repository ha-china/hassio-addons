# Unofficial Home Assistant 附加程序：syslog-ng

作为 Home Assistant 附加程序捆绑的 Healthchecks (<https://healthchecks.io/>).

## 关于

Healthchecks 是监控您的 cron 任务的看门狗。它是一个接收来自 cron 任务的 ping 并且提供网络界面的 Web 服务器。

## 最后说明

有关配置此附加程序的说明，请参阅附加程序页面内的 [文档](DOCS.md)

本项目与 Healthchecks 无关，仅仅是社区的努力。Healthchecks 本身bsd 3 条款许可证分发。
