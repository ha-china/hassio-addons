## 关于 FreshRSS

FreshRSS 是一个自托管的 RSS 和 Atom 聚合器。它会收集你订阅的源，记录哪些文章已阅读，并让你通过搜索、标记和过滤来管理这些内容。

FreshRSS 会按照设定的计划读取你的源，因此你打开时，内容已经在等待你了。同时，它支持 Google Reader 和 Fever 协议，这使得 Reeder、FeedMe、Fluent Reader 和 NetNewsWire 等移动阅读器可以与其同步。

当你从侧边栏打开 FreshRSS 时，Home Assistant 会为你自动登录，因此无需进行第二次登录。
