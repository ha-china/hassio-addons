## 关于

FreshRSS 是一个自我托管的 RSS 和 Atom 聚合器。它会收集您订阅的源，记录您已阅读的条目，并让您可以通过搜索、标记和筛选来浏览它们。

它按照时间表读取您的源，因此打开时内容已经为您就绪，并支持 Google Reader 和 Fever 协议，这使得像 Reeder、FeedMe、Fluent Reader 和 NetNewsWire 之类的移动阅读器可以与其同步。

当您从侧边栏打开它时，Home Assistant 将为您登录，因此无需二次登录即可进入。
