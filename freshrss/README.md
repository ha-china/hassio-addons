## 关于 FreshRSS

FreshRSS 是一个自托管的 RSS 和 Atom 聚合器。它会收集您订阅的流，记录您已阅读的内容，并允许您通过搜索、标记和过滤来遍历这些内容。

它会定时读取您的流源，因此您打开的内容已经为您准备妥当，并且它支持 Google Reader 和 Fever 协议，这使得像 Reeder、FeedMe、Fluent Reader 和 NetNewsWire 这样的移动阅读器能够与之同步。

当您从侧边栏打开它时，Home Assistant 会自动为您登录，因此无需再次登录即可开始使用。
