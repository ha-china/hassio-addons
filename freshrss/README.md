## 关于 FreshRSS

FreshRSS 是一款可自我托管的 RSS 和 Atom 聚合器。它收集您订阅的源，记录您已经阅读过的内容，并让您以您熟悉的方式搜索、标签化和过滤这些内容。

它会按计划读取您的源，因此当您打开时，内容已经等待在那里，并且它支持 Google Reader 和 Fever 协议，这使得像 Reeder、FeedMe、Fluent Reader 和 NetNewsWire 这样的移动阅读器可以与其同步。

Home Assistant 在您从侧边栏打开它时代为您登录，因此无需二次登录即可进入。
