一个将lameteoagricole.net包装器实现为MQTT for Home Assistant的方案。为法国的一个或多个地点创建了一个`weather.<location>`实体（与Météo France卡片兼容）以及农业传感器（DJC、警戒、UV、湿度、风速、日/月…）。

原始Github: https://github.com/Smeagolworms4/meteoagricole2mqtt
