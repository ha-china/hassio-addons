# 非官方 Home Assistant 插件：Loki

Loki (<https://grafana.com/oss/loki/>) 作为 Home Assistant 插件提供。

## 关于

Grafana Loki 是一个受 Prometheus 启发的水平可扩展、高可用、多租户日志聚合系统。它旨在非常经济高效且易于操作。它不对日志内容进行索引，而是为每个日志流设置一组标签。 <https://grafana.com/oss/loki/>
