# 非官方 Home Assistant 扩展：Loki

Loki（<https://grafana.com/oss/loki/>）作为 Home Assistant 扩展捆绑。

## 关于

Grafana Loki 是一个基于 Prometheus 启发的水平可扩展、高可用、多租户日志聚合系统。它设计得非常经济高效且易于操作。它不对日志内容进行索引，而是对每个日志流的一组标签进行索引。<https://grafana.com/oss/loki/>
