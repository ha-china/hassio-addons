# 非官方 Home Assistant 附加组件：Loki

Loki (<https://grafana.com/oss/loki/>) 已捆绑为 Home Assistant 附加组件。

## 关于 Grafana Loki

Grafana Loki 是一款受 Prometheus 启发的横向可扩展、高可用、多租户日志聚合系统。它旨在成本效益高且易于操作。它不会索引日志内容，而是为每个日志流设置一组标签。<https://grafana.com/oss/loki/>

## 最后说明

有关如何配置此附加组件的信息，请参阅附加组件页面中的 [文档](DOCS.md)。
