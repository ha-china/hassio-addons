# 非官方 Home Assistant Add-ons: Loki

Loki (<https://grafana.com/oss/loki/>) 捆绑为 Home Assistant 插件。

## 关于

Grafana Loki 是一款受 Prometheus 启发的水平扩展、高可用、多租户日志聚合系统。它旨在成本效益高且易于操作。它不对日志内容进行索引，而是对每条日志流设置一组标签。<https://grafana.com/oss/loki/>

## 最后说明

关于如何配置此插件的详细信息，请参阅插件页面内的 [文档](DOCS.md)。

本项目与 Loki 无关，仅仅是社区的一项工作。Loki 本身采用 [AGPLv3 许可证](https://www.gnu.org/licenses/agpl-3.0.de.html) 分发。
